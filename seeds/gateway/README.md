# 게이트웨이 배관 씨앗

**새 프로젝트가 복사해서 출발하는 골든이다** — 사내 게이트웨이(와 사외 갈래)에 붙는 배관 한 벌:
갈래 표 · 닿음·담장 판정 · 자격 · 계약 넷(Anthropic · OpenAI · Gemini · 로컬 CLI)의 어댑터 ·
그것을 무는 검사. 배포되지도 임포트되지도 않는다. 복사한 순간부터 그 프로젝트의 것이다.

왜 씨앗인가 — 형제 저장소에서 배관을 **읽어 가져오면 반쪽이 온다**(claude-config #16 · #15).
1,900줄짜리 앱 파일에서 절을 골라 읽는 대신, 짝(손잡이·난간·실측 좌표·곁말·검사)이 다 세어진
밑판에서 시작한다. 무엇을 어느 앱에서 왜 가져왔나는 결정 `docs/decisions/0033` 의 판정표가 든다.

## 출발하는 법

1. `app/` 과 `_check/` 를 새 저장소로 복사한다 — `_check/` 의 `_verdict.py` · `exit_code_check.py` 는
   검사 씨앗(`seeds/check/`)의 사본이라 그 씨앗을 먼저 받았으면 겹친다(같은 글자다 — 결정 0040)
2. `app/gateway.py` 의 `ENV_PREFIX` 를 그 저장소의 접두어로 바꾼다 — 손잡이 전부가 그 접두어로 선다
3. 갈래 표(`app/gateway.py` `_GATEWAY`)의 값을 확인한다 — 사내 값의 진본은 이 저장소 `posco/` 다
4. 검사를 돌린다 — 초록이면 배관이 선 것이다

```bash
python -X utf8 _check/envelope_check.py      # 봉투와 손잡이 — 계약 셋 · 변수로 연 한도
python -X utf8 _check/sites_lock_check.py    # 담장 스위치 — 닫힌 갈래가 자격에서 빠지나
python -X utf8 _check/cli_pipe_check.py      # 로컬 CLI 파이프 — 가짜 자식으로 배관만
python -X utf8 _check/exit_code_check.py     # 검사들이 종료코드 계약을 지키나 — 원문만 읽는다
```

앱은 그 위에 제 것을 얹는다 — 서버 문 · 화면 · 프롬프트 · 기록층 · 도구 루프. `providers.stream_once`
가 돌려주는 것은 `(글자, stop_reason)` 하나다.

## 무엇이 들고 무엇이 안 드나

| 든다 | 안 든다 — 앱이 얹는다 |
|---|---|
| 글자 스트림 · 캐시 경계 · 씀씀이 보고 · 이어받기(이음매 벗기기까지) | 도구 호출 루프 · 첨부 · 그림 parts |
| 드라이런(키 없으면 봉투 명세만) · 거절 몸통을 구조로 지님 · 빈손 둘의 이름 | 기록층(무엇을 어디에 남기나) · 화면 신호 |
| 담장 선언 · 닿음 판정(끝점 단위 한 번) · CLI 로그인 판정 · 「안 잰 자리」를 재는 실호출 프로브 | 앱 고유 규격의 프로브(도구 루프 · 첨부) |

## 한도는 변수다

시간 벽 · 이어받기 바퀴 · 봉투 상한 · 출력 상한 · 캐시 수명 · 생각 손잡이 · 담장 · 기본 갈래가
전부 `{ENV_PREFIX}_…` 로 열린다. 부딪히면 코드를 고치지 말고 변수부터 바꾼다. 무엇이 있나는
`app/gateway.py` 에서 `_env(` 를 찾으면 전부다 — 여기 목록을 두면 사본이다.

## 안 잰 자리 — 씨앗이 모른다고 말하는 것

곁말에 「안 쟀다」로 박혀 있다. 조용히 한쪽을 고르지 않았다. 사내 PC 에서 재는 자가 있다 —
값을 치르는 자라 검사 묶음에 안 든다:

```bash
python -X utf8 _check/live_probe.py all <글 파일>       # 셋 다 · 검체를 안 주면 「안 잼」으로 물러난다 · 숫자는 _check/log/ 에
python -X utf8 _check/live_probe.py ratio <글 파일>     # 제 봉투의 결(HTML 섞임 등)로 환산비만
python -X utf8 _check/claude_thinking_probe.py          # Claude 갈래 — 침묵이 생각인가 버퍼링인가. 판정을 낸다
python -X utf8 _check/stream_probe.py [--wall]          # 글자가 언제 오나. --wall 은 벽의 시각(3분 · 값을 치른다)
```

- **자/토큰 환산비** — 한국어 산문으로 쟀다(2026-09-09): anthropic 1.26 · openai 2.06 · gemini 2.08.
  조이는 자는 「벽 × 비」가 가장 작은 모델(Claude · 1.26M자)이고 씨앗의 900,000 은 그 아래다.
  HTML 이 섞인 결은 아뜰리에 표본(1.17~2.09)뿐이라 제 봉투로 다시 잰다
- **층 셋 이상 봉투의 캐시 적중** — 쟀다(2026-09-09): 표를 단 두 층이 다 캐시에 든다(write 8,005 → read 8,005)
- **gemini 밖 계약의 여문 빈손** — 판정은 계약 전체 위에 섰지만 다른 계약이 그 판을 낸 적은 없다. **아직 안 쟀다**
- **생각 조각** — 쟀다(2026-09-09 · gemini-3.1-pro-preview): 첫 조각 8.6초 전에 생각 신호 11번, 씀씀이에 `thinking_tokens=971`
- **Claude 갈래의 생각** — 쟀다(2026-09-09 · opus-4.7 · opus-5): 4.7 은 어떤 몸으로도 생각이 안 나고 5 는
  모델 기본값으로 난다. **생각 조각은 어느 판에도 안 흐른다** — 모델이 생각하는 동안 선이 조용하다.
  그래서 `claude_thinking_probe.py` 의 「선을 탄다」 판정은 **빨강이 실측**이고, 초록이 나오면 게이트웨이가 바뀐 것이다
- **스트림이 흐르나** — 쟀다(2026-08-24 · anthropic · openai): 고르게 흘렀다. 첫 글자 5초 언저리 · 뒤 창 몫 3%
- **180초 벽** — 두 번 실측됐지만(2026-08-27 · 09-09 · 클라이언트 쪽에서) **프로브로는 아직 안 쟀다.**
  `stream_probe.py --wall` 이 그 자리다 — 벽이 옮겨졌는지 의심될 때 돌린다

## 앱과 씨앗이 갈렸을 때

앱은 갈려도 된다 — **왜 갈렸나가 그 자리 곁말에 서 있으면.** 갈린 자리를 세우는 자가 있다:

```bash
python -X utf8 _check/drift_check.py <앱 나무>     # 같음 · 갈림 · 없음 — 판정은 사람이
```

배관을 앱에서 고쳤으면 씨앗도 고친다 — 그 고침이 사고에서 왔으면 더욱. 씨앗이 낡으면 다음
프로젝트가 같은 사고를 다시 겪는다.
