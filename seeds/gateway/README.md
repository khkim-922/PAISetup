# 게이트웨이 배관 씨앗

**사내 게이트웨이에 붙는 배관 한 벌과, 그 배관을 무는 검사 한 벌이다.** 회사가 세운 모델
중계 서버를 이 문서에서는 게이트웨이라고 부르고, 그 서버가 내주는 경로 하나하나를 **갈래**라고
부른다. 사외 갈래(구글 직결 · 이 PC 의 구독)도 같은 표에 산다.

들어 있는 것 — 갈래 표 · 닿음 판정 · 담장(어느 갈래를 여나) · 자격 · 그리고 계약 넷의
어댑터(Anthropic · OpenAI · Gemini · 이 PC 에 깔린 로컬 CLI). 계약이란 그 갈래가 쓰는
요청·응답 규격을 말한다 — 갈래는 넷보다 많고, 여럿이 한 계약을 함께 쓴다.

임포트해서 쓰는 라이브러리가 아니다. 폴더를 복사하면 그때부터 그 저장소의 것이다.

## 왜 이런 것이 따로 있나

이미 돌아가는 앱에서 배관 부분만 골라 읽어 옮기면 **반쪽이 온다.** 손잡이는 오는데 그것을
지키는 난간이 안 오고, 그 난간이 왜 거기 있었는지는 더 안 온다 — 난간은 대개 한 번 데인
자리에 서 있으므로, 안 옮긴 쪽이 곧 다음에 다시 데일 자리다.

그래서 짝이 다 세어진 밑판을 따로 둔다. 손잡이 하나마다 그것을 지키는 난간과, 난간이 선
까닭과, 그 난간이 실제로 무는지 재는 검사가 함께 있다.

## 받는 길이 둘이다

무엇을 받으려는지에 따라 갈린다.

| 가르는 것 | 길 ① 배관째 출발한다 | 길 ② 검사만 받는다 |
|---|---|---|
| 언제 | 새 프로젝트를 시작한다 | 배관은 이미 제 저장소에 있다 |
| 복사할 것 | `app/` 과 `_check/` | `_check/` |
| 이어 맞출 것 | 접두어와 갈래 표의 값 | 곁 선언 `_check/gateway.conf` 에 제 배관 좌표 |

### 길 ① — 배관째 출발한다

1. `app/` 과 `_check/` 를 새 저장소로 복사한다. `_check/` 의 `_verdict.py` 와
   `exit_code_check.py` 는 검사 씨앗(곁 폴더 `check/`)의 사본이라, 그 씨앗을 먼저 받았으면
   그 두 파일이 겹친다 — 글자가 같으므로 겹쳐도 된다.
2. `app/gateway.py` 의 `ENV_PREFIX` 를 그 저장소의 접두어로 바꾼다. 손잡이 전부가 그 접두어로
   선다.
3. 갈래 표(`app/gateway.py` 의 `_GATEWAY`)의 값을 확인한다. 사내 값의 진본은 함께 깔리는
   사내 환경 문서 폴더(`posco/`)다.
4. 아래 「돌려 보기」를 돈다.

앱은 그 위에 제 것을 얹는다 — 서버 문 · 화면 · 프롬프트 · 기록층 · 도구 루프.
`providers.stream_once` 가 돌려주는 것은 `(글자, stop_reason)` 하나다.

### 길 ② — 배관은 이미 있고 검사만 받는다

받아 간 검사 파일은 **사본**이라 진본과 글자가 같아야 한다(검사 씨앗의 「진본과 사본」 절).
그런데 배관이 사는 모듈 이름은 저장소마다 갈린다. 그 이름을 검사 안에 박아 두면, 다르게 두는
저장소는 받는 순간 그 줄을 손으로 고쳐야 하고 **고치는 순간 사본이 어긋남으로 물린다.**

그래서 갈리는 것만 검사 밖으로 뺐다. 검사는 `from _plumb import gateway, providers` 로 물고,
`_plumb.py` 가 이 폴더의 `gateway.conf` 를 읽어 어느 모듈을 물지 고른다.

```ini
[plumb]                                    # 배관이 사는 모듈
module    = app.gateway
providers = app.providers
[where]                                    # 위 `module` 이 **안 드는** 자리만 · 꼴은 `모듈:이름`
LOGS_DIR  = app.config:LOGS_DIR
env_token = app.config:_env_token
[values]                                   # 배관에 속성이 **아예 없는** 자리 · 좌표가 아니라 값
ENV_PREFIX = MYAPP
```

**선언이 없거나 칸이 비면 씨앗 기본값(`app.gateway` · `app.providers`)으로 돈다** — 배관
이름이 씨앗과 같은 저장소는 선언을 안 채워도 그대로 돈다.

값이 아니라 **모듈 이름 하나**가 선언의 몸통인 까닭은 이렇다. 이 검사들이 코드로 무는 배관
이름은 서른 남짓인데, 저장소 사이에서 실제로 갈리는 것은 셋뿐이다 — 접두어(`ENV_PREFIX`) ·
기록 자리(`LOGS_DIR`) · 키를 읽는 손(`env_token`). 나머지는 어느 저장소나 같은 이름으로 든다.
그래서 `[where]`·`[values]` 는 예외를 적는 자리로 남는다. 예외가 열을 넘어가기 시작하면 그때는
이 길이 아니라 배관 이름을 씨앗에 맞추는 쪽이 싸다.

맞췄는지 이렇게 본다.

```bash
python -X utf8 _check/_plumb.py --show          # 이 저장소의 선언이 무엇으로 풀리나
python -X utf8 _check/_plumb.py --self-check    # 선언이 좌표를 정말 옮기나 — 임시 나무로
```

**이 길로 오는 것은 검사 넷과 부품 하나다** — `cli_pipe_check.py` · `sites_lock_check.py` ·
`probe_words_check.py` · `gateway_probe.py`, 그리고 그중 `cli_pipe_check.py` 가 쓰는 부품
`_fake_cli.py`(혼자 안 돈다).
`envelope_check.py` · `claude_thinking_probe.py` · `live_probe.py` · `stream_probe.py` 는 아직
`from app import gateway` 를 박고 있어, 배관이 그 이름으로 사는 저장소에서만 돈다.

⚠ **이 길이 여는 것은 이름까지다.** 저쪽 배관에 그 자리가 **아예 없으면** 좌표로 이을 데가
없어, `get`·`slot`·`put` 이 「없다」를 던지고 부르는 검사가 그것을 `2`(못 쟀다)로 옮긴다.
**빨강이 아니다** — 안 잰 것이지 어긋난 것이 아니다. 화면이 어느 선언을 어떻게 고치라고
말하므로, 돌리고 읽고 채우는 순서로 맞춰 간다.

⚠ **검사 안에 배관 모듈 이름을 다시 적지 않는다.** 적으면 그 검사만 조용히 씨앗 이름에
묶여, 받은 저장소에서 **초록인 채로 남의 모듈을 잰다.** 자식 프로세스로 넘길 때도 이름을
인자로 건넨다.

## 돌려 보기

```bash
python -X utf8 _check/envelope_check.py      # 봉투가 계약 셋의 규격대로 서나 · 손잡이가 실제로 봉투를 바꾸나
python -X utf8 _check/sites_lock_check.py    # 담장 — 닫은 갈래가 목록에서도 자격에서도 빠지나
python -X utf8 _check/cli_pipe_check.py      # 로컬 CLI 파이프 — 가짜 자식으로 배관만. 진짜 CLI 를 안 부른다
python -X utf8 _check/exit_code_check.py     # 검사들이 종료코드 계약을 지키나 — 원문만 읽는다
python -X utf8 _check/gateway_probe.py --self-check   # 어댑터가 응답을 읽는 쪽 — 가짜 게이트웨이로 값 안 치르고 한 바퀴
python -X utf8 _check/probe_words_check.py   # 끝점에 못 닿았을 때 그 까닭을 사람 말로 내나
```

**위 여섯은 다 바깥으로 안 나간다** — 게이트웨이도 진짜 CLI 도 진짜 모델도 안 부르고 자격도
요금도 안 쓴다. 재려면 상대가 있어야 하는 것들은 이 PC 안에서 상대를 지어 세운다 — 루프백에
가짜 서버를 띄우거나, 임시 자리에 가짜 자식 프로세스를 구워 놓고 부른다.

마지막 하나에는 갈래가 있다. 전제를 재는 한 절이 OS 신뢰 저장소를 끼우는 꾸러미(`truststore`)를
무는 자리라, 그것이 없는 파이썬에서는 그 절만 못 재고 `2` 로 나간다 — 초록이 아니지만 빨강도
아니다. 씨앗 배관에는 실행 의존이 없어 그 꾸러미를 선언하지 않으므로, 이 자리는 그것을 끼는
앱의 파이썬에서 닫힌다.

## 배관이 드는 것과 앱이 얹는 것

| 이 배관이 든다 | 앱이 얹는다 |
|---|---|
| 글자 스트림 · 캐시 경계 · 씀씀이 보고 · 상한에서 끊긴 응답 이어받기(이어 붙인 이음매의 군더더기를 벗기는 것까지) | 도구 호출 루프 · 첨부 · 그림 조각 |
| 드라이런(키가 없으면 보내지 않고 봉투 명세만 돌려준다) · 거절 몸통을 글자가 아니라 구조로 지님 · 빈손 두 갈래의 이름(빈 채 끊긴 것 · 신호는 섰는데 0자인 것) | 기록층(무엇을 어디에 남기나) · 화면에 무엇을 보이나 |
| 담장 선언 · 닿음 판정(끝점 하나에 한 번) · CLI 로그인 여부 판정 · 「안 잰 자리」를 실제로 재는 프로브 | 그 앱 고유 규격을 재는 프로브(도구 루프 · 첨부) |

## 한도는 변수다

시간 벽 · 이어받기 바퀴 · 봉투 상한 · 출력 상한 · 캐시 수명 · 생각 손잡이 · 담장 · 기본
갈래가 전부 `{ENV_PREFIX}_…` 꼴 환경변수로 열려 있다. 부딪히면 코드를 고치지 말고 변수부터
바꾼다.

무엇이 있나는 `app/gateway.py` 에서 `_env(` 를 찾으면 전부다. 여기 목록을 두면 사본이 되고,
사본은 손잡이가 늘거나 줄 때 조용히 낡는다.

## 안 잰 자리 — 씨앗이 모른다고 말하는 것

값을 치르는 자리(사내 자격·요금)는 검사 묶음에 안 든다. 조용히 한쪽을 고르지 않고 「안
쟀다」로 적어 두었고, 필요할 때 사내 PC 에서 다시 재는 자가 따로 있다.

```bash
python -X utf8 _check/live_probe.py all <글 파일>   # 셋 다 · 검체를 안 주면 「안 잼」으로 물러난다 · 숫자는 _check/log/ 에
python -X utf8 _check/live_probe.py ratio <글 파일> # 제 봉투의 결로 환산비만
python -X utf8 _check/claude_thinking_probe.py      # Claude 갈래 — 침묵이 생각인가 버퍼링인가
python -X utf8 _check/stream_probe.py [--wall]      # 글자가 언제 오나. --wall 은 벽의 시각(3분)
```

지금까지 잰 것과 아직 못 잰 것.

| 자리 | 어디까지 쟀나 |
|---|---|
| 자·토큰 환산비 (한 토큰이 몇 자인가) | 한국어 산문으로 쟀다(2026-09-09) — anthropic 1.26 · openai 2.06 · gemini 2.08. 가장 먼저 조이는 것은 「토큰 벽 × 이 비」가 가장 작은 Claude(1.26M자)이고, 씨앗이 세운 봉투 상한(`MAX_ENVELOPE_CHARS`)은 그 아래다. HTML 이 섞인 봉투는 1.17~2.09 로 넓게 흔들린 표본이 있어 **제 봉투로 다시 잰다** |
| 층 셋 이상 봉투의 캐시 적중 | 쟀다(2026-09-09) — 표를 단 두 층이 다 캐시에 든다(쓰기 8,005 → 읽기 8,005) |
| 생각 조각이 선을 타나 (Gemini) | 쟀다(2026-09-09 · gemini-3.1-pro-preview) — 첫 조각 8.6초 전에 생각 신호 11번, 씀씀이에 `thinking_tokens=971` |
| 생각 조각이 선을 타나 (Claude) | 쟀다(2026-09-09 · opus-4.7 · opus-5) — 4.7 은 어떤 몸으로도 생각이 안 나고 5 는 모델 기본값으로 난다. **어느 판에도 생각 조각은 안 흐른다** — 모델이 생각하는 동안 선이 조용하다. 그래서 `claude_thinking_probe.py` 의 「선을 탄다」 판정은 **빨강이 실측**이고, 초록이 나오면 게이트웨이가 바뀐 것이다 |
| 스트림이 진짜 흐르나 | 쟀다(2026-08-24 · anthropic · openai) — 고르게 흘렀다. 첫 글자 5초 언저리 · 뒤 창 몫 3% |
| 여문 빈손 — 저쪽이 「다 말했다」 신호를 세워 놓고 글자를 한 자도 안 준 판 | Gemini 갈래에서만 겪었다. 배관은 계약 넷 전부에서 그 판을 잡게 서 있지만 **다른 계약이 실제로 그 판을 낸 적은 없어 아직 안 쟀다** |
| 180초 벽 | **프로브로는 아직 안 쟀다.** 클라이언트 쪽에서 두 번 겪었다(2026-08-27 · 09-09). `stream_probe.py --wall` 이 그 자리다 — 벽이 옮겨졌는지 의심될 때 돌린다 |

## 앱과 씨앗이 갈렸을 때

**앱은 갈려도 된다 — 왜 갈렸나가 그 자리에 적혀 있으면.** 갈림 자체는 결함이 아니고, 같음이
곧 맞음도 아니다. 문제는 **왜 갈렸는지 아무도 모르는 채로** 갈리는 것이다.

갈린 자리를 이름으로 세워 주는 자가 있다. 판정은 안 낸다 — 같음·갈림·없음 목록만 내고
정하는 것은 사람이다.

```bash
python -X utf8 _check/drift_check.py <앱 나무>
```

이름으로 세우므로 **한쪽에만 있는 값과 손으로 적은 글자는 안 잡힌다.** 그 자리는 절을 통째로
읽는 수밖에 없다.

배관을 앱에서 고쳤으면 씨앗도 고친다 — 그 고침이 사고에서 왔으면 더욱. 씨앗이 낡으면 다음
프로젝트가 같은 사고를 처음부터 다시 겪는다.
