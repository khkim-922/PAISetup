# `_check/` — 종료코드 계약

이 폴더의 검사·프로브는 판정을 `_verdict.py` 로 찍고 **종료코드로 말한다.** 어느 검사가
무엇을 재나는 각 파일 머리말과 씨앗 `README.md` 가 든다 — 여기는 계약 하나만 든다.

## 종료코드 — 갈래를 코드가 말한다

훅도 CI 도 화면 문구를 안 읽고 코드만 본다. 그래서 이 갈림이 곧 계약이다.

| 코드 | 뜻 | 조심할 것 |
|---|---|---|
| **0** | 쟀고 맞다 | 「전부 통과」는 *여기까지* 통과다 — 무엇을 쟀나(건수·범위)를 초록 줄이 같이 찍는다 |
| **1** | 어긋났다 | 고침을 넣었는데 그대로 빨강이면 다음에 열 것은 대상이 아니라 **검사**다 |
| **2** | **못 쟀다** | 초록이 아니다. 자격·검체·게이트웨이가 없어 **아예 안 재인** 자리다 |

⚠ **`raise SystemExit("글자")` 는 2 를 1 로 뭉갠다** — 파이썬이 그 글자를 stderr 로 찍고
무조건 **1** 로 나간다. 화면은 맞는 말을 하는데 훅·CI 만 조용히 틀린다. 「못 쟀다」로 그
자리에서 나가는 손은 **한 벌**이다 — `raise Unmeasured("…")` 가 까닭을 찍고 2 로 나간다.
상수는 `_verdict.py` 의 `EXIT_OK`·`EXIT_MISMATCH`·`EXIT_UNMEASURED` 다.
