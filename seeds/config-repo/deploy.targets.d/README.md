# deploy.targets.d — 배포 대상 선언

`deploy.ps1` 이 이 폴더의 `*.conf` 를 **전부 읽어 합친다.** 존재하지 않는 경로는 조용히
건너뛰므로, 어느 PC 에서 돌려도 그 PC 것만 걸린다.

**파일 하나가 PC 하나다.** 한 파일에 몰지 않는 이유는 포크다 — 파일이 갈려 있으면 포크한
사람은 **제 파일만 두고 나머지를 지우면** 되고, 그 뒤로 `git merge upstream/main` 이 남의
파일만 건드리므로 **이 자리에서 충돌이 안 난다.**

## 형식

- `[repos]` — 저장소마다 한 벌씩 두는 배포본(훅 몸통과 그 등록)을 받을 저장소 루트.
  **무엇이 가나는 `deploy.repofiles.conf` 가 든다** — 여기 옮겨 적지 않는다.
  전역 규범·영역 룰은 이리로 **안 온다**: 홈 한 자리다 (결정 기록 `0014`)
- `[memory:<이름>]` — `memory/<이름>/` 이 갈 `~/.claude/projects/` 슬러그

슬러그는 Claude Code 가 **프로젝트의 전체 경로**를 바꿔 만든 폴더 이름이라 PC마다 다르다.
경로를 알면 계산할 수 있고, 확인은 `ls ~/.claude/projects`.

`#` 뒤는 주석이고 빈 줄은 무시한다.

## 포크한 사람

이 폴더의 파일을 **다 지우고** 자기 PC 파일 하나를 만든다. `deploy.ps1` 은 고치지 않는다.
