# deploy.targets.d — 배포 대상 선언

`deploy.ps1` 이 이 PC 의 어느 저장소와 어느 메모리 폴더에 무엇을 깔지 정하려고 이 폴더의
`*.conf` 를 **전부 읽어 합친다.** 이 PC 에 없는 경로는 말없이 건너뛰므로, 여러 PC 의 파일이 같이
있어도 어느 PC 에서 돌리든 그 PC 것만 걸린다. 다만 `[repos]` 가 이 PC 에 **하나도** 안 걸리면
「이 PC 파일이 없다」로 읽고 그렇게 알린다.

**파일 하나가 PC 하나다.** 한 파일에 몰지 않는 까닭은 포크다 — 파일이 갈려 있으면 포크한
사람은 **제 파일만 두고 나머지를 지우면** 되고, 그 뒤로 `git merge upstream/main` 을 해도 남의
파일만 바뀌므로 **이 폴더에서는 충돌이 안 난다.**

## 형식

- `[repos]` — 이 PC 에 있는 저장소의 뿌리 폴더 경로. 배포는 여기 적힌 저장소마다 훅 본체 같은
  파일을 넣고, 커밋 게이트를 걸고, 그 저장소의 세션 훅을 부른다.
  **무엇을 넣나는 `deploy.repofiles.conf` 가 든다** — 여기 옮겨 적지 않는다.
  전역 규범 · 영역 룰은 저장소로 **안 간다** — 홈(`~/.claude/`) 한 자리에만 깐다
  (결정 기록 `0014` — 「전역 규율은 홈 한 자리다」)
- `[memory:<이름>]` — 설정 저장소의 `memory/<이름>/` 을 깔 `~/.claude/projects/` 아래 폴더 이름(슬러그)

슬러그는 Claude Code 가 **프로젝트의 전체 경로**에서 영숫자가 아닌 글자를 모두 `-` 로 바꿔 만든 폴더
이름이라 PC 마다 다르다. 경로를 알면 계산할 수 있고, 확인은 `ls ~/.claude/projects`.

`#` 뒤는 주석이고 빈 줄은 무시한다.

## 포크한 사람

이 폴더의 `*.conf` 를 **다 지우고** 자기 PC 파일 하나를 만든다(견본 `example-pc.conf` 가 있으면 그것의
이름을 바꿔 고친다). `deploy.ps1` 은 고치지 않는다.
