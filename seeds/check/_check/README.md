# `_check/` — 검사와 부품 지도

**이 폴더는 저장소가 제 코드를 재는 검사들이 사는 곳이다.** 이 지도가 따로 있어야 하는 까닭은 파일
이름만으로는 답이 안 나오기 때문이다 — 겉으로는 다 같은 `python -X utf8 _check/<이름>.py` 인데 **초록의
뜻이 갈래마다 다르다.** 어떤 초록은 *우리 코드가 계약을 지킨다*는 말이고, 어떤 초록은 *저쪽이 그렇게
하더라*는 말이다. 둘을 섞으면 「다 통과했다」가 아무 뜻도 없는 말이 된다.

**한 검사가 무엇을 재나는 그 파일의 머리 첫 줄이 진본이다.** 표의 「무엇을 재나」 칸은 손으로 안
적고 그 줄에서 옮겨 온다 — 표 바로 위의 표식 주석이 그렇다고 적어 두고, `map_check.py` 가 어긋남을
문다. 표가 제 손으로 드는 것은 *무엇이 있고 언제 부르나*까지다.

## 초록의 뜻이 갈래마다 다르다

| 갈래 | 무엇을 부르나 | 무엇이 있어야 도나 | 초록이 뜻하는 것 |
|---|---|---|---|
| **게이트** | 우리 코드만 | 이 나무의 파이썬 | **우리가 정한 계약이 코드에 서 있다.** 저쪽이 무엇을 주는지는 아무 말도 안 한다 |
| **화면 실측** | 진짜 브라우저에 띄운 우리 화면 | 위 + node · playwright · 크로미움 | **화면이 실제로 그렇게 군다.** 소스에 문자열이 있나가 아니라 그려진 것을 읽는다 |
| **프로브** | 게이트웨이·진짜 CLI·진짜 모델 | 위 + 자격과 그 망 | **저쪽이 지금 그렇게 하더라.** 판마다 흔들릴 수 있어 한 판은 사실이지 규칙이 아니다 |
| **재는 자** | 검사마다 다르다 | 그 검사의 줄에 적는다 | **없다 — 판정을 안 낸다.** 수·견줌표만 내고 정하는 것은 사람이다 |

⚠ **갈래가 곧 「돌려도 되나」다.** 게이트와 화면 실측은 아무 때나 돌려도 잃을 것이 없다. 프로브는
**누르는 순간 값을 치른다.** 그래서 프로브는 「검사를 다 돌리자」에 안 들어간다.

## 종료코드 — 갈래를 코드가 말한다

훅도 CI 도 화면 문구를 안 읽고 코드만 본다. 그래서 이 갈림이 곧 계약이다.

| 코드 | 뜻 | 조심할 것 |
|---|---|---|
| **0** | 쟀고 맞다 | 「전부 통과」는 *여기까지* 통과다 — 무엇을 쟀나(건수·범위)를 초록 줄이 같이 찍는다 |
| **1** | 어긋났다 | 고침을 넣었는데 그대로 빨강이면 다음에 열 것은 대상이 아니라 **검사**다 |
| **2** | **못 쟀다** | 초록이 아니다. 자격·검체·브라우저가 없어 **아예 못 잰** 자리다 |

⚠ **`raise SystemExit("글자")` 는 2 를 1 로 뭉갠다** — 파이썬이 그 글자를 stderr 로 찍고 무조건 **1**
로 나간다. 화면은 맞는 말을 하는데 훅·CI 만 조용히 틀린다. 「못 쟀다」로 그 자리에서 나가는 길은
**하나**다 — `raise Unmeasured("…")` 가 까닭을 찍고 2 로 나간다. 상수는 `_verdict.py` 의
`EXIT_OK`·`EXIT_MISMATCH`·`EXIT_UNMEASURED` 다. `sys.exit(main())` 꼴이면 `main` 의 `return` 도
그 상수로 한다 — 그 꼴까지 `exit_code_check.py` 가 문다.

## 공용 부품 — 검사가 아니다

밑줄로 시작하는 파일은 검사가 아니라 여러 검사가 함께 쓰는 부품이다. **새 검사는 이 부품을 불러
쓰고, 제 안에 베껴 넣지 않는다.**

| 부품 | 무엇을 드나 |
|---|---|
| `_verdict.py` | **판정 한 벌과 종료코드 계약** — 계약 판정 · 값 대조 · 통과할 때도 보여야 하는 경계 · 아예 안 잰 자리(`unmeasured()`) · 계수. 숫자 셋과 **그 자리에서 2 로 나가는 손**(`Unmeasured`)의 진본이 여기다 |
| `_serve.py` | 서버를 제 프로세스 안에 세우고(`stand`·`stop`) 문을 두드리는(`knock`·`jknock`) 한 벌 — 앱을 안 문다 |
| `_browser.mjs` | 브라우저를 판에 안 매이게 띄운다 — 실행 파일을 찾아 직접 가리키고 무엇을 집었나 찍는다 |
| `_tree.mjs` | 검사가 제 뿌리와 제 파이썬을 묻는 자리 — 자리를 박지 않고 물어서 받는다 |
| `_pixels.py` | 결정론 잡음 PNG — 「이름만 그림」인 가짜가 안 실리게 된 뒤의 검체 (PIL 이 든다) |
| `_vision.py` | 그림이 무는 값의 눈금 — 패치 28 · 기본 긴 변 · 상류 천장 · `patches()`·`fit()`·`downscaled()`. 의존성 0 이라 PIL 없는 그림 문(홈 훅)도 같은 수를 읽는다 |
| `_shrink.py` | 그림을 줄여 비전 토큰을 아낀다 — **치수가 토큰을 정하고** 무손실 WebP 는 바이트만 정한다 (PIL 이 든다 · 눈금은 `_vision.py`) |
| `_see_window.ps1` | 창 하나를 **창 손잡이로** 찍는다 — 가려져 있어도 제 모습이 찍힌다. 층 · 위에 겹친 창 · 캡처 막기를 같이 댄다. 화면 전체 캡처의 빈 자리는 「없다」가 아니라 「안 보였다」라서 둔다 (윈도우 전용 · 그림 문이 화면 크기 그림에서 가리킨다) |
| `_bake.mjs` | 검사가 먹일 파일을 굽는다 — PNG · EMF · docx · DRM 머리. 바이너리 검체를 폴더에 안 둔다 · 머리 바이트는 부르는 쪽이 제 진본에서 읽어 넘긴다 |
| `_py.sh` | **실행형 파이썬 해석기를 골라 부르거나 변수로 세운다** — 윈도 스토어 껍데기(49)를 거르고 venv · 시스템 판을 찾아 `exec` 또는 `PY` 변수를 채운다 (0028 · 0040 · #75) |

## 이 폴더의 규율

1. **양성 대조 없이 음성 판정을 세우지 않는다.** 「안 일어난다」만 재면 화면이 통째로 안 떠도
   초록이 된다.
2. **재는 쪽과 재이는 쪽이 같으면 답은 늘 초록이다.** 한쪽을 진본으로 세우고, 다른 쪽을 거기서
   지어 견준다.
3. **전수를 셀 때는 반드시 잡혀야 할 표본(센티널)을 같이 세운다.** 수집이 무너지면 `0 == 0` 으로
   초록이 난다.
4. **판정마다 제가 정말 무는지 확인한다** — 고침을 걷어 낸 사본을 먹였을 때 실제로 빨강이 나는지까지
   본다.
5. **경계는 검사가 스스로 말한다.** 통과할 때도 보여야 하는 말은 `edge()` 로 — 실패 상세에 싣지
   않는다.
6. **초록 줄은 「몇 건을 쟀나」를 달고 나간다.** 그 건수를 손으로 적지 않는다 — `len(passes())` 가
   센다. `verdict_line_check.py` 가 문다.
7. **받아 간 사본은 손으로 고치지 않는다.** 머리말의 곁말(사본 표식) 한 줄이 진본을 가리키고
   `borrowed_check.py` 가 문다 — 그 줄의 꼴과 자리는 씨앗 `README.md` 가 든다. 고쳐야 했다면
   그 고침은 진본으로 올린다.
8. **실물 결함을 만나면 여기서 고치지 않는다** — 이 폴더는 재는 자리다.

## 무엇을 안 재나

| 자리 | 왜 |
|---|---|
| `.mjs`·`.sh`·`.ps1` 의 나가는 자리 중 **글자 꼴로 안 보이는 것** | `shell_exit_check.py` 는 AST 없이 글자 꼴로 문다 — 변수로 나가는 자리·`.sh`/`.ps1` 의 손글자 2(계약 상수를 둘 자리가 없다)·「못 쟀다」 뒤 `exit 0`(뜻이라 세기만 한다)은 판정 밖이다 |
| 「못 쟀다」의 **갈래 선택** — 못 쟀는데 0 이나 1 로 나가는 자리 | 꼴이 아니라 뜻이라 사람이 읽는다 |
| 한국어 수사로 적은 범위(「계약 아홉」)가 맞는 말인가 | 글자가 곧 뜻이다 |
| 곁말(사본 표식) 없이 베낀 사본 | `borrowed_check.py` 에게는 남이다 — 갈린 자리를 이름으로 세우는 자의 몫. 다만 **`.githooks/` 는 예외다**: 셸 조각은 곁말을 달 자리가 없어 자리로 맞춘다 |
| `.githooks/` 배포본 — **진본 저장소가 이 기계에 안 붙은 판** | `borrowed_check.py` 가 견줄 상대가 없다. 판정이 아니라 **안 잰 자리**로 찍는다 — 진본 저장소 안에서 돌릴 때도 같다(제 자신과 견주면 늘 초록이다) |
| 진본에는 있는데 이 나무의 `.githooks/` 에 **없는** 조각 | 형제 저장소에는 조각이 없는 것이 정상이다 — 러너가 설정 저장소(없으면 홈 씨앗)에서 찾는다(결정 0064). 없는 것은 결함이 아니라 안 무는 것이 맞다 |
| 어느 검사가 **실제로** 어느 코드로 나가나 | 원문의 꼴까지다 — 돌려 보지 않는다 |
| 진본 뿌리가 **그 나무의 최신 판인가** | `borrowed_check.py` 는 뿌리의 판을 판정 줄에 **찍기만** 한다(뿌리의 `.version` → git `HEAD` → 「판 모름」). 최신인지는 나무를 봐야 아는 것이라 이 자리 밖이다 — 찍힌 판이 그 물음의 재료다 |
