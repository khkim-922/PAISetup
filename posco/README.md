# 사내 환경 자료 (POSCO)

**이 회사에서 무엇이 되고 안 되는지는 이 폴더 전체가 진본이다.** 다른 회사면 폴더째 지운다
(결정 0020 — 잘라 쓰기가 파일 고르기가 아니라 폴더 하나 지우기가 되게).

이 문서는 **어느 결의 자료가 여기 사는가**만 가른다. 파일 목록은 안 든다 — `ls` 가 답하는
것을 문장에 박으면 그 문장이 사본이 되고, 파일이 늘 때 조용히 낡는다. 0020 이 이 폴더를
만든 까닭이 그것이다: **폴더가 곧 목록이다.**

## 먼저 열 것

**[`ENV-posco.md`](ENV-posco.md)** — 이 회사 환경의 들머리다. 사내 게이트웨이를 무엇으로
부르고, 어느 명세가 어느 파일에 있고, 무엇이 막혀 있나를 그 문서가 든다. 무엇을 열지 모를
때 여기서 시작한다.

## 여기 사는 자료의 결

| 결 | 무엇 | 어떻게 읽나 |
|---|---|---|
| **사내 명세** (`*.setting.md`) | 게이트웨이가 내주는 API 의 계약 — 모델별·클라이언트별 | 회사 문서를 그대로 옮긴 것이다. **우리가 쓴 글이 아니라 인용이라 고치지 않는다** |
| **오류 사전** | 게이트웨이가 내는 오류 코드와 그 뜻 | 같다 — 인용이다 |
| **게이트웨이 앞단** | 요청이 실제로 지나는 경로와 그 설정 원문 | 회사가 세운 것이라 바꾸는 손이 우리에게 없다 |
| **실측 보고서** (`gateway-report-*.md`) | 게이트웨이가 규격과 다르게 행동한 것을 우리가 재어 남긴 글 | **굳는 문서다** — 그때의 값을 박고 낡지 않는다. 날짜가 이름에 있다 |
| **로컬 프록시** (`pgpt-proxy/`) | 게이트웨이의 결함을 사이에서 메우는 배관 | **남이 쓴 코드다.** 작성자 허락을 받아 싣는다 — 그 폴더 README 가 든다 |
| **회사 인증서** | 사내망 TLS 를 검증할 CA | 설치기와 뽑는 자가 태운다 |

## 사내 코딩 기준은 여기가 아니다

회사가 마련한 **FastAPI 앱 코딩 기준**은 이 폴더가 아니라 씨앗에 산다 —
`seeds/vibecoding/` 이고, 그 안의 [`SEED.md`](../seeds/vibecoding/SEED.md) 가 들머리다.

가르는 축은 **무엇에 대한 자료인가**다. 이 폴더는 *환경*을 든다(무엇이 있고 무엇이 막혔나 ·
어느 주소로 무엇이 오나). 씨앗은 *짓는 법*을 든다(어느 구조로 어느 스택으로 짜나). 그리고
그쪽은 **뽑아 오는 생성물**이라 손으로 안 고치는데, 이 폴더는 인용과 실측이 섞여 결이 다르다.

사내 앱을 짤 때는 스킬 `inhouse-app` 을 부른다 — 이 폴더의 게이트웨이 실측을 먼저 들고, 회사 방식으로 배포하는
앱일 때만 씨앗의 회사 기준을 연다(결정 0075).

## 이 폴더가 어디에 서나

| 자리 | 무엇 |
|---|---|
| `claude-config/posco/` | **진본.** 여기서 고친다 |
| `~/.claude/posco/` | 로드 자리 — 저장소가 없는 기계에서도 같은 좌표가 서게(결정 0034) |
| 설치본(PAISetup) | 받는 사람 홈에 깔린다. 설치기가 프록시와 인증서를 실제로 쓴다 |

⚠ **로드 자리는 사본이다.** 진본을 고친 뒤 배포를 안 돌리면 낡는데,
`scripts/check-global-copies.sh` 가 그 어긋남을 문다.

⚠ **이 폴더는 배포에서 폴더째 실린다.** 새 파일을 여기 두면 다음 배포에 조용히 나간다 —
사내 좌표가 들었다면 그것이 밖으로 나가는 것이 맞나를 두기 전에 묻는다.
