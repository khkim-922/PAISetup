설치 창에서 고른 프로그램 말고도, 일하는 데 쓰는 도구를 함께 깔아 둡니다. 무엇을 할 수 있게 되는지만 짧게 적었습니다.

사내에서 쓰는 도구Claude 나 Codex 를 고르면

Claude Code 가 막히는 자리를 미리 막고, 회사 문서와 사내 앱 일을 바로 할 수 있게 합니다. Codex 를 고르면 그림 문 · DRM 길잡이 · 두 안전 훅과 DRM 문서 읽기 · 사내 앱 만들기를 Codex 에도 같이 겁니다.

그림 문 image-gate스크린샷이나 큰 그림을 Claude 에 보내기 전에 크기를 잽니다. 너무 크면 막고 줄여서 다시 열게 해, 그림 한 장에 대화가 멈추지 않습니다.
웹 다시 찾기 web-retry웹 검색이나 웹 가져오기가 실패하면, 이 PC 에서 쓸 수 있는 다른 길(curl · Tavily · agy)을 결과 옆에 알려 줍니다. 막지는 않습니다.
DRM 길잡이 drm-guide회사 DRM 이 걸린 오피스 · PDF 를 붙이거나 경로를 적으면, Claude 가 그 파일을 DRM 문서 읽기(drm-office-read)로 열도록 길을 알려 줍니다. DRM 이 안 걸린 파일에는 아무것도 붙이지 않습니다.
Bash 겹역슬래시 차단 bash-backslash-deny윈도우에서 Bash 로 보낸 명령의 겹역슬래시는 셸에 닿기 전에 하나로 접혀 엉뚱한 경로가 됩니다. 그런 명령을 실행 전에 돌려보내 다시 짓게 합니다.
PowerShell 한글 지키기 utf8-bom윈도우 파워셸 5.1 은 BOM 없는 스크립트의 한글을 깨뜨려 읽습니다. 고친 .ps1 에 BOM 을 찍어 둡니다.
Tavily 웹 검색 tavily-search웹 검색 도구를 하나 더 붙입니다. 무료 키(TAVILY_API_KEY)를 넣으면 한 달 1,000회까지 씁니다. 무료 키 받기
문서 스킬 document-skills워드 · 엑셀 · 파워포인트 · PDF 를 읽고 만듭니다. Anthropic 공식 스킬을 공식 통로로 받습니다.
DRM 문서 읽기 drm-office-read회사 DRM 이 걸린 오피스 · PDF 에서 글자를 뽑습니다. 만든 슬라이드를 화면으로 떠서 넘친 곳도 봅니다.
사내 앱 만들기 inhouse-app회사 디지털혁신그룹이 배포한 사내 앱 기준을 설명해 주는 스킬입니다. 사내 LLM 게이트웨이 · SSO · 배포를 붙일 때 그 기준에서 필요한 장만 골라 엽니다.

agy 에게 맡기기Claude 나 Codex 와 안티그래비티를 같이 고르면

오래 걸리는 일은 agy(구글 제미나이)에게 뒤에서 맡기고, Claude 와는 하던 대화를 이어 갑니다.

뒤에서 맡기기 agy-background큰 파일 읽기 · 여러 파일 훑기 · 긴 조사를 agy 에게 넘깁니다. 끝나면 Claude 가 결과를 거둬 옵니다.
막히면 다음 모델로한도에 걸리거나 서버가 몰리면 다음 모델로 다시 띄웁니다. 사외는 제미나이를 먼저 쓰고 마지막에 Claude 로, 사내는 회사 키가 받는 모델을 일의 무게로 골라 씁니다.
구글 무료 API 키 GOOGLE_API_KEY사외에서 로그인 한도가 차도 제미나이를 더 쓰게 해 줍니다. Google AI Studio 에서 API 키를 만들고, 새 터미널에서 setx GOOGLE_API_KEY <키> 를 친 뒤 앱을 다시 엽니다.

Codex · Copilot 에게 맡기기Claude 와 Codex 를 같이 고르면

긴 조사 · 리뷰 · 다른 모델의 의견을 Codex 에게 뒤에서 맡기고, Claude 와는 하던 대화를 이어 갑니다. Claude 의 맥락을 그만큼 아낍니다.

뒤에서 맡기기 codex-copilot-background긴 조사 · 큰 코드 읽기 · 분석 · 리뷰 · 웹 조사를 Codex 에게 넘기고, 끝나면 Claude 가 답을 거둬 옵니다. 맡긴 쪽은 읽기만 하고 파일은 안 고칩니다.
자리마다 맞춰 돌기사외에서는 Codex 가 실시간으로 웹을 검색하고, Codex 한도가 차면 Copilot 이 받습니다(Copilot CLI 는 Copilot 을 고르면 깔립니다). 사내에서는 Codex 가 회사 게이트웨이로 가고, 웹 검색도 사내 프록시가 게이트웨이로 잇습니다.
사외는 로그인 한 번씩터미널에서 codex login(ChatGPT 계정)과 copilot login(GitHub 계정)을 한 번씩 칩니다. 사내 Codex 는 회사 키로 서서 로그인이 없습니다.
거꾸로 — Codex 에서 Claude 에게 claude-backgroundCodex 를 쓰다가 리뷰 · 조사 · 다른 모델의 의견을 Claude 에게 넘깁니다. 받는 Claude 는 읽기만 하고, 고치는 일은 Codex 가 합니다.

사내에서만회사 망 안에서

사내에서는 Claude · Gemini · 안티그래비티가 회사 키 하나로 게이트웨이에 붙습니다. PC 안의 작은 프록시가 그 사이에 서서, 게이트웨이가 그대로는 못 받는 요청을 고쳐 넘깁니다.bug fix

Opus 5 · 1M 컨텍스트 claude-opus-5[1m]Claude Code 는 회사 게이트웨이를 거치면 100만 토큰을 믿지 않고 창을 20만으로 잡았습니다. 모델 이름에 [1m] 표시를 붙여 100만 토큰 창으로 엽니다. /model 의 다른 Claude 모델도 같습니다.
Opus 5 요청 거절 prefill게이트웨이(Bedrock)는 대화 끝에 Claude 가 미리 채운 답이 붙은 요청을 거절해(400), Opus 5 로 일을 못 했습니다. 프록시가 그 부분을 떼고 넘깁니다.
없는 모델 이름Claude Code 가 곁일에 부르는 Haiku 와 기본 Sonnet 이름이 게이트웨이에 없어, 그 호출이 실패했습니다. 프록시가 게이트웨이에 있는 Sonnet 으로 바꿔 넘깁니다.
웹 검색 WebSearchClaude 요청은 회사 게이트웨이를 거쳐 AWS Bedrock 에서 도는데, 거기서는 Claude Code 의 웹 검색이 지원되지 않아 사내에서는 늘 빈손이었습니다. 프록시가 그 자리를 게이트웨이의 제미나이 검색으로 채워, 출처가 달린 결과가 옵니다.
웹 가져오기 WebFetch페이지를 받기 전에 그 주소가 안전한지 Anthropic 에 묻는데, 사내 망이 그 확인을 끊어 열리는 주소도 못 가져왔습니다. 그 확인을 건너뛰게 해 본문을 가져옵니다.
그림 보기 Read파일로 연 그림을 게이트웨이가 조용히 버려, 사내에서는 Claude 가 그림을 못 봤습니다. 프록시가 그림을 게이트웨이가 읽는 자리로 옮겨 넘깁니다.
생각하다 끊김게이트웨이는 Claude 가 생각하는 동안 아무것도 흘리지 않아, Claude Code 가 연결이 죽은 줄 알고 끊었습니다. 프록시가 15초마다 살아 있다는 신호를 흘리고, 답 길이를 게이트웨이 시간 제한 안으로 맞춥니다.
개인 키 새는 것PC 에 개인 Anthropic 키가 있으면 Claude Code 가 그 키를 회사 키와 함께 보내, 암호화 안 된 사내 연결로 게이트웨이까지 갔습니다. 프록시가 개인 키를 떼고 넘깁니다.
늘 켜진 프록시 PGPTProxy-Watchdog프록시가 꺼지면 위 고침이 다 멈춥니다. 로그인할 때 감시 작업이 프록시를 띄우고, 꺼지면 다시 살립니다.
