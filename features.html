설치하면 생기는 기능

설치 창에서 고른 프로그램이 묻지 않고 바로 일하게 맞춰 두고, 일하는 데 쓰는 도구도 함께 깔아 둡니다. 무엇을 할 수 있게 되는지만 짧게 적었습니다.

묻지 않고 일하기 사내에서 쓰는 도구 다른 도구에게 맡기기 사내에서만 씨앗과 사내 문서 설치할 때마다 제작자 칸을 켜면

고른 도구는 묻지 않고 일합니다Claude · Codex · 안티그래비티 · Copilot 가운데 고르면

도구는 명령을 돌리거나 파일을 고치기 전에 「해도 될까요」를 묻곤 하고, 누가 눌러 줄 때까지 일이 멈춥니다. 그래서 고른 도구마다 그 도구 자신의 「묻지 않음」 설정을 심어 둡니다 — 그 도구의 설정 화면에 그대로 보이고 거기서 되돌립니다. 이미 정해 둔 값은 건드리지 않고, 다른 값으로 바꿔 두면 다음 설치도 덮지 않습니다(Codex 데스크탑 앱만 다릅니다 — 아래).

Claude Code · 자동 모드위험해 보이는 동작은 분류기가 따로 가르고, 나머지는 묻지 않고 진행합니다.
Codex · 나 대신 승인작업 폴더 밖에 쓰는 것처럼 울타리(샌드박스)를 넘는 요청은 사람 대신 검토 모델이 승인하거나 거절합니다. 사외 PC 의 Codex CLI 와 데스크탑 앱에 섭니다(사내 Codex 는 묻던 대로 묻습니다). 데스크탑 앱은 새로 깐 뒤 대개 묻는 채로 시작합니다 — 앱의 샌드박스 설정을 마친 뒤 설치를 다시 돌려 Codex 를 껐다 켜는 데 동의하면 「나 대신 승인」이 되고, 그 뒤 앱에서 다른 값을 골라도 그렇게 동의할 때마다 다시 이 값으로 돌아갑니다.
agy · 묻지 않고 진행agy CLI 는 도구를 쓸 때마다 묻던 것을 묻지 않고 진행하고, 안티그래비티 앱에도 Turbo 설정을 심어 둡니다. 위험을 가르는 판단은 없습니다 — 감긴 회사 문서를 여는 것만 DRM 길잡이가 그대로 막습니다.
Copilot CLI · Allow All · Autopilot도구를 묻지 않고 쓰고, 새 대화는 Autopilot 으로 시작해 첫 요청에서 일을 끝까지 스스로 이어 갑니다 — 그만큼 AI 크레딧을 씁니다. 위험을 가르는 판단도, 우리가 거는 안전장치도 없습니다. Copilot 데스크탑 앱의 권한은 앱이 정한 그대로입니다.

사내에서 쓰는 도구Claude · Codex · 안티그래비티 가운데 고르면

Claude Code 가 막히는 자리를 미리 막고, 회사 문서와 사내 앱 일을 바로 할 수 있게 합니다. Codex 를 고르면 그림 문 · DRM 길잡이 · 두 안전 훅과 DRM 문서 읽기 · 사내 앱 만들기를 Codex 에도 같이 겁니다. 안티그래비티를 고르면 agy 도 Codex 와 같은 스킬을 받고, DRM 길잡이 · PowerShell 한글 지키기를 겁니다 — agy 에서는 DRM 이 걸린 파일을 열거나 셸 명령으로 읽으려는 순간 막고 읽는 길을 알려 줍니다.

그림 문 image-gate스크린샷이나 큰 그림을 Claude 에 보내기 전에 크기를 잽니다. 너무 크면 막고 줄여서 다시 열게 해, 그림 한 장에 대화가 멈추지 않습니다.
웹 다시 찾기 web-retry웹 검색이나 웹 가져오기가 실패하면, 이 PC 에서 쓸 수 있는 다른 길(curl · Tavily · agy)을 결과 옆에 알려 줍니다. 막지는 않습니다.
DRM 길잡이 drm-guide회사 DRM 이 걸린 오피스 · PDF 를 붙이거나 경로를 적으면, Claude 가 그 파일을 DRM 문서 읽기(drm-office-read)로 열도록 길을 알려 줍니다. DRM 이 안 걸린 파일에는 아무것도 붙이지 않습니다.
Bash 겹역슬래시 보정 bash-backslash-deny윈도우에서 Bash 로 보낸 명령의 겹역슬래시는 셸에 닿기 전에 하나로 접혀 엉뚱한 경로가 됩니다. 그런 명령의 역슬래시를 미리 두 배로 늘려 쓴 그대로 닿게 합니다. 접힘을 아직 안 잰 새 Claude Code 판에서는 돌려보내 다시 짓게 합니다.
PowerShell 한글 지키기 utf8-bom윈도우 파워셸 5.1 은 BOM 없는 스크립트의 한글을 깨뜨려 읽습니다. 고친 .ps1 에 BOM 을 찍어 둡니다.
문서 스킬 document-skills워드 · 엑셀 · 파워포인트 · PDF 를 읽고 만듭니다. Anthropic 공식 스킬을 공식 통로로 받습니다.
DRM 문서 읽기 drm-office-read회사 DRM 이 걸린 오피스 · PDF 에서 글자를 뽑습니다. 만든 슬라이드를 화면으로 떠서 넘친 곳도 봅니다.
사내 앱 만들기 inhouse-app회사 디지털혁신그룹이 배포한 FastAPI 사내 앱 기준 문서를 읽어 주는 스킬입니다. 사내 앱에 LLM 게이트웨이 · SSO · 배포를 붙일 때 그 기준에서 필요한 장만 골라 엽니다.

다른 도구에게 맡기기맡기는 법은 늘 · 러너는 맡기는 쪽과 받는 쪽을 같이 고르면

오래 걸리는 일 · 리뷰 · 다른 모델의 의견을 다른 도구에게 뒤에서 맡기고, 하던 대화를 이어 갑니다. 두 층입니다 — 맡기는 법이 일을 가르고 작업 지시서를 짓고 결과를 거두며, 받는 도구마다 있는 러너가 실제로 띄웁니다. 러너는 맡기는 쪽에만 깔려, 받는 도구가 제게 되맡기는 길은 생기지 않습니다.

맡기는 법 agent-envelope누구에게 맡길지 고르고, 받는 쪽이 읽을 작업 지시서를 짓고, 돌아온 결과를 확인해 거둡니다. 어느 도구를 고르든 깔리고, Claude 안의 서브에이전트에게 맡길 때도 이 절차를 씁니다. 아래 러너 셋은 이 스킬이 부르는 손입니다.

설치할 때마다 다시 맞춥니다다시 누르거나 로그온 자동 실행이 돌 때

깔린 것을 새 판으로 올리고 환경을 다시 맞추는 일은 설치가 돌 때마다 되풀이됩니다. 설치 창에서 내 저장소를 받으면 그 저장소도 이때 손봅니다.

로그온할 때 저절로설치 창의 로그온 자동 실행 칸은 기본으로 켜져 있습니다. 켜 둔 동안은 로그온할 때마다 설치 창이 떠서 이 일을 하고, 설치본도 새 판이 있으면 그 판으로 올라갑니다. 칸을 끄면 설치를 다시 누를 때만 합니다.
처음 열어도 안 묻는 저장소설정 저장소를 받으면설정 저장소와, 그 저장소가 설정을 깔아 둔 같이 쓰는 저장소는 고른 도구(Claude Code · Codex · agy · Copilot CLI)와 VS Code 가 처음 열 때 「이 폴더를 믿나」를 묻지 않습니다. Codex 데스크탑 앱에는 프로젝트로도 올려 둡니다. 다른 폴더는 그대로 묻고, VS Code 나 앱이 떠 있으면 다음 설치로 미룹니다.
옛 판 우리 파일은 지금 판으로받은 저장소 · 제작자 칸을 켜면 repos 의 다른 저장소도예전 설치가 저장소에 깔아 둔 우리 파일(세션 훅 등)이 옛 판이면 지금 판으로 갈아 둡니다 — 옛 판은 설치가 깐 것을 제 사본으로 덮어 버립니다. 작업 폴더에만 쓰고 커밋은 안 하며, 설치 기록의 「우리 파일을 지금 판으로 갈았다」 줄이 바뀐 파일과 되돌리는 명령을 댑니다. 고쳐 커밋해 둔 것도 갈지만 옛 판은 git 에 남고, 커밋 안 한 손질이 걸리면 그 저장소는 건드리지 않습니다.

제작자 칸을 켜면설치 창의 「제작자의 … 깝니다」 — 도구마다 고른다

만든 사람이 일하는 방식입니다. Claude · Codex · agy 가운데 받을 도구만 켭니다 — Claude 만 받고 나머지는 가볍게 써도 됩니다. 안 켜도 설치는 완전합니다. 설치 창에 내 설정 저장소 주소를 넣으면 같은 칸이 그 저장소의 규범 · 룰 · 스킬을 고른 도구에 보냅니다. 판마다 바뀐 것은 그 판의 릴리스 노트가 적습니다 — 설치 창의 「바뀐 것」 링크가 엽니다.

규범 · 룰생각하고, 글 쓰고, 코드를 고칠 때의 원칙입니다. Claude 가 세션마다 읽고, 룰은 코드나 문서를 만질 때만 걸립니다.
