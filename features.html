일하는 데 쓰는 도구Claude 를 고르면

Claude Code 가 막히는 자리를 미리 막고, 회사 문서와 사내 앱 일을 바로 할 수 있게 합니다.

그림 문 image-gate스크린샷이나 큰 그림을 Claude 에 보내기 전에 크기를 잽니다. 너무 크면 막고 줄여서 다시 열게 해, 그림 한 장에 대화가 멈추지 않습니다.
웹 다시 찾기 web-retry웹 검색이나 웹 가져오기가 실패하면, 이 PC 에서 쓸 수 있는 다른 길(curl · Tavily · agy)을 결과 옆에 알려 줍니다. 막지는 않습니다.
Tavily 웹 검색 tavily-searchClaude 가 쓸 웹 검색 도구를 하나 더 붙입니다. 키 없이는 검색과 본문 읽기만 되고, 무료 키를 넣으면 한 달 검색 1,000회까지 쓰고 사이트 지도 · 크롤 · 리서치도 열립니다. 받은 키는 환경변수 TAVILY_API_KEY 에 넣습니다. 무료 키 받기
문서 스킬 document-skills워드 · 엑셀 · 파워포인트 · PDF 를 읽고 만듭니다. Anthropic 공식 스킬을 공식 통로로 받습니다.
DRM 문서 읽기 drm-office-read회사 DRM 이 걸린 오피스 · PDF 에서 글자를 뽑습니다. 만든 슬라이드를 화면으로 떠서 넘친 곳도 봅니다.
사내 앱 만들기 inhouse-app회사 디지털혁신그룹이 배포한 사내 앱 기준을 설명해 주는 스킬입니다. 사내 LLM 게이트웨이 · SSO · 배포를 붙일 때 그 기준에서 필요한 장만 골라 엽니다.

agy 에게 맡기기Claude 와 안티그래비티를 같이 고르면

오래 걸리는 일은 agy(구글 제미나이)에게 뒤에서 맡기고, Claude 와는 하던 대화를 이어 갑니다.

뒤에서 맡기기 agy-background큰 파일 읽기 · 여러 파일 훑기 · 긴 조사를 agy 에게 넘깁니다. 끝나면 Claude 가 결과를 거둬 옵니다.
막히면 다음 모델로한도에 걸리거나 서버가 몰리면 다음 모델로 다시 띄웁니다. 사외는 제미나이를 먼저 쓰고 마지막에 Claude 로, 사내는 회사 키가 받는 모델을 일의 무게로 골라 씁니다.

사내에서만회사 망 안에서

사내에서는 Claude · Gemini · 안티그래비티가 회사 키 하나로 게이트웨이에 붙습니다. PC 안의 작은 프록시가 그 사이에 서서, 게이트웨이가 그대로는 못 받는 요청을 고쳐 넘깁니다.

Opus 5 · 1M 컨텍스트 claude-opus-5[1m]사내에서는 Claude Code 가 대화 창을 20만 토큰으로 줄여 썼습니다. 게이트웨이는 100만까지 받으므로, 모델 이름을 맞춰 100만 토큰 창으로 엽니다. /model 의 다른 Claude 모델도 같습니다.
웹 검색 WebSearchClaude 요청은 회사 게이트웨이를 거쳐 AWS Bedrock 에서 도는데, 거기서는 Claude Code 의 웹 검색이 지원되지 않아 사내에서는 늘 빈손이었습니다. 프록시가 그 자리를 게이트웨이의 제미나이 검색으로 채워, 출처가 달린 결과가 옵니다.
웹 가져오기 WebFetch페이지를 받기 전에 그 주소가 안전한지 Anthropic 에 묻는데, 사내 망이 그 확인을 끊어 열리는 주소도 못 가져왔습니다. 그 확인을 건너뛰게 해 본문을 가져옵니다.
그림 보기 Read파일로 연 그림을 게이트웨이가 조용히 버려, 사내에서는 Claude 가 그림을 못 봤습니다. 프록시가 그림을 게이트웨이가 읽는 자리로 옮겨 넘깁니다.
키 하나로 셋Gemini CLI 와 안티그래비티도 같은 회사 키로 붙습니다. 키는 한 번만 넣습니다.
늘 켜진 프록시 PGPTProxy-Watchdog프록시가 꺼지면 위 고침이 다 멈춥니다. 로그인할 때 감시 작업이 프록시를 띄우고, 꺼지면 다시 살립니다.

씨앗과 사내 문서누구에게나

씨앗은 불러 쓰는 라이브러리가 아니라, 폴더를 내 프로젝트에 복사하면 그때부터 내 것이 되는 견본입니다. ~/.claude/seeds/ 아래에 깔립니다.

설정 저장소 config-repo내 Claude Code 설정을 git 저장소로 들고 다니는 견본입니다. 새 PC 에서 설정과 여러 저장소를 한 번에 깔아 줍니다. 만드는 법
