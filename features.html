설치 뒤 할 일

설치가 대신 못 하는 것은 로그인뿐입니다. 사내와 사외가 다릅니다.

사내 회사 PC · 회사 망 — 로그인이 없습니다
  • 설치 창에 회사 키를 넣으면 끝입니다. 고른 도구가 그 키 하나로 회사 게이트웨이에 붙습니다.
  • 데스크탑 앱은 깔리지 않습니다. VS Code 와 터미널로 씁니다.
사외 집 · 밖 · 개인 PC — 뜬 창마다 한 번씩

설치가 끝나면 고른 도구의 앱 창을 띄웁니다. 뜬 창마다 한 번씩 로그인하면 됩니다 — Codex 는 「ChatGPT」 창으로 뜨고, 그 로그인을 터미널 · VS Code 의 Codex 도 함께 씁니다.

따로 한 번 더 하는 것

  • Claude Code(터미널 · VS Code) — 설치 중에 뜨는 브라우저에서 구독 계정으로. 앱 로그인과 따로입니다.
  • agy — Claude · Codex 가 agy 에게 일을 맡기는 조합이면 터미널에서 agy 를 한 번 띄웁니다.
  • Copilot CLI — gh auth login 한 번. GitHub 로그인을 그대로 씁니다.
