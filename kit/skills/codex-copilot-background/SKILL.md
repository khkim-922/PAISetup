# Codex · Copilot 에게는 백그라운드로 맡긴다

띄워 두고 대화를 잇다가, 끝나면 알림으로 답을 거둔다. 부르는 길은 이 스킬의 래퍼 하나다. **Codex 는 이 대화를
모르니 프롬프트가 일의 전부다** — 무엇을 맡기고 어떻게 쓰나는 agent-envelope 가 든다.

**기본은 읽기만 하니 저장소를 통째로 가리켜도 된다** — Codex 는 읽기 전용 샌드박스에 앱 · 플러그인 · MCP 도구를 끄고
승인을 `never` 로 박아(사람 설정의 검토자가 샌드박스 밖 요청을 못 연다), Copilot 은 파일 읽기 · 웹 읽기 도구만 열고 뜬다. 고칠 것은 답으로 받아 맡긴 쪽(Claude · agy)이 고치거나, 아래 고치기
레인으로 맡긴다.

## 고치기 레인 — `--write`

봉투가 고치기를 맡기기로 골랐을 때만 준다(agent-envelope). **작업 자리(`--cwd`) 안만 고친다** — 시스템 임시
폴더(`%TEMP%`) 밑의 다른 자리도 못 쓴다. 가두는 법과 쪽마다 덧붙는 자리 하나는 아래와 같다.

- **Codex** — 쓰기 샌드박스(`workspace-write`)로 뜨되 임시 폴더 변수(`TEMP` · `TMP` · `TMPDIR`)를 래퍼가 그 실행에만
  세우는 빈 폴더로 돌리고 `/tmp` · 덧붙인 쓰기 자리는 끄며, 끝나면 그 폴더를 지운다 — 그 빈 폴더에도 쓴다. 셸의 망은
  닫혀 있고, 앱 · 플러그인 · MCP 는 그대로 꺼진다
- **Copilot** — 편집 도구를 더 열고 쓰기를 허락하되, 작업 자리 밖에 쓰려는 호출은 Copilot 의 경로 검사가 거절한다.
  임시 폴더는 그 허락에서 뺀다. **셸은 안 열린다** — 검사 돌리기는 맡긴 쪽이 한다. 예외 하나 — Copilot 이 실행마다
  제 홈에 세우는 세션 폴더(`~/.copilot/session-state/<id>/`)에는 쓴다

- **작업 자리를 따로 세워 `--cwd` 로 준다** — 본 트리를 주면 그 트리를 고친다. `--cwd` 없이는 안 뜬다(4)
- **Codex 가 한도면 Copilot 이 고치기 레인으로 받는다** — 차례(`CC_BG_AGENTS`)를 그대로 따른다. `--agent copilot` 으로
  처음부터 Copilot 에게 줄 수도 있다
- **이어 물을 때도 `--write` 를 다시 준다** — 안 주면 같은 대화가 읽기 레인으로 이어진다
- 끝나면 맡긴 쪽이 그 자리의 diff 를 읽고 검사를 돌린다. 커밋 · 푸시 · 이슈는 맡긴 쪽이 한다

## 자리 값

자리마다 다른 값은 설치기가 심는 환경변수(`CC_BG_*`)이고 래퍼가 읽는다.

- **모델은 래퍼가 고른다** — `--model` 이 없으면 맡기기 모델(`CC_BG_CODEX_MODEL_DELEGATE`)을 먼저, 없으면 기본 모델
  (`CC_BG_CODEX_MODEL`)을 쓰고, 둘 다 없으면 Codex 설정의 모델로 뜬다. 추론이 안 드는 일(훑기 · 찾기 · 요약)은
  `--model "$CC_BG_CODEX_MODEL"` 로 준다 — 빈 값은 안 준 것과 같다. `--model` 은 Codex 에만 가고 Copilot 은 제 모델로 뜬다.
  자리마다 어느 무게에 어느 모델을 대나는 맡기기 스킬 폴더의 모델 표 [`models.conf`](../agent-envelope/models.conf) 가 들고,
  설치기가 그 표에서 두 값을 심는다.
- **웹 검색은 자리 값 `CC_BG_CODEX_WEB_SEARCH` 가 켜고 끈다** — `disabled` 인 자리의 Codex 는 웹을 못 보니, 거기서
  웹이 드는 조사는 Claude 서브에이전트나 agy 에게 맡긴다.
- 사내 게이트웨이는 답 하나를 요청부터 180초에 끊는다 — 사내에서는 긴 정리를 한 번에 시키지 말고 나눠 맡긴다.

## 맡기는 법

1. **프롬프트를 UTF-8 파일로 쓴다**(스크래치패드). 길이는 자유다 — 래퍼가 표준 입력으로 넘긴다. 다른 인코딩이면
   래퍼가 4 로 돌려보낸다.
2. **Claude 에서는 Bash 를 `run_in_background: true` 로 부르고, `pythonw` 로 띄운다** — 창 없이 돈다. 윈도 밖에서는 `python3` 로 부른다.

   ```sh
   pythonw "<이 스킬 폴더>/scripts/codex_copilot_bg.py" --prompt-file <프롬프트> --out <답 파일> --cwd <작업 자리> \
     [--timeout <초>] [--agent codex|copilot] [--resume <쪽>:<id>] [--write] [--model <이름>]
   ```

   **agy 에서는 같은 명령을 콘솔 있는 `python` 으로 부르고 끝날 때까지 기다린다** — `pythonw` 는 창 없는 프로그램이라
   셸이 안 기다리고 바로 돌아온다. 명령의 기다림(`WaitMsBeforeAsync`)은 `--timeout` 보다 길게 주고, 뒤로 넘어가면 그
   작업이 끝날 때까지 상태를 본 뒤 `--out` 을 읽는다. 승인 건너뛰기 없이 뜬 헤드리스 agy(`agy -p`)에서는 이 명령이
   자동 거절된다 — 권한 설정을 고쳐 뚫지 말고 거절됐다고 알리고 멈춘다. 헤드리스로 맡기는 길은 부르는 쪽이
   `--dangerously-skip-permissions` 를 붙여 띄운 agy 뿐이다(`agy-background` 러너의 꼴 · 결정 0114).

3. **끝나면 `--out` 파일을 읽는다.** 끝 줄 `[cc-bg] <갈래> …` 이 레인(`mode=read|write`) · 맡은 쪽(`agent=`) · Codex 에 넘긴 모델(`model=` ·
   안 넘겼거나 Copilot 이면 `-`) · 넘어간 자취 · Codex 가 마친 웹 검색 수
   (`web=` · Copilot 은 `-`) · 이어 묻기 값(`resume=`)을 든다. 인자가 틀렸거나 래퍼가 멈췄어도 `--out` 을 줬으면 그 파일에
   까닭과 끝 줄이 남는다.

   | 종료 코드 | 뜻 |
   |---|---|
   | 0 | 답이 왔다 |
   | 1 | 실패 — 래퍼가 멈춘 것도 여기다. 끝 줄 위의 까닭과 `raw=` 경로를 본다 |
   | 2 | 한도(받을 쪽까지 다) 또는 빈 답 |
   | 3 | 시간 초과 |
   | 4 | 부르는 법이나 자리 값이 틀렸거나, 깔린 쪽 · 이 자리에서 쓰는 쪽이 없다 |

4. **이어 물을 때**는 끝 줄의 `resume=` 값을 그대로 `--resume` 으로 준다 — 그 대화가 있는 쪽에서 잇는다. 끝 줄 `model=` 이
   `-` 가 아니면 그 이름도 `--model` 로 준다 — 안 주면 래퍼가 맡기기 모델로 잇는다. 그쪽 대화
   기록이 안 남은 실행은 `resume=-` 에 까닭을 달고 끝난다 — 그때는 새로 맡긴다.
5. **판 번호 · 날짜처럼 시점에 매인 답은 근거 URL 을 열어 맞춰 본 뒤에 쓴다** — 묵은 페이지를 물고 온 답도 말투는
   확신에 차 있다. Codex 가 웹으로 가는 길은 검색 도구 하나라, `web=0` 인 답은 기억으로 낸 것이다 — 사실은 다시 찾아 쓴다.

## 누가 받나

- **차례는 자리 값 `CC_BG_AGENTS` 다**(없으면 Codex → Copilot). 여기 없는 쪽은 `--agent` · `--resume` 으로도 안 띄운다(4)
- **Codex 가 한도(사용 한도 · 할당량 · 용량 초과)에 걸리면 다음 쪽이 받는다** — Copilot 은 검색 없이 주소를 짐작해 열어서,
  공식 문서처럼 길이 뻔한 조사에 맞는다. 다른 실패와 시간 초과는 그 자리에서 멈추고 까닭을 남긴다
- 깔린 쪽만 차례에 든다
- **로그인은 사람이 한 번 한다** — 인증 실패로 멈추면 그쪽 명령(`codex login` · `copilot login`)을 터미널에서 한 번 치게
  알린다. API 키로 붙는 자리는 로그인이 없다

## 작업 자리

- 조사만 시킬 때 `--cwd` 는 스크래치패드다. 읽힐 자료는 그 폴더에 두거나 자료 폴더를 `--cwd` 로 준다 — Copilot 이
  여는 파일은 작업 자리와 임시 폴더 안이다(고치기 레인은 작업 자리 안만)
