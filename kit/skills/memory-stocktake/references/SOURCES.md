# 출처 · 견준 것

## 표준 — 앤트로픽 `consolidate-memory` 스킬

- 자리 — Claude 데스크톱이 딸려 싣는 번들 스킬(`anthropic-skills:consolidate-memory`). 사용자 설치 없이 Skill 도구로 불린다
- 본 판 — 2026-10-30 에 불러 읽은 본문. 라이선스 표시가 없어 **인용만 한다** — 바이트 보관 없음
- 요지 — 세 단계. ① 폴더와 목차를 훑어 겹침 · 낡음 · 얇음을 센다 ② 굳은 것(취향 · 일하는 법 · 관계 · 되풀이 흐름)과 날짜 지난 것
  (프로젝트 · 마감 · 일회성)을 가르고, 겹침은 합치고, 상대 날짜는 절대값으로, 다른 데서 바로 찾을 수 있는 것은 걷는다 ③ 목차를
  200 줄 · 25KB 안으로, 한 줄 150 자 안으로
- **우리가 다른 자리** — 표준은 폴더 하나(하네스의 자동 메모리 자리)만 알고 층이 없다. 우리는 전역과 저장소 둘,
  메모리 위의 층 넷(훅 · 스킬 · 룰 · 규범 — norm-design), 판정은 결정 기록으로, 목차 줄의 꼴(「걸리는 순간 → 무엇」)을 더한다.
  표준의 ② ③ 은 그대로 부른다 — 우리 본문에 다시 안 적는다. 이 셋의 까닭과 잰 값은 원본 저장소의 결정 기록이 든다
