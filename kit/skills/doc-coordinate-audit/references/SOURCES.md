# 출처 — doc-coordinate-audit

보관한 원문은 없다 — 스킬이 부르는 넷은 읽을 명세가 아니라 **깔아서 돌리는 도구**라 옮겨 둘 원문이 없다. 도구를
부르는 것 자체가 알맹이다.

## 부르는 도구

- **lychee** — `lycheeverse/lychee` · 링크 · URL · 목차 앵커
- **markdownlint** — `DavidAnson/markdownlint` · 마크다운 구조. `markdownlint-cli2` 로 부른다
- **Vale · textlint** — 산문 린터. 일은 언어별 규칙 묶음이 하므로, 내 언어의 묶음이 있을 때만 깐다
