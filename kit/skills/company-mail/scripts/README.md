# 메일 손

**회사 PC 의 스크립트 · 스킬이 사내 메일을 보내고 받는 파일들과, 그것을 무는 검사다.**

- **보내는 손** `mailer.py` — 환경변수를 하나도 안 줘도 사내망 안에서는 첫 판에 나간다. 사내 중계에서 잰 동작(인증
  없는 25 번 · 끊기는 STARTTLS 에서 평문으로 물러나기)이 기본값과 난간으로 들어 있다. 수신자를 파일로 둘 때의 꼴은
  `recipients.example.json` 이다(실제 수신자 파일은 주소가 들므로 저장소 밖에 둔다)
- **받는 손** `inbox.py` — 받은편지함 · 하위 폴더 · 보낸편지함 · 임시보관함의 목록, 웹메일 검색, 받는 사람 목록, 본문 ·
  첨부, 사내 주소록 · 조직도를
  받고, **메일의 읽음 표시를 바꾸지 않는다.** 읽음을 안 바꾸는 것으로 잰 주소만 묻고 그 밖의 주소는 서버에 닿기 전에
  막아서, 사람이 웹메일에서 열기 전까지 그 메일은 「안 읽음」으로 남는다. 로그인은 이 손이 안 든다 — 스킬
  ep-login 의 받는 손(`edge_session.js`)이 세션 쿠키 파일을 남긴다
- **메일함을 바꾸는 손** — `inbox.py` 의 읽음으로 · 안 읽음으로 · 폴더 만들기 · 지우기 · 메일 옮기기 · 휴지통에서 되살리기 ·
  메일 규칙 넣기 · 고치기 · 지우기이고, 이름 붙은 함수 하나씩이다. 사람이 그 메일 · 폴더 · 규칙을 두고 분명히 고른 뒤에만
  부른다 — 언제 부르나는 부르는 스크립트가 정한다. 규칙은 서버가 그 뒤의 새 메일에 스스로 쓰고, 자동전달 칸은 늘 빈다
- **주소록 조사 손** `directory_survey.py` — 웹메일 받는 사람 고름 창을 눌러 본 HAR 파일 하나에서, 웹메일이 주소록 · 조직에
  묻는 주소마다 질의 칸 · 답의 꼴 · 읽기 길이 이미 그 주소를 묻나를 거둔다. 서버에 묻지 않고 파일만 읽는다
- **얇은 명령** `mail.py` — 대화에서 부르는 명령. 형제 스킬 ep-login 의 `ep_session.py` 로 세션을 받은 뒤 곁의 두 손을 부른다

대화에서 쓰는 절차는 스킬 `company-mail` 이 든다. 이 폴더는 그 스킬의 명령과, 깔린 자리에서 이 손을 불러 쓰는 앱이 함께
쓰는 손이다 — 복사해 쓰는 밑판이 아니라 불러 쓰는 손이라, 공개 이름과 꼴(부르는 꼴 · 내는 것)을 바꾸면 부르는 쪽이 깨진다.
부르는 꼴 · 내는 것 · 환경변수 · 회사에서 잰 꼴과 그 출처는 `inbox.py` ·
`mailer.py` 머리말이 든다 — 여기 옮겨 적지 않는다.

## 앱에서 쓰기

1. 이 폴더를 `sys.path` 에 넣고 `import inbox` · `import mailer` 로 싣는다 — 작업 스케줄러에서 `python -I` 로 띄우면 스크립트 폴더가
   `sys.path` 에 안 서서 스크립트가 부르기 전에 제 폴더를 넣는다(`sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent))`)
2. 세션 쿠키 파일은 스킬 ep-login 의 받는 손이 남기고 그 자리를 끝 줄로 알린다 — 그 경로를 `inbox.Mailbox(url, <자리>)` 로 넘긴다.
   메일함 주소는 `inbox.discover_mailbox("http://<메일 서버>", <세션 파일>)` 가 그 세션 주인의 것을 낸다. 세션이 끊기면
   `SessionExpired` 가 나니 받는 손을 다시 부른다
3. 메일함을 바꾸는 손(`mark_read` · `mark_unread` · `create_folder` · `delete_folder` · `move_mails` · `restore_from_trash` ·
   `save_rule` · `delete_rule`)은 사람이 그 대상을 고른 자리(확인 단추 같은 것)에서만 부른다

## 돌려 보기

```bash
python -X utf8 -I check_mailer.py            # 이 폴더의 mailer.py 를 잰다 — 127.0.0.1 밖으로 안 나간다
python -X utf8 -I check_inbox.py             # 이 폴더의 inbox.py 를 잰다 — 127.0.0.1 밖으로 안 나간다
python -X utf8 -I check_mailer.py <폴더>     # 다른 폴더의 사본을 잰다(check_inbox.py 도 같다)
python -X utf8 -I check_mail.py              # 스킬의 명령 mail.py 를 잰다 — 세션 손은 대역 · node 가 든다
```

끝 줄이 「통과 N/N」이면 선 것이다. 가짜 중계 · 가짜 메일함이라 못 재는 길이 있다 — 보내기는 STARTTLS 가 실제로
서는 길, 받기는 사내 SSO 를 넘는 길(스킬 ep-login)과 회사에서 안 잰 꼴(`check_inbox.py` 머리말 「여기서 못 재는
것」). 첫 실발송 · 첫 실수신은 회사 PC 에서 제 주소로 한 통 보내 그 메일로 잰다.
