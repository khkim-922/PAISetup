# Claude 에게 맡긴다 — 쓰기는 작업 자리 안만

Codex 나 agy 가 Claude 를 부를 때의 러너다(Claude 안에서는 Agent 도구가 그 자리다). 권한은 부를 때 일에 맞춰
고른다(무엇을 줄지는 agent-envelope 2 절 「자료 · 도구」) — `--write` 가 없으면 읽기 · 찾기 · 웹 읽기 도구만 보이고 셸 · 쓰기
도구는 없다. 저장소를 통째로 가리켜도 된다. MCP · 스킬 · 훅은 끄고 뜬다(리뷰 모드는 스킬을 켠다). 이 대화를 모르니 프롬프트가
일의 전부다. **홈 CLAUDE.md 와 그 `@경로` 가져오기는 래퍼가 풀어 시스템 프롬프트로 싣는다**(끝 줄 `norms=`) — 사용자 설정을
안 싣는 띄우기에서는 하네스가 CLAUDE.md 도 안 읽어서다(실측 2026-10-15). 싣는 것은 그 PC 홈의 CLAUDE.md 에 든 것 그대로라,
제작자 칸에 claude 가 없어 설치기가 규범 가져오기를 안 쓴 PC 에서는 규범도 안 실린다 — 대화형 Claude 가 그 PC 에서 읽는 것과
같다. 파일 경로에 걸리는 룰은 안 온다.

## 부르는 꼴

프롬프트를 파일로 쓰고 이 스킬의 래퍼 하나로 띄운다. 받는 인코딩 · 플래그 · 끝 줄의 칸 · 종료 코드 · 이어 묻기는 래퍼의
도움말이 든다:

    python "<이 스킬 폴더>/scripts/claude_bg.py" --help

- 콘솔 있는 `python` 으로 부르고 끝날 때까지 기다린다 — 명령의 시간 한도는 `--timeout` 보다 길게 준다(`pythonw` 는 셸이 안
  기다린다).
- **Codex 에서는 샌드박스 밖에서 돌린다** — 셸 호출에 `sandbox_permissions: "require_escalated"` 와 허락을 묻는 한
  줄(`justification`)을 싣는다. 받는 Claude 는 망이 있어야 답하고, 샌드박스 안에서는 제 홈에 대화 기록을 못 써 이어 묻기가 안
  선다. 승인 정책이 `never` 인 자리(`codex exec` 기본)에서는 `-c sandbox_workspace_write.network_access=true` 로 띄워야 답이
  오고 그래도 이어 묻기는 안 선다(결정 0098).
- **agy 에서는** 명령의 기다림(`WaitMsBeforeAsync`)을 `--timeout` 보다 길게 주고, 뒤로 넘어가면 끝난 뒤 `--out` 을 읽는다.
  승인 건너뛰기 없이 뜬 헤드리스 agy(`agy -p`)는 이 명령을 자동 거절한다 — 뚫지 말고 거절됐다고 알리고 멈춘다(결정 0114).

## 고치기 레인 — `--write`

고치기뿐 아니라 리뷰 · 재기처럼 돌려 보고 적어 봐야 하는 일에도 준다. 편집 도구 둘(`Edit` · `Write`)이 더 보이되 허락은
작업 자리(`--cwd`) 안에만 걸려, 밖에 쓰려는 호출은 거절되고 실패(1)로 남는다. 사람 설정의 허락 규칙은 어느 레인에도 안
넘어간다 — 레인의 울타리는 래퍼가 건 허락이 다다.

- **셸은 고치기 레인에도 없다** — 이 러너의 「재 볼 손」은 사본에 적어 보기까지다. 명령을 돌려 재야 하는 리뷰는 셸이 있는
  쪽(Claude 서브에이전트 · Codex 고치기 레인)에 맡기고, 검사 돌리기는 맡긴 쪽이 한다. 윈도에는 Claude 샌드박스가 없어 셸이
  자리를 못 지킨다.
- 작업 자리를 따로 세워 `--cwd` 로 준다 — 본 트리를 주면 그 트리를 고친다. 이어 물을 때도 `--write` 를 다시 준다.

## 리뷰 모드 — `--review [대상] [--max-findings <n|all>]`

내장 리뷰 스킬(`/code-review`)을 `medium` 으로 부른다 — 후보마다 검증 에이전트가 맞나를 가르고 0건도 답이다. 여는 것은 그
스킬이 드는 만큼: 스킬을 켜고, 셸과 검증 에이전트를 띄울 `Agent` 를 보인다. 셸은 Claude Code 가 읽기로 가르는 명령(`git diff`
· `git log` · `cat` · `grep` 같은)만 서고 코드 돌리기 · 파일로 내보내기(`git diff --output=<파일>` 포함)는 거절된다 — 그 거절은
울타리가 한 일이라 실패로 안 치고 끝 줄 `denied=<도구>:<수>` 로 남긴다.

- **봉투는 프롬프트 파일 그대로 준다** — 래퍼가 시스템 프롬프트 덧붙이기로 넘긴다(슬래시 명령 뒤에 붙인 글은 리뷰 대상으로
  읽힌다). 대상은 그 스킬의 낱말(PR 번호 · 가지 · 경로)이고 안 주면 지금의 diff 다. `--fix` · `--comment` · `ultra` 는 안 싣는다.
- **모델은 `--model` 로 준다** — 깊은 리뷰면 [`models.conf`](../agent-envelope/models.conf) 의 모델을.
- `--write` · `--resume` 과 같이 못 준다(4) — 리뷰는 읽기만 하는 새 대화다. 더 물을 때는 `--review` 없이 `resume=` 값으로 잇는다.

## 자리

- Claude Code CLI(`claude`)가 이 PC 에 서 있어야 한다. 사외는 구독 로그인으로, 사내는 설치기가 심은 게이트웨이 값으로 붙는다 —
  래퍼는 사용자 설정을 읽어 그 값을 그대로 쓴다. 인증 실패로 멈추면 터미널에서 `claude` 를 한 번 띄워 로그인하게 알린다.
- 맡긴 대화는 Claude Code 의 대화 기록(`~/.claude/projects`)에 남아 이어 묻기가 선다.
- **사실은 쓴 도구로 가린다** — 끝 줄 `tools=` 에 읽기 · 검색이 없는 답은 기억으로 낸 것이다.
