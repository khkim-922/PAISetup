# 검사 결과를 그대로 믿지 않는다

기계가 못 재는 것은 사람이 재고, 보고 겪는 것이 본질인 일은 그 눈이 첫 판정이다.

- **초록은 「없다」가 아니라 「본 데까지는 없다」다.** 어디까지 봤고 무엇을 안 봤는지를 판정 옆에 적는다.
- **초록이 무엇과 견준 초록인가를 본다** — 검사가 있다는 것과 그것이 재려던 것을 잰다는 것은 다르다.
- **고쳤는데 여전히 빨강이면, 다음에 열 것은 대상이 아니라 검사다.**
