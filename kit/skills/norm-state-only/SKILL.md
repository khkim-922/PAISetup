# 본문은 현재 상태만 든다

*언제 발견했고 누가 지적했고 옛 판은 어땠나* 는 git log · 커밋 메시지 · 결정 기록의 몫이다. 주석은 코드가 못 보이는 것만 들고,
사람에게 하는 설명은 결정 기록 · README 에 두어 좌표(결정 NNNN)로 가리킨다. 결정 기록 · 핸드오버는 그때의 값을 박는 **굳는 문서**라
예외다.
