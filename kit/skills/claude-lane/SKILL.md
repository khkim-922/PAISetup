# 셸 있는 Claude 레인을 띄운다

맡기는 쪽이 Claude 든 Codex · agy 든, 셸 · 편집 · 커밋이 드는 레인을 `claude -p` 로 제 격리 워크트리에서 띄운다. 서브에이전트는
맡기는 세션의 한도를 함께 쓰고 claude-background 는 셸이 없다 — 둘이 못 지는 자리가 여기다. 레인은 대화형 세션처럼 홈 규범 ·
스킬 · 설정을 싣고, 권한은 자동 모드라 묻는 대신 분류기가 가른다. 이 대화를 모르니 봉투가 일의 전부다.

## 부르는 꼴

봉투를 파일로 쓰고 래퍼 하나로 띄운다. 인자 · 결제 둘 · 끝 줄의 칸 · 종료 값 · 이어 묻기는 `--help` 가 든다:

    python "<이 스킬 폴더>/scripts/claude_lane.py" --help

- 레인이 끝날 때까지 돌아오지 않는 명령이다 — Claude 에서는 배경 셸로 띄우고 끝 알림을 기다린다. 배경 셸의 시간 한도는 가장 길게
  (`timeout: 7200000`) 준다 — 기본 한도에서 셸이 끊기면 레인도 함께 끝나 끝 줄이 안 남는다. Codex 에서는 샌드박스 밖
  (`sandbox_permissions: "require_escalated"`)에서 돌린다 — 레인은 망 · 제 홈의 대화 기록 · 본 사본의 git 자리에 써야 선다.
  agy 에서는 명령의 기다림을 `--timeout` 보다 길게 준다
- 시작 줄이 피어 세션 이름(`lane-<이름>`)을 댄다 — 도는 동안 같은 PC 의 Claude 세션은 ListAgents 에서 그 이름을 찾아 SendMessage
  로 고침을 보내고, 레인은 보낸 세션에 이름으로 답한다
- 배경 셸 명령의 설명은 「레인: <이름>」으로 준다 — 데스크톱 앱의 배경 작업 창에 그 이름으로 돌고 있는 항목이 서고 멈춤 단추가 붙는다.
  레인을 멈추려면 그 셸을 멈춘다 — 레인 프로세스도 함께 끝나고 피어 목록에서 빠진다. 끝 줄은 안 남는다
- 레인의 커밋은 그 트리의 가지에 있다 — 거두기는 agent-envelope 3 절(`harvest_worktree.py`)이다. 레인에 더 물을 것이 있으면
  트리를 걷기 전에 `--resume <이름>` 으로 잇는다 — 트리를 걷으면 이어 묻기 기록도 함께 걷힌다

## 맡기기 전에 가를 것

- **결제** — 기본은 구독이다(Claude CLI 가 제 설정으로 붙는다 — 사외는 claude 로그인, 사내는 게이트웨이). API 크레딧으로 돌릴 때는
  키가 든 환경변수의 *이름*을 `--key-env` 로, 지출 상한을 `--max-budget-usd` 로 준다 — 키는 그 레인 프로세스에만 실린다. 키를
  사용자 환경변수 `ANTHROPIC_API_KEY` 에 두라고 권하지 않는다 — 사람의 대화형 세션까지 키로 넘어간다
- **울타리는 자동 모드 분류기와 push 막음뿐이다** — 트리 밖 쓰기를 막는 샌드박스는 없다. 소유와 「트리 밖은 부모 몫」은 봉투의
  레인 규칙이 든다
- **묻는 창이 없다** — 사람에게 물을 걸음은 거절되고 끝 줄 `denied=` 에 남는다. 물을 거리는 보고에 적고 끝내라고 봉투가 시킨다

## 사람만 하는 일

Claude Code CLI(`claude`)가 이 PC 에 서 있어야 한다 — 구독 결제는 터미널에서 `claude` 를 한 번 띄워 로그인해 둔다. API 결제의 키는
사람이 Console 에서 받아 제 이름의 사용자 환경변수에 둔다.
