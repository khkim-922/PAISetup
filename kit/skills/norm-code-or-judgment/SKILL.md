# 코드로 되는 일인지부터 가른다

- **사례 하나로 스크립트를 짜지 않는다** — 규칙표로 우회하는 것도 같다.
- 값을 얻으려고 산문을 읽어야 했거나, 라벨보다 실제 용례를 따랐거나, "없는 값"을 판정해야 했다면 그 일은 의미 판단이다. 코드는
  **판단의 적용 · 검증 · 관문**을 맡지 판단 자체를 맡지 않는다.
