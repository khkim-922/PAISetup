# 사내 문서함에서 찾고 읽고 고치기

ECM 서버는 파일을 주지 않는다. 화면의 「보기」 · 「편집」처럼 서버에 청하고 PC 의 ECM 에이전트에 한 줄을 넘기면, 에이전트가
파일을 받아 **DRM 에 감긴 채** 두고 그 확장자의 기본 앱으로 **화면에 띄운다.** 이 스킬은 그 길을 대신 걷는다. 손은 이
스킬의 `scripts/ecm.py` 가 들고, 아래 명령(`company_ecm.py`)은 사내 세션을 맞춘 뒤 그 손을 부르는 얇은 명령이다.

**편집과 등록은 동료가 보는 문서함을 바꾼다.** 편집으로 열면 서버가 그 문서를 이 사람 이름으로 잠그고, 올리면 동료가 보는 문서의 판이 바뀐다. 그래서
편집은 사람이 그 문서를 확인한 뒤에만 열고, 올릴 때는 늘 다음 판을 고른다(지금 판을 덮어쓰지 않는다). 새 문서는 폴더 · 보안등급 ·
공개를 사람이 확인한 뒤에만 등록한다 — 사외비B · 일반 공개는 검색으로 전 직원이 본다. 손은 편집 열기와 등록 화면의 두 요청만 짓고,
편집취소 · 지우기 · 옮기기는 짓지 않는다 — 사람이 ECM 화면에서 한다.

**사람이 보는 대화에서만 쓴다.** 에이전트가 오피스 창을 화면에 띄운다 — 예약 작업이나 사람이 없는 회차에서 부르면 쓰는 사람의
화면에 창이 뜨고, 사람이 쓰던 오피스에 들어간다.

## 명령

```bash
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" cabinets                       # 볼 수 있는 부서 · 프로젝트 문서함과 열쇠(제 부서가 맨 앞)
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" list [--search 낱말] [--cabinet <열쇠>] [--page N] [--per-page N] [--period 6M]
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" count [--search 낱말] [--cabinet <열쇠>] [--period 6M]
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" read <id>          # 받아서 창을 닫고 글자를 낸다
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" open <id>          # 받아서 화면에 띄워 둔다 — 사람이 보려 할 때
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" version <id>       # 최종 버전 — 못 읽으면 「못 읽었다」를 내고 종료는 0 이다
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" edit <id>          # 편집으로 연다 — 서버가 잠근다
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" checkin <id> <받은 파일> --desc "수정 내용"   # 저장해 닫고 다음 판으로 올린다
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" folders <문서함 열쇠> [--parent <폴더 열쇠>]   # 폴더 한 층과 열쇠
python -X utf8 -I "<이 스킬>/scripts/company_ecm.py" register <파일> --cabinet <문서함> --folder <폴더> --security 2A --open F [--title 이름]
```

명령은 먼저 사내 세션을 말없이 맞춘다 — 쓰는 사람의 Edge 가 디버깅 포트로 떠 있고 EP 에 로그인돼 있으면 사람 손이 안 든다.

## 찾고 읽는 차례

1. **찾는다** — `list` 에 사람이 말한 낱말을 `--search` 로 준다. 내 문서함에 없으면 `cabinets` 로 문서함을 보고, 제 부서(맨 앞)부터
   `--cabinet <열쇠>` 로 찾는다 — 부서 문서는 내 문서함 찾기에 안 걸린다. 사람이 「내 부서 컨텐츠」 · 부서 · 프로젝트 이름을 말하면 그
   문서함부터 간다. 기간의 기본은 화면과 같은 6 개월이라, 못 찾으면 그 말을 하고 기간을 넓힐지 묻는다 — `--period` 는 화면 기간
   필터의 값만 받는다(받는 값은 `list --help`). 건수를 같이 보이면 `count` 에도 같은 `--period` 를 준다. 줄 끝의 `id` 가 문서의 열쇠다.
   메일의 ECM 첨부는 스킬 company-mail 의 `attachment <unid> --save <번호>` 가 그 열쇠를 낸다(첨부 쪽지 머리의
   `<objectId>doc<16 hex>` 에서 `doc` 을 뗀 값) — 찾기 · 고르기 없이 바로 「읽는다」로 간다
2. **고른다** — 맞는 문서가 하나로 서면 바로 간다. 여럿이 걸리면 이름 · 고친 날 · 판 · 폴더를 보여 주고 사람이 고르게 한다
3. **읽는다** — `read <id>` 전에 「문서 창이 잠깐 떴다 닫힌다」를 한 줄 알린다. 결과의 첫 줄은 글자 수와 「글 밖」 셈이고, `---` 뒤가 글자다
4. **「글 밖」이 서면** 결과의 「받은 파일」 경로로 drm-office-read 의 그림 뜨기를 부른다 — 표 · 그림 · 차트가 글자에서 빠졌다는 뜻이다
5. **뽑은 글자는 추출본이다** — 수치 · 표 · 고유명사를 인용할 때의 확인은 drm-office-read 3 절을 따른다

## 고쳐 올리는 차례

워드 · 엑셀 · 파워포인트 문서(`ecm.py` 의 `OFFICE_BY_EXT`)만 이 차례를 탄다 — `checkin` 이 그 꼴만 저장해 닫기 때문이다. 다른
꼴(pdf 따위)이면 `edit` 가 잠그기 전에 「이 꼴은 편집으로 열어 올리지 못한다 … 잠그지 않았다」로 멈춘다(종료 1). 그 말을 전하고
사람에게 ECM 화면에서 고치라고 이른다.

1. **확인받는다** — 문서 이름 · 문서함 · 지금 판 · 올린 이를 보이고 「이 문서를 편집으로 열면 고치는 동안 서버에서 잠긴다」를 한 줄
   알린 뒤, 사람이 그 문서를 고쳐도 된다고 한 뒤에만 연다. 무엇을 고칠지 먼저 `read` 로 읽어 사람과 정해 둔다
2. **편집으로 연다** — `edit <id>`. 결과의 「받은 파일」이 고칠 파일이다 — 그 경로는 이름을 짓지 말고 결과에서 그대로 받는다.
   기본 앱을 사람이 골라야 하면(종료 4) 잠그지 않고 멈춘다
3. **고친다** — 이미 열린 그 창의 문서(`FullName` 이 받은 파일)를 오피스 COM 으로 고친다. ⚠ 에이전트가 띄운 창은 포커스를 잃기
   전까지 `GetActiveObject` 에 안 잡힌다 — `close_view.ps1` 처럼 오피스 창마다 `AccessibleObjectFromWindow` 로 앱을 받아 그 문서를
   찾고, `Documents.Open` 으로 같은 파일을 한 벌 더 열지 않는다. 감긴 파일은 오피스 안에서만 풀리므로 파서로 열지 않는다. 파워포인트
   장을 더하거나 바꿀 때는 덱 안의 견본 장을 복사해 글 · 표만 바꾼다. **고치는 쪽은 문서를 닫거나 앱을 끄지 않는다** — 저장해
   닫기는 다음 걸음(`checkin`)이 한다
4. **올린다** — `checkin <id> <받은 파일> --desc "수정 내용"`. 수정 내용은 무엇을 고쳤나를 한 줄로(동료가 판 이력에서 읽는다) 적는다.
   그 문서만 저장해 닫고, 그 앱에 남은 문서가 0 일 때만 앱을 끈다 → 에이전트의 편집완료 창에서 다음 판을 골라 올린다 → 최종 버전이
   바뀌었나 본다. 결과 「판 0.4 → 0.5」를 사람에게 알린다
5. **그만두면** — 고치지 않기로 했거나 바퀴가 멈췄으면 ECM 화면에서 그 문서의 「편집취소」를 누르라고 이른다. 잠금이 남으면 동료가 그
   문서를 못 고친다

## 새 문서로 올리는 차례

1. **자리를 고른다** — `cabinets` 로 문서함을, `folders <문서함>` · `folders <문서함> --parent <폴더>` 로 폴더를 한 층씩 내려가 보이고, 사람이
   둘 폴더를 고르게 한다. 사람이 폴더 이름을 말하면 그 길을 따라 내려가 찾아 「이 폴더 맞나」를 한 줄 확인받는다
2. **보안등급 · 공개를 확인받는다** — 화면의 단추 여섯 가운데 하나다: 기밀(`1A F`) · 사외비A/비공개(`2A F`) · 사외비A(`2A T` — 부서원이
   본다) · 사외비B/비공개(`2B F`) · 사외비B(`2B T` — 전 직원이 검색으로 본다) · 일반(`3A T` — 전 직원). 추천을 하나 붙이되(모르면
   사외비A/비공개) **값은 사람이 고른다** — 잘못 고르면 동료 전체에 보이고, 회사 보안등급 기준에 걸린다
3. **올린다** — `register <파일> --cabinet … --folder … --security … --open …`. 등록 이름은 파일 이름(확장자 뺀)이고, 다르게 두려면
   `--title`. 그 폴더가 `--cabinet` 문서함의 것이 아니면(폴더 나무를 읽어 본다) 아무것도 안 보내고 멈춘다 — 그 문서함의 `folders` 가
   낸 폴더로 다시 고른다. 그 폴더에 같은 이름이 있으면 안 올리고 멈춘다 — 고친 판이면 고쳐 올리는 차례로, 새 문서면 이름을 바꾼다
4. **알린다** — 결과의 이름 · 판 0.0 · 보안 · id 를 사람에게 알린다. 올린 PC 의 파일은 그대로 남는다
5. **잘못 올렸으면** — ECM 화면에서 그 문서를 지우라고 이른다. 손은 지우기를 짓지 않는다

## 종료 값마다 할 일

| 종료 | 뜻 | 할 일 |
|---|---|---|
| 0 | 됐다 | 결과를 쓴다 |
| 1 | 실패 | 메시지를 그대로 알린다 — 에이전트가 안 돌면 트레이의 ECM 에이전트(Rayful)가 켜져 있나 묻는다. `checkin` 이 「다른 문서 N 개가 열려 있어 앱을 끄지 않았다」면 사람이 그 문서들을 저장해 닫은 뒤 같은 명령을 다시 부른다 · 「편집완료의 저장은 보냈는데 창이 시한 안에 안 닫혔다」면 **다시 누르지 않고** 잠시 뒤 `version` 으로 판이 올랐나 본다 · 「편집완료 창을 누르지 않았다」면 사람이 그 창에서 「새로운 버전」을 고르고 누르게 한다. `register` 가 「등록은 됐는데 …」 · 「올린 문서(…)의 폴더 · 보안등급이 고른 값과 다르다」를 내면 문서는 이미 올라갔다 — 다시 올리지 않는다 |
| 2 | 인자가 틀렸다 | 메시지가 받는 값을 든다(`--period` 따위) — 그 값으로 고쳐 다시 돌린다 |
| 3 | 사내 세션이 없거나 끊겼다 — ECM 세션만 못 받은 판도 여기다 | 스킬 `ep-login` 으로 세션을 받은 뒤 같은 명령을 다시 돌린다 — 메시지가 「EP 로그인은 섰는데 … ECM 넘김을 화면 없이 못 따라갔다」면 사람에게 다시 로그인을 청하지 않는다(그 스킬의 「ECM 만 못 받았다」가 받는다) |
| 4 | 그 확장자의 기본 앱을 사람이 한 번 골라야 한다 | 메시지가 고를 앱과 자리를 든다 — 그대로 전하고, 사람이 골랐다고 하면 다시 돌린다. 사람이 「열 때 뜨는 창에서 고르겠다」고 하면 `open` · `read` 에 `--allow-picker` 를 붙여 돌린다 — 「어떤 앱으로 열까요」가 뜨면 그 앱을 고르고 「항상 이 앱 사용」을 누르라고 먼저 알린다. `edit` 는 골라 둔 뒤에만 돌린다 |

기본 앱이 빠진 확장자는 `open` · `read` · `edit` 가 깔린 앱으로 스스로 채운다(채우는 확장자와 앱은 `default_app.py` 의 `PROGIDS` —
오피스 꼴과 pdf 의 Acrobat) — 이미 고른 값은 안 건드린다. 결과의 「기본 앱 … (이번에 적었다)」가 그 표시다.
기본 앱이 서 있어도 새로 깔린 앱이 있으면 Windows 가 앱 고르는 창을 띄워 문서가 안 열린다 — 명령이 그 확장자의 「새 앱」 알림을 먼저
걷어 그 창이 안 뜬다.

## 받은 파일과 창

- 보기 창은 받은 그 문서만 닫는다 — 같은 앱에 떠 있던 사람의 문서와 앱은 남는다. pdf 는 Acrobat · Reader 에서 받은 pdf 가 앞 탭일 때만 그 탭을 닫는다. 「창: … 못 찾았다」 · 「…앞 탭이라 안 건드렸다」 · 「…앱이 아니라 안 닫았다」(Edge 따위가 pdf 기본 앱일 때)면 사람에게 다 본 뒤 그 창 · 탭을 닫아 달라고 한다
- 받은 파일은 에이전트의 폴더에 감긴 채 남는다 — 화면에서 열어도 같은 자리에 쌓이고, 비우는 일은 에이전트 몫이다. 그 파일을 저장소 · 메일로 옮기지 않는다
- 뽑은 글자는 대화에만 둔다 — 파일로 남겨야 하면 사람에게 묻고, 필요한 대목만 추린다
