# 사내 세션은 ep-login 창에서 받는다

사내 앱 스킬은 Edge 의 사내 세션 쿠키를 디버깅 포트(127.0.0.1 에만)로 받아 쓴다. 이미 떠 있는 Edge 에는 포트를 열 수 없으므로,
붙을 Edge 가 없으면 사람의 Edge 를 끝내지 않고 **ep-login 프로필의 Edge 창 하나**를 포트와 로그인 탭으로 띄운다. 그 창은 평소 Edge
와 쿠키를 나누지 않아, 거기서 한 로그인은 SSO 가 앞선 로그인을 끊고 새로 선다 — 다른 자리(평소 Edge · 다른 PC)에서 연 메일(Domino)과
EP 포털은 다시 로그인하라고 한다(문서함 같은 나머지는 산다 · 쓰던 메일은 임시보관함에 남는다). 거꾸로 사람이 거기서 메일에 다시 로그인하면 이쪽
세션이 끊기고, 다음 부름이 이 창에서 다시 로그인한다. 사내 앱 스킬 · 스크립트는 세션 파일이 있으면 그것으로 먼저 돌고 서버가 거절할
때만 받는 손을 부르며, 그것이 서면 이 스킬 없이 돈다. 이 스킬은 **받는 손이 혼자 못 서는 자리의 복구 절차**다.

## 입구 하나 — 손이 낸 「다음」 대로 간다

```bash
bash "<이 스킬>/scripts/login.sh" [domino] [ecm]     # 0 이면 표준 출력이 세션 파일의 경로 한 줄
```

이 명령 하나가 먼저 세션을 받아 본다. 메일 · 일정만 쓰는 일(`ecm` 없음)이고 세션이 살아 있으면 평소 Edge 는 보지도 열지도 않고 곧바로
0 이다 — 그 일에는 평소 EP 로그인이 안 쓰인다. 문서함 일(`ecm`) · 세션이 없을 때 · 사람 없는 아침 부름은 사용자의 평소 Edge 에 EP 포털 탭이
이미 있나를 본다(윈도에서 탭을 읽는다 — 사용자의 다른 탭은 내지 않는다). 이 로그온에 평소 로그인이 한 번 섰으면 다시 보지도 열지도 않는다. 있으면 평소
Edge 는 안 건드리고, 없으면 평소 Edge 에 회사 SSO 주소를 사람처럼 열어 그 탭이 포털로 넘어가기를 본 뒤 잇는다(그동안 뜨는 「EP 접속 정보」 창을
포트 없이 누른다). 그 뒤 받아 보고, 안 서면 로그인을 띄워 지켜본 뒤 다시 받는다 — 포트가 열린 Edge 의 로그인이 끊겼으면 그 Edge 에 로그인 탭을
열고, 붙을 Edge 가 없으면 ep-login 창을 띄운다.

입구가 가르는 것은 PC 의 종류(VDI · 데스크톱)가 아니라 **그 로그온에 SSO(통합 인증)가 서나**다. 회사 SSO 주소를 연 탭이 입력 없이 넘으면 선
것이고, 아이디 · 비밀번호를 묻거나(Edge 의 자격 증명 창은 띄우지 않고 거절한다) · 입력 칸 화면에 머물거나 · 오래 못 넘으면 안 선 것이다. 안 서면
입구는 그것을 그 윈도 로그온에 남기고 사람이 치는 화면으로 넘긴다 — 평소 Edge 에는 EP 포털을 열어 사용자가 거기서 치기를 기다리고, ep-login 창은
평소 EP 로그인 화면으로 넘긴다. 남긴 로그온의 다음 부름은 처음부터 그 화면을 연다. ECM 넘김이 조용히 안
따라오면 탭을 잠깐 열어 받는 갈래까지 이어서 돈다. 문서함(ECM) 일이면 `ecm` 을, 메일 · 일정과 함께 걸린 일이면 `domino ecm` 을 준다.
명령은 Git Bash 에서 친다. 차례 · 종료 값 · 세션 파일에 무엇이 남나는 입구와 받는 손의 머리말이 든다.

평소 Edge 의 탭을 못 읽으면 입구는 아무것도 안 열고 종료 4 로 사용자에게 한 번 묻게 한다 — 오늘 평소 Edge 에서 EP 에 이미 로그인했나. 그
「다음」 이 사용자의 답을 붙여 다시 부르는 꼴을 대고, 답은 그 윈도 로그온 동안 남는다. 물음은 「다음」 의 글 그대로 건넨다 — 사용자만 아는 것이다.
입구의 진행 줄(평소 Edge 에 EP 탭이 있었나 · 열었나 · 왜)은 사용자가 보자고 하면 그대로 보인다.

종료 4 는 「다음: …」 한 줄을 낸다 — 그 말대로 가고, 사람에게 청할 것이 들었으면 그 말을 그대로 전한다. 종료 1(도구 · 설정)은 까닭만
드니 고칠 수 있으면 고쳐 다시 부르고, 못 고치면 그 말을 사람에게 전한다. 로그인을 지켜보는 동안 5 분 남짓 걸릴 수 있다 — 셸 도구의
기본 시한(2 분)보다 길게 주거나 배경으로 띄우고 끝 알림을 기다린다. 도중에 끊기면 「EP 접속 정보」 창을 받을 손도 함께 끊긴다.

부르기 전에 한 줄 알린다: 「세션이 살아 있으면 메일 · 일정 일은 창 없이 끝납니다. 문서함 일이거나 세션이 없으면, 평소 쓰시는 Edge 에 EP 탭이 없을 때 하나 열어 먼저 로그인하고(「다른 곳에서 접속 중」 확인 창이 뜨면 대신
누릅니다), 세션이 없으면 이어 EP 로그인용 Edge 창을 하나 띄워 한 번 더 로그인합니다(열려 있는 Edge 는 끄지 않습니다). 그 뒤 로그인 때문에 평소 Edge 에 떠 있던
사내 메일 · 일정 창은 닫히고(다른 PC 에 떠 있던 것도 그럴 수 있습니다) 평소 Edge 의 EP 포털에서는 앱(ERP · MES 따위)을 새로 띄울 수 없게 됩니다 — 이미 띄운
앱 창은 그대로 되고, 새로 띄우시려면 평소 Edge 에서 EP 를 로그아웃한 뒤 다시 로그인하시거나 「EP 돌려줘」 하시면 되고, 그러면 이쪽 메일 · 일정이 끊겨 다음 회사 일 때 다시 로그인합니다. 문서함 세션을 받느라 탭 하나가 잠깐
열렸다 닫힐 수 있습니다」 — 이 로그온에 입구가 「SSO 가 안 선다」를 낸 적이 있거나 사람이 SSO 가 안 되는 PC(VDI 따위)라고 하면 「평소
쓰시는 Edge 에 EP 탭이 열리면 거기서 먼저 로그인해 주세요. 그다음 EP 로그인용 Edge 창에서 한 번 더 로그인하시게 됩니다」. 연 탭 · 띄운
창은 사람이 그대로 쓴다 — 닫지 않는다. 처음 부른 로그온에서 SSO 가 안 서면 평소 Edge 에 회사 로그인 화면이 하나 남을 수 있다 — 사람이 닫으면 된다.

## 하위 에이전트와 세션

- **하위 에이전트는 이 입구를 부르지 않는다** — 손이 종료 3 을 내면 그 자리에서 멈추고 돌려준다. 로그인은 사람이 창을 보며 해야 하고,
  둘이 함께 부르면 창이 둘 서고 SSO 가 서로의 로그인을 끊는다
- **맡기기 전에 대화의 모델이 이 입구를 한 번 부른다** — 맡길 일이 쓰는 앱(`domino` · `ecm`)을 준다. 메일 · 일정만 쓰는 일은 세션이 살아
  있으면 창 없이 바로 0 이다. 문서함 문서를 PC 로 받아 여는 일이면 `ecm` 을 준다 — 평소 로그인을 그때 세운다
- **문서함 손이 「평소 EP 로그인이 없다」(종료 3)를 내면** — 하위 에이전트는 거기서 멈추고 돌려준다. 대화의 모델이 이 입구를 `ecm` 으로
  부른 뒤 같은 명령을 다시 돌린다. 문서함 손은 이 입구를 대신 부르지 않는다(창이 둘 서고 SSO 가 서로의 로그인을 끊는다)
  도중에 멈춘 에이전트가 있으면 로그인을 마친 뒤 그 에이전트에 이어 보낸다

## 사람 없는 부름은 대화에서 쓰지 않는다

입구의 `--unattended` 는 메일함 스캔이 사용자가 켠 아침 한 번의 로그인에만 쓴다 — 입력 없이 넘는 통합 인증으로만 세우고, 사람이 쳐야
하는 자리(SSO 가 안 서는 로그온 · 통합 인증이 안 선 화면)에서는 기다리지 않고 4 로 끝난다. 대화에는 사람이 있으니 그 선택 없이 부른다 — 치는 동안 기다려
주는 꼴이 맞다.

## 사람만 할 수 있는 일 — 손이 청하라고 할 때, 까닭과 함께

- **로그인** — SSO 가 서는 로그온은 통합 인증이 입력 없이 넘고, 안 서는 로그온은 사람이 ep-login 창에서 평소 아이디로 친다.
  입구는 치는 동안 기다린다

- **평소 Edge 의 EP 로그인** — 파수 에이전트에 물린 일(문서함의 DRM 문서 열기)은 그날 평소 Edge 에서 EP 에 한 번 로그인한
  뒤에만 선다. 이 입구의 창으로 한 로그인만으로는 안 선다. 입구는 평소 Edge 에 EP 포털 탭이 없으면 로그인을 먼저 연다 — SSO 가 서면 통합
  인증에 맡기고, 안 서면 사람이 거기서 친다. DRM 문서가 안 열려서 이 입구를 부를 때는 `ecm` 을 준다 — 메일 · 일정만 받는 부름은 산
  세션 위에서 평소 Edge 를 안 본다. 그래도 안 열리면 평소 Edge 에서 EP 로그인을 해 달라고 청하고, 됐다고 하면 이 입구를 `ecm` 으로 다시
  부른다 — 차례가 「평소 로그인 → 이 입구」다

세션이 섰나 · 포트가 열렸나는 사람에게 묻지 않고 손으로 본다. 로그인이 이 PC 의 프로그램에 무엇을 보내고 무엇이 막히나를 사람이
보자고 할 때는 입구에 `--trace` 를 준다 — 「trace …」 줄을 그대로 전한다.

## 사람의 로그인을 돌려준다 — 물어서 한 번

포트 창(이 입구의 창)이 로그인하면 사람의 평소 Edge 의 EP 포털이 죽고, 거기서 ERP · MES 같은 앱을 새로 못 띄운다. 사람이 청하거나, 맡긴 회사
일이 끝났다 싶으면 사람에게 먼저 묻고 「그래」라고 할 때만 돌린다 — 저절로 부르지 않는다.

```bash
bash "<이 스킬>/scripts/login.sh" --give-back      # 평소 Edge 에 로그인을 한 번 열고 끝난다 — 포트 창은 안 건드린다
```

평소 걸음 하나만 하고 끝난다 — 포털 탭이 있어도 연다. 그 로그인이 AI 쪽(포트 창)의 메일 · 일정 세션을 끊으니, 끝난 줄을 사람에게 그대로
전한다. 다음 회사 일이 입구를 부르면 포트 창이 다시 로그인한다. 사람 없는 부름(`--unattended`)과 함께는 안 받는다

## 세션 파일 — 사내 앱의 열쇠

입구가 0 으로 낸 경로를 사람에게 그대로 알린다(자리를 바꾸려면 경로를 인자로 주거나 `MAILBOX_COOKIES` 를 둔다 — 받는 손은
git 저장소 안의 자리를 거절한다). 남에게 넘기지 않는다 — 공용 PC · 남에게 넘길 PC 에서는 사람이 고르면 세션 파일과 ep-login 창의
프로필 폴더(`%LOCALAPPDATA%\ep-login`)를 지운다. 비영속 VDI 는 로그오프 때 홈과 함께 사라진다.
