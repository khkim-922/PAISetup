# 사내 세션은 쓰는 사람의 Edge 에서 빌린다

새 브라우저로 사내 SSO 를 넘으면 SSO 가 「다른 PC에서 EP 접속 정보」 창을 띄우고, 「확인」이면 쓰는 사람의 다른 세션이 끊긴다.
그래서 쓰는 사람의 평소 Edge 를 디버깅 포트(127.0.0.1 에만)로 세우고(띄우는 손이 띄운다), 이 스킬의 받는 손이 그 Edge 에 붙어
사내 세션 쿠키만 받는다. 받는 손은 기본으로 창 · 탭을 열지 않고 사람의 탭을 건드리지 않는다 — SSO 넘김이 갈아 준 쿠키만 그
Edge 에도 되써 둔다. 탭을 여는 `--ecm-tab` 은 아래 「ECM 만 못 받았다」에서 사람에게 알린 뒤에만 쓴다. 로그인을 따로 세우는
새 창은 띄우지 않는다 — 그 로그인이 「EP 접속 정보」로 같은 사람의 다른 세션을 끊는다.

이 스킬은 **받는 손이 혼자 못 서는 자리의 복구 절차**다. 사내 앱 스킬 · 스크립트는 세션 파일을 읽기 전에 늘 받는 손부터
부르고, 그것이 0 이면 이 스킬 없이 돈다. 사람에게 청하는 것은 사람만 할 수 있는 일이다 — 포트 없이 뜬 Edge 를 닫기 · 통합
인증이 안 서는 자리(VDI)나 끊긴 세션의 로그인 · 평소 Edge 의 EP 세션을 끊는 갈래(따로 사는 프로필) 앞의 알림과 동의.
띄우기와 「EP 접속 정보」 창은 띄우는 손이 한 번에 든다. 세션이 섰나 · 포트가 열렸나는 묻지 않고 스크립트로 본다.

손은 이 스킬의 `scripts/` 가 든다 — 받는 손 `edge_session.js` 와 띄우는 손 `edge_start.js` 이고, 사내 앱 스킬
(company-mail · company-calendar · company-ecm)도 형제 폴더인 이 자리에서 받는 손을 부른다. 부르는 꼴 · 종료 값 · 파일에
무엇이 남나는 손 파일의 머리말이, 잰 것과 돌려 보기는 `scripts/README.md` 가 든다. 명령은 Git Bash 에서 친다.

## 1. 세션이 섰나부터 본다

```bash
bash "<이 스킬>/scripts/session.sh"
```

- **0** — 섰다. 표준 출력의 끝 줄이 세션 파일의 경로다. 그 경로와 아래 「세션 파일」의 두 줄을 알리고 끝낸다
- **2** — Edge 에 못 붙었다 → 2. 끝 줄에 경로가 있으면 남은 세션 파일은 있으나 그 파일로 확인이 안 섰다 — 서버가 안 받았거나
  답이 없었다(사내망 밖 · 네트워크). 손은 둘을 가르지 않으니 사람에게 「세션이 거절됐다」고 말하지 않는다
- **3** — 붙었지만 꼭 서야 하는 앱이 로그인이 안 됐다 → 3
- **4** — 붙었고 로그인 화면에는 안 닿았는데 ECM 만 못 받았다(`ecm` 을 준 판에서만 난다) → 4. 다시 로그인을 청하지 않는다
- **1** — 표준 오류의 끝 줄이 까닭이다(Node 판 · 메일함 주소 · 저장소 안의 자리). 고쳐 다시 부른다

인자를 안 주면 받는 손은 Domino(메일 · 일정)만 가린다 — 서버의 세션 확인으로 가리고, `MAILBOX_URL`(웹메일 주소의
`…/<번호>.nsf` 까지)이 환경에 있으면 그 메일함의 목록으로 가린다(없어도 되고, 일부러 묻지 않는다). ECM 은 `ecm` 을 준 판에서만
확인하고 받는다 — 문서함(ECM) 일이면 `ecm` 을, 메일 · 일정과 문서함이 함께 걸린 일이면 `domino ecm` 을 붙여 부른다. 준 앱이
다 서야 0 이다.

## 2. Edge 를 포트로 세우고 로그인까지 한 번에(종료 2 · 3)

Edge 는 평소대로 띄우면 디버깅 포트를 안 연다. 포트는 Edge 가 처음 뜰 때의 플래그로만 서서, 떠 있는 Edge 에 새로 준 플래그는
버려진다.

```bash
bash "<이 스킬>/scripts/start-edge.sh"
```

띄우는 손이 쓰는 사람의 평소 Edge 를 **EP 로그인 탭 하나와 함께** 띄우고 그 탭의 로그인을 지켜본다 — 로그인 화면의 「EP 접속 정보」
창은 「확인」으로 받고, 탭이 EP 로 넘어가면 떨어진다. 데스크톱은 통합 인증으로 입력 없이 넘고, VDI(VMware Horizon)는 평소 EP 로그인 화면이 떠
사람이 평소 아이디로 로그인한다. 띄운 창은 사람이 그대로 쓴다 —
닫지 않는다. 띄우기 전에 사람에게 한 줄 알린다: 「Edge 를 EP 로그인 화면으로 띄웁니다. 다른 자리(다른 PC · 다른 창)의 EP 세션이
있으면 끊깁니다」.

⚠ 띄우는 손은 사람이 로그인하는 동안 로그인 탭을 지켜보며 끝나지 않는다 — 최대 5분 남짓(머리말의 `SESSION_LOGIN_WAIT_SECONDS`).
셸 도구의 기본 시한(2분)으로 부르지 않는다 — 시한을 그보다 길게 주거나 배경으로 띄우고 끝 알림을 기다린다. 도중에 끊기면
「EP 접속 정보」 창을 받을 손도 함께 끊긴다.

- **0** — 포트가 섰다. 결과 줄이 「로그인 탭이 넘어갔다」면 1 을 다시 부른다. 「시한이 지났다」면 그 창에서 사람이 로그인하게
  한다(VDI 는 통합 인증이 안 서 사람이 로그인한다) — 됐다고 하면 1 을 다시 부른다. 「로그인 탭에 못 붙었다」 · 「로그인 탭을
  못 찾았다」면 손이 지켜보지 못한 것이다 — 띄운 창에서 사람이 로그인하게 하고, 「EP 접속 정보」 창이 뜨면 「확인」이 다른 자리의
  EP 세션을 끊는다고 알린 뒤 됐다고 하면 1 을 다시 부른다. 「이미 열려 있다」면 그 Edge 에서 로그인이 안 된 것이다 — 그 창에서
  EP 에 로그인해 달라고 한다
- **2** — 포트 없이 도는 Edge 가 있다. 사람에게 Edge 창을 다 닫고 **알림 영역(트레이)의 Edge 아이콘도 끝내** 달라고 한 뒤 다시
  부른다. 그 Edge 를 이쪽에서 닫지 않는다 — 열린 탭 · 쓰던 글이 사람의 것이다
  - 비영속 VDI — 로그온마다 이 걸음이다. 그 자리의 Edge 는 로그온 때마다 포트 없이 새로 뜬다
  - 영속 PC — 한 번 세우면 그 Edge 가 사는 동안 간다. 창을 다 닫아도 Edge 가 뒤에서 사는 설정(시작 부스트 · 닫은 뒤에도
    백그라운드 확장과 앱 계속 실행)이 켜져 있으면 다시 뜬 Edge 가 그 프로세스에 붙어 포트가 안 선다 — 끌지는 사람이 고른다
  - 로그온 때 Edge 를 포트로 띄우는 상주 앱이 깔린 PC — 그런데도 2 면 그보다 먼저 다른 프로그램(회사 시작 화면 같은 것)이
    Edge 를 포트 없이 띄운 것이다 — 같은 길로 닫고 다시 부른다
- **3** — 기본 프로필로 띄웠는데 시한 안에 포트가 안 열렸다. 손은 까닭을 가리지 않고, 까닭은 Edge 판으로 갈린다 — 판을 모르면
  사람에게 Edge 주소창에 `edge://version` 을 열어 첫 줄의 판을 읽어 달라고 한다
  - Chromium 136 이상 — 기본 프로필에 포트를 안 여는 판이다(Chrome 공지 · Edge 는 공지 없이 같은 증상의 보고만 있다). 사람에게
    알린 뒤 따로 사는 프로필로 띄운다. 그 창은 평소 Edge 와 쿠키를 안 나눠, 그 로그인이 평소 Edge 의 EP 세션을 끊는다:

    ```bash
    bash "<이 스킬>/scripts/start-edge.sh" --profile "$LOCALAPPDATA/ep-login/edge-profile"
    ```

  - 그 아래 판 — 그 규칙이 없다. 포트 없이 떠 있던 Edge(시작 부스트 · 닫은 뒤에도 백그라운드 실행)가 띄운 명령을 받아 버렸거나
    회사 정책이 막는다 — 2 처럼 Edge 를 트레이까지 다 닫아 달라고 한 뒤 다시 부른다
  - 이것도 안 서면 5
- **1** — 끝 줄이 까닭이다(Edge 를 못 찾음 · 그 프로필의 Edge 가 이미 포트 없이 떠 있음 · 회사 정책)

## 3. 이미 뜬 Edge 에서 로그인이 끊겼다(종료 3)

1 이 3 이면 Edge 에서 EP 로그인이 안 됐거나 끊긴 것이다(ECM 넘김이 로그인 화면에서 멈춘 판도 여기다). 사람에게 그 Edge 창에서
EP 에 다시 로그인해 달라고 한다. 사람이 됐다고 하면 1 을 다시 부른다.

## 4. ECM 만 못 받았다

1 이 4 일 때 간다(사내 앱 스킬이 「ECM 넘김을 화면 없이 못 따라갔다」로 이 스킬을 가리킨 판도 같다). EP 로그인은 섰는데 받는 손이
ECM 의 SSO 넘김을 화면 없이 못 따라간 자리라, 다시 로그인해도 안 풀린다 — 사람에게 로그인을 청하지 않는다. 사람에게 그 Edge 에 탭
하나가 잠깐 열렸다 닫힌다고 알린 뒤:

```bash
bash "<이 스킬>/scripts/session.sh" ecm --ecm-tab
```

메일 · 일정도 걸린 일이면 `domino ecm --ecm-tab` 으로 부른다. 이것도 4(「탭으로도 안 섰다」)면 그 말을 그대로 알리고 멈춘다. 3 이면
그 사이 로그인이 끊긴 것이라 3 의 자리다.

## 세션 파일

- 자리 — 받는 손이 정한 홈의 기본 자리다. 받는 손이 0 의 끝 줄로 낸 경로를 사람에게 그대로 알린다(경로를 인자로 주거나
  `MAILBOX_COOKIES` 를 두면 그 자리다). 받는 손은 git 저장소 안의 자리를 거절한다 — 사내 앱의 열쇠라 저장소 밖에만 둔다
- 사람에게 알린다 — 남에게 넘기지 않는다. 일을 마친 공용 PC · 남에게 넘길 PC 에서는 지운다. 비영속 VDI 는 로그오프 때 홈과 함께
  사라진다. 지우기는 사람이 고른 뒤에 한다
