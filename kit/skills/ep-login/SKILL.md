# 사내 세션은 ep-login 창에서 받는다

사내 앱 스킬은 Edge 의 사내 세션 쿠키를 디버깅 포트(127.0.0.1 에만)로 받아 쓴다. 이미 떠 있는 Edge 에는 포트를 열 수 없으므로,
붙을 Edge 가 없으면 사람의 Edge 를 건드리지 않고 **ep-login 프로필의 Edge 창 하나**를 포트와 로그인 탭으로 띄운다. 그 창은 평소 Edge
와 쿠키를 나누지 않아, 거기서 한 로그인은 SSO 가 앞선 로그인을 끊고 새로 선다 — 다른 자리(평소 Edge · 다른 PC)에서 연 메일(Domino)은
다시 로그인하라고 한다(EP 포털 · ECM 은 산다 · 쓰던 메일은 임시보관함에 남는다). 거꾸로 사람이 거기서 메일에 다시 로그인하면 이쪽
세션이 끊기고, 다음 부름이 이 창에서 다시 로그인한다. 사내 앱 스킬 · 스크립트는 세션 파일이 있으면 그것으로 먼저 돌고 서버가 거절할
때만 받는 손을 부르며, 그것이 서면 이 스킬 없이 돈다. 이 스킬은 **받는 손이 혼자 못 서는 자리의 복구 절차**다.

## 입구 하나 — 손이 낸 「다음」 대로 간다

```bash
bash "<이 스킬>/scripts/login.sh" [domino] [ecm]     # 0 이면 표준 출력이 세션 파일의 경로 한 줄
```

이 명령 하나가 받아 보고, 안 서면 로그인을 띄워 지켜본 뒤 다시 받는다 — 포트가 열린 Edge 의 로그인이 끊겼으면 그 Edge 에 로그인 탭을
열고, 붙을 Edge 가 없으면 ep-login 창을 띄우고, 통합 인증이 안 서면 같은 탭을 평소 EP 로그인 화면으로 넘긴다. ECM 넘김이 조용히 안
따라오면 탭을 잠깐 열어 받는 갈래까지 이어서 돈다. 문서함(ECM) 일이면 `ecm` 을, 메일 · 일정과 함께 걸린 일이면 `domino ecm` 을 준다.
명령은 Git Bash 에서 친다. 차례 · 종료 값 · 세션 파일에 무엇이 남나는 입구와 받는 손의 머리말이 든다.

종료 4 는 「다음: …」 한 줄을 낸다 — 그 말대로 가고, 사람에게 청할 것이 들었으면 그 말을 그대로 전한다. 종료 1(도구 · 설정)은 까닭만
드니 고칠 수 있으면 고쳐 다시 부르고, 못 고치면 그 말을 사람에게 전한다. 로그인을 지켜보는 동안 5 분 남짓 걸릴 수 있다 — 셸 도구의
기본 시한(2 분)보다 길게 주거나 배경으로 띄우고 끝 알림을 기다린다. 도중에 끊기면 「EP 접속 정보」 창을 받을 손도 함께 끊긴다.

부르기 전에 한 줄 알린다: 「EP 로그인용 Edge 창을 하나 띄웁니다(열려 있는 Edge 는 그대로 둡니다). 거기서 로그인하면 다른 창 · 다른
PC 에서 연 사내 메일은 다시 로그인해야 할 수 있고, 문서함 세션을 받느라 탭 하나가 잠깐 열렸다 닫힐 수 있습니다」. 띄운 창은 사람이
그대로 쓴다 — 닫지 않는다.

## 사람만 할 수 있는 일 — 손이 청하라고 할 때, 까닭과 함께

- **로그인** — 데스크톱은 통합 인증이 입력 없이 넘고, VDI 와 통합 인증이 안 선 자리는 사람이 ep-login 창에서 평소 아이디로 친다.
  입구는 치는 동안 기다린다

세션이 섰나 · 포트가 열렸나는 사람에게 묻지 않고 손으로 본다.

## 세션 파일 — 사내 앱의 열쇠

입구가 0 으로 낸 경로를 사람에게 그대로 알린다(자리를 바꾸려면 경로를 인자로 주거나 `MAILBOX_COOKIES` 를 둔다 — 받는 손은
git 저장소 안의 자리를 거절한다). 남에게 넘기지 않는다 — 공용 PC · 남에게 넘길 PC 에서는 사람이 고르면 세션 파일과 ep-login 창의
프로필 폴더(`%LOCALAPPDATA%\ep-login`)를 지운다. 비영속 VDI 는 로그오프 때 홈과 함께 사라진다.
