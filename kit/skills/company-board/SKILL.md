# 게시판은 찾기를 넓게, 쓰기는 임시저장까지

게시판은 전사가 보는 자리라 한 번 게시하면 모두에게 간다. 그래서 **이 스킬은 글을 임시보관함에 저장하고 그 글을 편집 창으로 띄우는 데서
멈춘다 — [등록]은 사람이 그 창에서 보고 누른다.** 임시저장은 남에게 안 나가니 확인 없이 바로 한다. 읽기는 게시판에 아무것도 안 남긴다
(조회수도 안 올린다).

```bash
python -X utf8 -I "<이 스킬>/scripts/board.py" <boards | list | search | read | comments | readers | attachment | drafts | form | save | show> …   # 인자 · 답의 칸은 --help
```

답은 표준 출력의 JSON 하나다. 0 이 아니면 `message` 가 까닭과 「다음: …」 을 드니 그 말대로 간다 — 종료 3(세션)은 스킬 **ep-login**
을 부른 뒤 같은 명령을 다시. 종료 2 가 게시판 이름 후보를 들면 물음에 맞는 하나를 id 로 다시 준다(모르면 사람에게 후보를 보인다).
종료 1(도구 · 앱 고장 · 저장이 섰는지 못 가림)은 까닭만 드니 그대로 알리고 다시 시도하거나 우회하지 않는다. 세션은 명령이 말없이 받으니
사람에게 묻지 않는다.

여러 글을 찾아 읽거나 첨부까지 볼 때는 하위 에이전트에 맡긴다 — 맡기는 법은 곁의 `agent-envelope/app-lanes.md` 가 든다. 임시저장 · 편집
창 띄우기는 직접 한다.

```text
스킬 company-board 로 찾고 읽는다 — 이 봉투를 받은 너는 다시 맡기지 않고, 임시저장하지 않는다.
청: <사용자의 말 그대로>
돌려줄 것: 찾은 글마다 게시판 · 날짜 · 제목 · 요지와 글 번호 — 본문은 옮겨 적지 않고 네 말로
```

## 찾는 차례 — 좁게 시작해 넓힌다

기간을 안 주면 처음부터 오늘까지 본다 — 화면의 기본(6 개월)보다 넓다. 찾기 한 번은 처음부터면 3 초 남짓, 6 개월이면 0.5 초 안쪽이라
때를 짐작할 수 있으면 기간부터 준다. 칸(넷 · 제목만)은 시간을 거의 안 가른다.

1. **게시판을 알면 그 게시판에서** — `list 식단` · `search 안전 --in 업무공지`. 게시판은 이름의 일부로 준다. 묶음(「일반사항」 · 「안전환경」)을
   주면 그 아래를 다 본다. 「최근 공지」 · 「이번 주 식단」 처럼 새것이 물음이면 낱말 없이 `list` 가 새것부터 낸다
2. **낱말이 있으면 칸을 고른다** — 기본은 제목 · 내용 · 작성자 · 첨부 이름 넷이다. 제목에 들 낱말이면 `--field title` 이 군더더기를 던다.
   사람 이름이면 `--field writer`, 양식 · 파일이면 `--field filename`
3. **때가 있으면 기간으로** — `--since 2026-11-01 [--until …]`. 「이번 달」 · 「작년」 은 날로 바꿔 준다
4. 안 나오면 낱말을 바꾸거나(「식단」 → 「식단표」 · 「메뉴」) 게시판을 넓혀(`--in` 을 빼면 모든 게시판) 다시 찾는다

찾기 답의 고정 공지(`pinned_notices`)는 찾은 것이 아니다 — 물음에 걸릴 때만 따로 말한다.

- **거르기** — 「공지 빼고」 `--no-pinned` · 「안 읽은 것만」 `--unread` · 「내가 쓴 글」 `--mine`(고정 공지는 그대로 맨 위에 선다). 「○○그룹이
  올린 공지」 는 `--field deptname`. 「'교육' 빼고」 는 `search … --without 교육` — 화면의 상세검색으로 묻는 길이라 고정 공지도 낱말이 들면
  찾은 줄로 서고 줄 날짜에 해가 없다

## 읽고 첨부를 연다

- **의견 · 열람내역** — 글의 `read` 가 의견 수(`comments`)를 대면 「달린 의견」 은 `comments <글 id> --board …` 로, 「누가 읽었나」 는
  `readers …` 로 읽는다. 둘 다 아무것도 안 남긴다. 사람 이름을 옮길 때는 물음에 걸린 만큼만 말한다
- **글 링크** — `read` 의 `link` 가 화면 「URL복사」 와 같은 바로가기다. 메일 · 대화에 그대로 붙인다

- **식단 · 안내문은 그림 하나로만 된 글이 흔하다** — 본문의 `[그림 N]` 자리에 든 것이 물음에 걸리면 같은 `read` 에 `--images` 를 붙여
  받은 그림 파일을 열어 읽는다. 안 받은 그림(`skipped`)은 사람에게 화면에서 보도록 권한다
- 답에 `hidden` 이 서면 화면에서 사람 눈에 안 보이게 감춘 글을 걷은 것이다 — 글이 물음에 비해 이상하게 비면 그렇다고 말하고 화면에서
  보도록 권한다
- 첨부가 문서함(ECM) 쪽지면 답이 문서 열쇠를 낸다 — 스킬 **company-ecm** 의 `read <열쇠>` 로 연다. 받은 파일의 `note` 가 「drm-office-read
  로 읽는다」면 스킬 **drm-office-read** 로 읽고, 「못 뽑는다」면 그 말 그대로 사람에게 이른다
- 게시글의 말을 옮길 때는 글 제목 · 게시자 · 게시일을 함께 댄다

## 글을 짓는다 — 출발 하나 × 바꿀 것 아무 조합 → [임시저장]

`save` 한 번이 게시판 화면 하나를 열고 준 것을 다 넣은 뒤 [임시저장]만 누르고, 그 글의 편집 창을 띄워 둔다 — 사람이 [글쓰기] 나 임시글을
열어 고치고 [임시저장] 하는 한 판과 같다. 부를 때마다 창이 새로 뜨고 저장을 기다리니 **바꿀 것이 여럿이면 한 번에 준다.**

| 출발(`--start`) | 고르는 때 |
|---|---|
| `new` | 새 글을 올릴 때 |
| `draft --id <임시글 id>` | 저장한 글을 고칠 때. 같은 글을 `new` 로 다시 저장하지 않는다 — 임시글이 둘이 되고 사람이 옛 창에서 [등록]할 수 있다 |
| `copy --id <원글 id> --from-board <게시판>` | 「그 공지 복사해서 날짜만 바꿔」 — 화면 [재활용]. 원글은 그대로고 새 임시글이 선다. **첨부는 안 따라온다**고 사람에게 말한다 |

- **글 일부** — 「둘째 문단만 고쳐」 는 `--swap <옛 조각> <새 조각>` 이다. 조각은 `form <글 id> --board … --of draft` 의 `body` 에서 꼭 한 번
  나오는 글자 그대로 고른다. 서식 · 그림 · 표는 그대로다. 통째 글(`--html-file`)과 같이 주지 않는다
- **첨부 빼기 · 게시기한** — `--drop <첨부 이름>`(되돌릴 수 없다 — 뺄 파일은 먼저 `attachment --save` 로 받아 둔다) · `--end YYYY-MM-DD`
  (게시판이 기한을 잠갔으면 명령이 화면 전에 멈춘다 — `form` 의 `end_editable`)
- 임시글의 게시판은 못 옮긴다 — 편집 창에 고름이 없다. 다른 게시판이면 `new` 로 짓는다

출발마다 여는 화면 · 받는 바꿀 것 · 저장을 가리는 법 · 회사에서 안 잰 것 · 아직 없는 손가락은 `save --help` 의 지도가 든다 — 표에 없는
조합은 명령이 화면을 열기 전에 까닭과 할 자리를 대며 멈춘다.

- **게시판** — `boards --write` 가 쓸 수 있는 곳이다. 사람이 정하지 않았으면 글의 성격에 맞는 곳을 골라 까닭과 함께 말한다
- **글** — 사람의 말이 곧 글이면 평문(`--text-file`)으로, 표 · 색 · 굵게가 들면 HTML 조각(`--html-file`)으로 짓는다. `--image` 의 그림은 글
  끝에 붙고, 다른 자리에 두려면 HTML 안에 `<img src="data:…">` 로 넣는다. **글은 통째로 간다** — 임시글의 글을 바꾸면 있던 글 · 그림이 다
  이 글로 바뀐다. 이 대화에서 지은 글이면 그 글을 고쳐 통째로 주고, 아니면(사람이 화면에서 쓴 글) 바꿀 자리를 띄운 창에서 사람이 고치도록
  이른다
- **부르기 전에 한 줄 알린다** — 「게시판 창이 떴다 닫히고, 저장한 글의 편집 창이 뜹니다」. 시한은 6 분으로 준다
- **전한다** — 저장한 게시판 · 제목 · 첨부 수와 함께 「아직 게시되지 않았습니다 — 띄운 창에서 보고 [등록]을 누르면 게시됩니다」를 말한다.
  답의 `reused` 가 서면 사람이 열어 둔 창에서 고친 것이라 그 창에서 고치던 것도 함께 저장됐다고 말하고, `note` 가 서면 그대로 전한다.
  창을 닫았으면 `drafts` 로 찾아 `show <글 id> --board <게시판 id>` 로 다시 띄운다

## 안 하는 것

[등록] (게시) · 게시된 글 고치기 · 지우기 · 의견(댓글) 쓰기 · 추천 · 읽음 표시 바꾸기 · 즐겨찾기 · 구독 · 열람 권한 지정(비공개 · 대상자) ·
예약 게시, 그리고 `save --help` 의 「아직 없는 손가락」 — 사람이 띄운 창 · 게시판 화면에서 하도록 이른다. 사람이 「바로 게시해」라고 해도 이 스킬은 임시저장과 창 띄우기까지다.
