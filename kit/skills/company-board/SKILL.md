# 게시판은 찾기를 넓게, 쓰기는 임시저장까지

게시판은 전사가 보는 자리라 한 번 게시하면 모두에게 간다. 그래서 **이 스킬은 글을 임시보관함에 저장하고 그 글을 편집 창으로 띄우는 데서
멈춘다 — [등록]은 사람이 그 창에서 보고 누른다.** 임시저장은 남에게 안 나가니 확인 없이 바로 한다. 읽기는 게시판에 아무것도 안 남긴다
(조회수도 안 올린다).

```bash
python -X utf8 -I "<이 스킬>/scripts/board.py" <boards | list | search | read | attachment | drafts | save | show> …   # 인자는 --help
```

답은 표준 출력의 JSON 하나다. 0 이 아니면 `message` 가 까닭과 「다음: …」 을 드니 그 말대로 간다 — 종료 3(세션)은 스킬 **ep-login**
을 부른 뒤 같은 명령을 다시. 종료 2 가 게시판 이름 후보를 들면 물음에 맞는 하나를 id 로 다시 준다(모르면 사람에게 후보를 보인다).
종료 1(도구 · 앱 고장)은 까닭만 드니 그대로 알리고 다시 시도하거나 우회하지 않는다. 세션은 명령이 말없이 받으니 사람에게 묻지 않는다.

여러 글을 찾아 읽거나 첨부까지 볼 때는 하위 에이전트에 맡긴다 — 맡기는 법은 곁의 `agent-envelope/app-lanes.md` 가 든다. 임시저장 · 편집
창 띄우기는 직접 한다.

```text
스킬 company-board 로 찾고 읽는다 — 이 봉투를 받은 너는 다시 맡기지 않고, 임시저장하지 않는다.
청: <사용자의 말 그대로>
돌려줄 것: 찾은 글마다 게시판 · 날짜 · 제목 · 요지와 글 번호 — 본문은 옮겨 적지 않고 네 말로
```

## 찾는 차례 — 좁게 시작해 넓힌다

기간을 안 주면 처음부터 오늘까지 본다 — 화면의 기본(6 개월)보다 넓다. 찾기 한 번은 처음부터면 3 초 남짓, 6 개월이면 0.5 초 안쪽이라
때를 짐작할 수 있으면 기간부터 준다. 칸(넷 · 제목만)은 시간을 거의 안 가른다.

1. **게시판을 알면 그 게시판에서** — `list 식단` · `search 안전 --in 업무공지`. 게시판은 이름의 일부로 준다. 묶음(「일반사항」 · 「안전환경」)을
   주면 그 아래를 다 본다. 「최근 공지」 · 「이번 주 식단」 처럼 새것이 물음이면 낱말 없이 `list` 가 새것부터 낸다
2. **낱말이 있으면 칸을 고른다** — 기본은 제목 · 내용 · 작성자 · 첨부 이름 넷이다. 제목에 들 낱말이면 `--field title` 이 군더더기를 던다.
   사람 이름이면 `--field writer`, 양식 · 파일이면 `--field filename`
3. **때가 있으면 기간으로** — `--since 2026-11-01 [--until …]`. 「이번 달」 · 「작년」 은 날로 바꿔 준다
4. 안 나오면 낱말을 바꾸거나(「식단」 → 「식단표」 · 「메뉴」) 게시판을 넓혀(`--in` 을 빼면 모든 게시판) 다시 찾는다

답의 `total` 이 다 센 수고 `rows` 는 한 쪽이다 — `next` 가 있으면 `--page` 로 잇는다. 찾기 답의 `pinned_notices` 는 쪽마다 맨 위에 고정된
공지라 찾은 것이 아니다 — 물음에 걸릴 때만 따로 말한다. 낱말이 든 고정 공지는 찾은 줄에 안 드니, 걸리면 그 `id` · `board` 로 `read` 한다.

## 읽고 첨부를 연다

- **`read <글 id> --board <게시판 id>`** — 글 id 는 목록 줄의 `id`, 게시판 id 는 그 줄의 `board` 다(게시판 하나만 본 답은 줄에 없고
  머리의 `board_id` 가 든다). 본문 글자와 첨부 목록이 온다. 긴 글은 `more` 의
  `--from` 으로 잇거나 `text_file` 을 나눠 읽는다. 본문의 `[그림 N]` 은 글자로 못 읽은 그림의 자리다 — 식단 · 안내문이 그림
  하나로만 된 글이 흔하니, 거기 든 것이 물음에 걸리면 같은 명령에 `--images` 를 붙인다. `images` 의 `path` 가 그 그림 파일이니 그림
  파일로 열어 읽는다(큰 그림은 받을 때 줄여 온다 — `note` 가 서면 못 줄인 것이다). `skipped` 는 안 받은 그림(게시판 밖 · 아이콘 · 못 읽는 꼴)이라 화면에서 보도록 권한다.
  답에 `hidden` 이 서면 화면에서 사람 눈에 안 보이게 감춘 글(숨긴 요소 · 바탕색 글 · 스크립트)을 그 수만큼 걷은 것이다 — 그 글은 본문에
  없으니, 글이 물음에 비해 이상하게 비면 그렇다고 말하고 화면에서 보도록 권한다
- **`attachment <글 id> --save 번호|all`** — 문서함(ECM) 첨부(「이름(확장자_NKB).html」)는 파일 대신 문서 열쇠가 오니 스킬 **company-ecm**
  의 `read <열쇠>` 로 연다. 그 밖은 파일로 받아 경로(`path`)가 오고, `note` 가 읽는 길을 이른다 — 「drm-office-read 로 읽는다」면 스킬
  **drm-office-read** 로 읽고, 「못 뽑는다」(감긴 한글 · 그 스킬이 안 받는 꼴)면 그 말 그대로 사람에게 이른다
- 게시글의 말을 옮길 때는 글 제목 · 게시자 · 게시일을 함께 댄다

## 글을 올린다 — 임시저장하고 띄운다

1. **게시판을 정한다** — `boards --write` 가 쓸 수 있는 게시판이다. 사람이 정하지 않았으면 글의 성격에 맞는 곳을 골라 까닭과 함께
   말한다. 묶음(`group`)에는 못 쓴다
2. **글을 짓는다** — 사람의 말이 곧 글이면 평문 파일(`--text-file`)로, 표 · 색 · 굵게가 들면 HTML 조각(`--html-file`)으로 짓는다.
   그림은 `--image` 로 주면 본문 끝에 차례로 붙는다. HTML 안의 다른 자리에 그림을 두려면 `<img src="data:…">` 로 직접 넣는다. 첨부는 `--file`
3. **`save --board … --title … (--html-file | --text-file) …`** — 부르기 전에 「게시판 글쓰기 창이 떴다 닫히고, 저장한 글의 편집 창이 뜹니다」
   를 한 줄 알린다. 시한은 6 분으로 준다
4. **전한다** — 저장한 게시판 · 제목 · 첨부 수와 함께 「아직 게시되지 않았습니다 — 띄운 창에서 보고 [등록]을 누르면 게시됩니다」를 말한다.
   고칠 것이 있으면 그 창에서 사람이 고친다. 창을 닫았으면 `drafts` 로 찾아 `show <글 id> --board <게시판 id>` 로 다시 띄운다

## 안 하는 것

[등록] (게시) · 글 고치기 · 지우기 · 의견(댓글) 쓰기 · 추천 · 열람 권한 지정(비공개 · 대상자) · 예약 게시 — 사람이 띄운 창 · 게시판 화면에서
하도록 이른다. 사람이 「바로 게시해」라고 해도 이 스킬은 임시저장과 창 띄우기까지다.
