# 게시판 손

**회사 PC 의 스크립트가 사내 세션으로 사내 게시판(XClick U14)에 들어가, 게시판 · 글 · 첨부를 읽고, 쓰는 사람의 Edge 화면에서 글을 임시저장하는 파일이다.**

- **앱 손** `xclick.py` — 사내 세션(쿠키)으로 SSO 를 넘어 게시판에 들어가고, 화면의 HTML 을 읽어 푼다. 쓰지 않는다
- **짓는 손** `draft_board.js` — 쓰는 사람의 Edge(디버깅 포트)에 붙어 게시판의 글쓰기 창에서 게시판 · 제목 · 본문 · 첨부를 넣고 [임시저장]만
  누른 뒤, 그 글을 편집 창으로 띄워 둔다. 등록은 안 한다. Edge 에 붙는 줄은 형제 스킬 ep-login 의 `edge_cdp.js` 를 싣는다
- **얇은 명령** `board.py` — 대화에서 부르는 명령. 형제 스킬 ep-login 의 `ep_session.py` 로 세션을 받은 뒤 두 손을 부른다. 명령의 뼈대(멈추는 꼴 · 종료 값 · 답을 JSON 하나로 내는 끝 · 답 크기에 본문 맞추기 · 받아 둔 파일)는 그 곁의 `ep_command.py` 를 부른다
- **검사** `check_board.py` — 들어가기의 뒤섞기가 화면과 같은 글자를 내나 잰다. 판정과 걷는 조건은 그 머리말이 든다

로그인은 이 손이 하지 않는다 — 사내 세션은 메일함과 한 벌이고, 그 세션을 파일로 남기는 손은 스킬 ep-login 이 든다. 들어가는 길 · 조회수를
안 올리는 까닭은 `xclick.py` 머리말, 화면에서 짓는 차례는 `draft_board.js` 머리말, 부르는 꼴 · 내는 것 · 종료 값은 `board.py` 머리말이 든다.
대화에서 쓰는 절차는 스킬 `company-board` 가 든다.

## 돌려 보기

```bash
python -X utf8 -I board.py search 식단 --field title     # 회사 PC
python -X utf8 -I check_board.py                          # 어느 PC 에서나 — 사내로도 밖으로도 안 나간다
```

검사의 끝 줄이 「통과 N/N」이면 선 것이다. 화면 꼴과 짓는 손은 검사가 못 잰다 — 회사 PC 에서 시험 글 하나를 임시저장 · 읽기 · 지우기로
쟀다(`references/SOURCES.md`).
