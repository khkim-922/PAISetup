# 회의실 손

**회사 PC 의 스크립트가 사내 회의실 예약 앱(MRS)의 출입증을 받아, 회의실 · 예약을 읽고 예약 한 건을 넣고 · 고치고 · 지우는 파일과, 그것을 무는 검사다.**

- **앱 손** `mrs.py` — 사내 세션(쿠키)으로 SSO 를 넘어 앱 출입증을 받고, 앱의 JSON 자리를 부른다. 판단은 없다
- **얇은 명령** `meeting_room.py` — 대화에서 부르는 명령. 형제 스킬 ep-login 의 `ep_session.py` 로 세션을 받은 뒤 앱 손을 부른다.
  앱의 미리 검사가 안 보는 것(겹침 · 지난 시각 · 보여 준 판과 같은가)을 여기서 가리고, 바꾼 뒤에는 내 예약을 다시 읽어 끝을 정한다

로그인은 이 손이 하지 않는다 — 사내 세션은 메일함과 한 벌이고, 그 세션을 파일로 남기는 손은 스킬 ep-login 이 든다. 들어가는 길 ·
앱이 하지 않는 것은 `mrs.py` 머리말, 부르는 꼴 · 내는 것 · 종료 값은 `meeting_room.py` 머리말이 든다. 대화에서 쓰는 절차는 스킬
`company-meeting-room` 이 든다.

## 돌려 보기

```bash
python -X utf8 -I check_meeting_room.py      # 가짜 SSO · 가짜 앱으로 잰다 — 127.0.0.1 밖으로 안 나간다
```

끝 줄이 「통과 N/N」이면 선 것이다. 가짜라 못 재는 길 — 실물 SSO 와 앱의 답 꼴은 회사 PC 에서 시험 예약 하나를 넣고 고치고 지워 잰다.
