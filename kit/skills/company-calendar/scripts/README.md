# 일정 손

**회사 PC 의 스크립트가 사내 일정 앱의 내 일정함을 읽고, 한 건을 넣고, 한 건을 지우는 파일과, 그것을 무는 검사다.**

- **읽는 손** `agenda.py` 의 `Reader` — 일정함 목록 · 내 일정 · 공유받은 일정함의 일정, 세 JSON 주소만 묻는다.
  공유받은 일정함은 읽기만 하고, 누구의 일정함이 어느 서버에 있나는 일정함 목록에서 받는다(사람마다 다르다). 이 앱은 편집 화면을 여는 주소도 지우기도
  GET 이라, 그 밖의 주소는 서버에 닿기 전에 막는다
- **일정을 바꾸는 손** — `register`(넣기) · `delete`(지우기) 둘뿐이고 이름 붙은 함수 하나씩이다. 답이 성공을 못 가려서 둘 다 다시
  읽어 끝을 정한다. 넣기는 참석자 칸을 비워 남에게 알림이 안 가고 같은 일정을 두 번 넣지 않는다. 지우기는 쓰는 사람이 손수 든 단건만,
  보인 그대로일 때 지운다. 사람이 그 한 건을 분명히 고른 뒤에만 부른다 — 언제 부르나는 부르는 스크립트가 정한다
- **얇은 명령** `company_calendar.py` — 대화에서 부르는 명령. 형제 스킬 ep-login 의 `ep_session.py` 로 세션을 받은 뒤 곁의 손을 부른다

로그인은 이 손이 하지 않는다. 사내 SSO 세션은 메일함과 한 벌이고, 그 세션을 쿠키 파일(Playwright 저장 상태 꼴)로 남기는 손은 스킬
ep-login 이 든다. 부르는 꼴 · 내는 것 · 환경변수 · 회사에서 잰 꼴과 그 출처는 `agenda.py` 머리말이 든다 — 여기 옮겨 적지 않는다.

대화에서 쓰는 절차는 스킬 `company-calendar` 가 든다. 이 폴더는 그 스킬의 명령과, 이 손을 깔린 자리에서 그대로 싣는 앱이
함께 쓰는 손이다 — 복사해 쓰는 밑판이 아니라 불러 쓰는 손이라, 공개 이름과 꼴(부르는 꼴 · 내는 것)을 바꾸면 그 쪽이 깨진다. 바꿀
때는 아래 「돌려 보기」를 돌고 부르는 앱을 같은 판에 고친다.

## 앱에서 쓰기

1. 이 폴더를 `sys.path` 에 넣고 `import agenda` 로 싣는다 — 작업 스케줄러에서 `python -I` 로 띄우면 스크립트 폴더가 `sys.path` 에
   안 서서 스크립트가 부르기 전에 제 폴더를 넣는다(`sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent))`)
2. 일정 앱 주소(`…/calperson<NN>.nsf` 까지)는 잰 기본 `agenda.DEFAULT_APP_URL` 을 쓴다 — 그 주소로 내 일정함이 안 읽히는
   사람(일정 DB 가 다른 서버에 있는 사람)만 Edge 에서 메일 → 일정을 열어 주소창에서 받는다
3. 세션 쿠키 파일은 스킬 ep-login 의 받는 손이 남기고 그 자리를 끝 줄로 알린다 — `agenda.Reader(url, <자리>)` 로 연다. 세션이
   끊기면 `SessionExpired` 가 나니 받는 손을 다시 부른다

## 돌려 보기

```bash
python -X utf8 -I check_agenda.py            # 이 폴더의 agenda.py 를 잰다 — 127.0.0.1 밖으로 안 나간다
python -X utf8 -I check_agenda.py <폴더>     # 다른 폴더의 사본을 잰다
```

끝 줄이 「통과 N/N」이면 선 것이다. 가짜 일정 앱이라 못 재는 길이 있다 — 사내 SSO 를 넘는 길과 회사에서 안 잰 꼴(`check_agenda.py`
머리말 「여기서 못 재는 것」). 첫 실제 넣기 · 지우기는 회사 PC 에서 시험 일정 하나를 넣고 지워 잰다.
