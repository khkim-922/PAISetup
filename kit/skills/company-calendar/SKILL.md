# 회사 일정은 일정 손으로 보고 · 넣고 · 지운다

회사 일정은 남이 보는 공유 시스템이고, 지운 일정은 되돌릴 손이 없다. 그래서 **넣기 · 지우기는 그 한 건을 사람에게 보이고 「네」를
받은 뒤에만 부른다.** 무엇을 넣을지 · 무엇이 급한지 같은 판단은 여기 없다.

```bash
python -X utf8 -I "<이 스킬>/scripts/company_calendar.py" <show | calendars | preview | add | delete | remember> …   # 인자는 --help
```

답은 표준 출력의 JSON 하나다. 0 이 아니면 `message` 가 까닭과 「다음: …」 을 드니 그 말대로 간다 — 종료 3(세션)은 스킬 **ep-login**
을 부른 뒤 같은 명령을 다시, 종료 4(주소)가 나면 그 메시지대로 사람에게 일정 화면의 주소를 청해 `remember` 로 남긴다. 종료 1(도구 고장)은 까닭만 드니
그대로 알리고 다시 시도하거나 우회하지 않는다. 세션은 있는 세션 파일로 먼저 가고
거절될 때만 스킬 ep-login 의 받는 손으로 말없이 받으니 사람에게 묻지 않고, 일정 앱 주소도 묻지 않는다 — 잰 기본 주소로 안 읽히는 사람에게만
종료 4 가 그때 청한다.

## 답을 읽는 법 — 모델이 짐작하기 쉬운 자리

- **요일은 답의 값을 쓴다** — 「금요일」처럼 요일로 들은 날은 `show` 답의 `today` · `today_weekday` 에서 세고, 확인에는 `preview`
  답의 `day` · `weekday` 를 「11월 13일(금)」처럼 드러내 사람이 바로잡게 한다. 제 셈으로 짐작하지 않는다. 시각은 다 서울 벽시계다
- `handle` 은 지우기에 넘기는 손잡이다 — 사람에게 보이지 않고 대화 속에 들고 간다. `pending` 이 참이면 「참석 답 전」을 붙인다 —
  참석 답은 여기서 하지 않는다(초대 메일이나 회사 일정 화면)
- **공유받은 일정함은 사람이 남의 일정을 물을 때만 본다** — 「○ 팀장님 내일 일정」은 `show 내일 --who <이름의 일부>`, 「팀 사람들
  일정까지」는 `--shared`. 누가 있나는 `calendars` 가 들고 사람마다 달라 이름을 짐작하지 않는다. 공유 줄은 `calendar`(누구 일정함)를
  함께 말하고 `private` 이 참이면 「비공개」를 붙인다. `shared_failed` 에 오른 일정함은 못 읽었다고 알린다

## 넣기 — 보이고, 확인받고, 넣는다

1. 사람의 말에서 제목 · 날 · 시작 · 끝 · 설명을 짓는다. 끝 시각이 없으면 지어 넣지 말고 「1시간으로 넣을까요」처럼 묻는다
2. `preview` 로 보인다 — 제목(잘린 꼴 그대로) · 날과 요일 · 시각 · 설명 · 겹치는 일정(`clash`) · 같은 일정이 이미 있나(`already` — 있으면
   넣지 않는다고 말하고 멈춘다). 함께 말한다 — 「내 일정함에만 들어가고 참석자는 없어 누구에게도 알림이 안 갑니다. 공개로 들어가 다른
   분이 제목을 볼 수 있습니다」
3. 사람이 **그 한 건**을 두고 넣으라고 분명히 답한 뒤에만 `add` 를 `preview` 와 같은 값과 그 답의 `seen` 으로 부른다. 무엇이든 바꾸면
   `preview` 부터 다시. 여러 건이면 건마다 보이고 사람이 고른 것만 넣는다
4. 끝은 답의 `state_word` 로 말하고 거기 든 「다음」 대로 간다

## 지우기 — 지울 수 있는 줄만, 확인받고 지운다

1. `show` 로 그날을 읽어 그 일정을 찾는다. 후보가 둘 이상이면 고르게 묻는다
2. `keep` 이 찬 줄은 지우지 않는다 — `keep_word` 를 그대로 전한다. 비었으면 날 · 시각 · 제목을 보이고 「지우면 되돌릴 수 없습니다」를
   붙여 묻는다
3. 사람이 **그 한 건**을 두고 지우라고 분명히 답한 뒤에만 `delete <handle>` 을 부른다
4. 끝은 답의 `state_word` 로 말하고 거기 든 「다음」 대로 간다

## 안 하는 것

공유받은 일정함에 넣기 · 지우기 · 참석 답 · 참석자나 회의실을 넣은 일정 · 반복 · 하루 종일 일정 넣기 · 일정 옮기기와 고치기(일정 줄의
`url` 은 편집 화면이라 열지 않는다 — 사람에게 회사 일정 화면을 권한다) · 일정 앱 화면을 브라우저로 조작하거나 일정 손을 거치지 않고
주소를 직접 부르기.
