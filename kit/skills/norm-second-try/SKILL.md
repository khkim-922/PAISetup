# 두 번째 시도 전에 기록부터 연다

그 지적은 제 층에 적는다([Layer Triage]) — 안 적으면 세 번째가 난다.

⚠ **두 번째 시도 전에 기록부터 연다** — 첫 실패의 출력 전체 · 코드 곁 머리말 · 결정 기록 · 그 자리의 `git log` · 메모리. 여러 번 고쳐진 자리에 선택지를
낼 때도 같다 — 이력 없이 낸 선택지는 이미 이름 붙은 실패를 되풀이하기 쉽다.
