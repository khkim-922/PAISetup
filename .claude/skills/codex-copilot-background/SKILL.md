# Codex · Copilot 에게는 백그라운드로 맡긴다

맡겨 두고 딴 일을 하다가, 끝났다는 알림이 오면 답을 거둔다. 부르는 길은 이 스킬의 래퍼 하나다.

**맡기는 일은 읽고 찾는 일이다.** Codex 는 읽기 전용 샌드박스에 앱 · 플러그인 · MCP 도구를 끄고, Copilot 은 파일 읽기 ·
웹 읽기 도구만 열고 뜬다. 고치는 일은 Claude 가 한다.

## 맡기기 전에 — 자리가 자료의 선을 정한다

자리는 환경변수 `CC_BG_SITE` 가 든다(`echo "${CC_BG_SITE:-outside}"` — 없으면 사외로 친다). 설치기가 자리마다 심고, 래퍼가
읽는 다른 자리 값(`CC_BG_*`)도 같이 심는다.

| `CC_BG_SITE` | 보낸 내용이 가는 곳 | 맡기는 자료 |
|---|---|---|
| `outside` | 개인 계정의 무료 요금제(ChatGPT · Copilot) — 학습에 쓰일 수 있다 | 회사 밖으로 나가도 되는 것만 |
| `inside` | Codex 는 회사 게이트웨이(사내)로 간다. 다만 검색을 켠 자리(`CC_BG_CODEX_WEB_SEARCH`)면 검색어가, Copilot 을 쓰는 자리(`CC_BG_AGENTS`)면 그쪽에 보낸 내용이 회사 밖으로 나간다 | 게이트웨이로만 가면 사내 게이트웨이를 타는 다른 도구와 같은 선, 밖으로 나가는 몫은 나가도 되는 것만 |

사내 게이트웨이는 답 하나를 요청부터 180초에 끊는다 — 사내에서는 긴 정리를 한 번에 시키지 말고 나눠 맡긴다.

## 맡기는 법

1. **프롬프트를 파일로 쓴다**(스크래치패드). 길이는 자유다 — 래퍼가 표준 입력으로 넘긴다.
2. **Bash 를 `run_in_background: true` 로 부르고, `pythonw` 로 띄운다** — 창 없이 돈다. 윈도 밖에서는 `python3` 로 부른다.

   ```sh
   pythonw "<이 스킬 폴더>/scripts/codex_copilot_bg.py" --prompt-file <프롬프트> --out <답 파일> --cwd <작업 자리> \
     [--timeout <초>] [--agent codex|copilot] [--resume <쪽>:<id>]
   ```

3. **끝나면 `--out` 파일을 읽는다.** 끝 줄 `[cc-bg] <갈래> …` 이 맡은 쪽(`agent=`) · 넘어간 자취 · Codex 가 마친 웹 검색 수
   (`web=` · Copilot 은 `-`) · 이어 묻기 값(`resume=`)을 든다.

   | 종료 코드 | 뜻 |
   |---|---|
   | 0 | 답이 왔다 |
   | 1 | 실패 — 끝 줄 위의 까닭과 `raw=` 경로를 본다 |
   | 2 | 한도(받을 쪽까지 다) 또는 빈 답 |
   | 3 | 시간 초과 |
   | 4 | 부르는 법이나 자리 값이 틀렸거나, 깔린 쪽 · 이 자리에서 쓰는 쪽이 없다 |

4. **이어 물을 때**는 끝 줄의 `resume=` 값을 그대로 `--resume` 으로 준다 — 그 대화가 있는 쪽에서 잇는다.
5. **판 번호 · 날짜처럼 시점에 매인 답은 근거 URL 을 열어 맞춰 본 뒤에 쓴다** — 묵은 페이지를 물고 온 답도 말투는
   확신에 차 있다. Codex 가 웹으로 가는 길은 검색 도구 하나라, `web=0` 인 답은 기억으로 낸 것이다 — 사실은 다시 찾아 쓴다.

## 누가 받나

- **차례는 자리 값 `CC_BG_AGENTS` 다**(없으면 Codex → Copilot). 여기 없는 쪽은 `--agent` · `--resume` 으로도 안 띄운다(4)
- **Codex 가 한도(사용 한도 · 할당량 · 용량 초과)에 걸리면 다음 쪽이 받는다** — Copilot 은 검색 없이 주소를 짐작해 열어서,
  공식 문서처럼 길이 뻔한 조사에 맞는다. 다른 실패와 시간 초과는 그 자리에서 멈추고 까닭을 남긴다
- 깔린 쪽만 차례에 든다
- **로그인은 사람이 한 번 한다** — 사외는 둘 다 브라우저로 잇는다. 인증 실패로 멈추면 그쪽 명령(`codex login` ·
  `copilot login`)을 터미널에서 한 번 치게 알린다. 사내 Codex 는 회사 키로 서서 로그인이 없다

## 작업 자리

- 조사만 시킬 때 `--cwd` 는 스크래치패드다. 읽힐 자료는 그 폴더에 두거나 자료 폴더를 `--cwd` 로 준다 — Copilot 이
  여는 파일은 작업 자리와 임시 폴더 안이다
