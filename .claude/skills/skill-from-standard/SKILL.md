# 표준 위에 스킬을 세운다

**스킬 하나의 골격은 이렇다**:

- 자리 — `.claude/skills/<이름>/SKILL.md` · 머리말은 `name`(폴더명과 같게) + `description` 둘
- **`description` 이 트리거다** — 3인칭으로, *무엇을 하나* + *언제 부르나*를 함께. 이 줄로 걸린다
- 본문 — 명령형 · 군더더기 없이. 상세가 부풀면 `references/` 로 내리되 **골격은 본문에 남긴다**(아래 4)
- 딸림 — `references/`(필요할 때 여는 문서) · `scripts/`(결정론 작업) · `assets/`(산출물 재료)
- 검증 — 부를 만한 물음을 실제로 던져 걸리는지, 걸린 채로 산출물이 규격에 맞는지 본다

이 파일의 나머지는 하나를 든다 — **어디서 가져와 어떻게 보존하나.**

- **근거 원칙** — 규범 **[Recall Priority]** · **[Single Source · Point or Derive]** · **[YAGNI]** · **[Determinism First]**

## 1. 쓰기 전에 표준을 찾는다

**바퀴를 새로 만들지 않는다**(규범 **[Recall Priority]**). 규칙을 한 줄이라도 쓰기 전에 찾는다.

- **같은 일을 하는 것** — 명세·스펙·널리 쓰는 도구·같은 자리의 공개 스킬
- **다른 분야** — 같은 *물음*을 오래 푼 곳. 인계·검수·분류처럼 오래된 문제일수록 밖에 답이 있다
- **찾은 뒤 판정 하나** — **원문이 우리보다 아는 게 있나.** 없으면 그건 참조가 아니라 장식이다

## 2. 묶을 수 있는지 가른다

| 상태 | 어떻게 |
|---|---|
| 자유 라이선스 + 진본 파일 있음 | **`references/` 에 바이트 그대로.** 아래 3 |
| 재배포 금지 (상업 저작물·논문) | **인용만.** 개념을 우리 말로 적고 출처를 단다. 원문은 안 묶는다 |
| 진본 파일이 없음 (블로그·구전) | 같음. 인용만 |
| 어느 것도 안 맞음 | **참조 없는 스킬로 간다.** 아래 8 |

못 묶을 때는 **그 사실을 파일에 적는다.** 안 적으면 다음 사람이 *"왜 이것만 없지"* 를 다시 조사한다.

## 3. 원문은 바이트 그대로 둔다

**요약하지 않고, 번역하지 않는다.**

- **압축하면 예시가 죽는다.** 규칙을 실제로 먹히게 하는 건 규칙 문장이 아니라 그 밑의 예시다
- **번역하면 검증이 끊긴다.** 번역은 매 문장이 의미 판단인데, 원문을 못 여는 자리에서는 그 판단을 **대조할 방법이 없다**
- **설치본을 복사하지 말고 상류에서 직접 받는다.** 그래야 URL 대조가 성립한다
- 파일 이름이 `SKILL.md` 면 바꾼다 — 스킬 로더와 부딪힌다. **바꾼 것도 손댄 것으로 적는다**

## 4. `SKILL.md` 에는 골격과 델타를 쓴다

본문은 스킬이 걸릴 때 자동으로 주입되고(**밀림**), `references/` 는 모델이 스스로 열어야 한다(**당김**).
**당김은 건너뛰어진다** — 약한 모델일수록 안 연 채 절 이름을 지어낸다. 그래서 본문은 자립해야 한다:

- **골격은 본문에 인라인한다** — 절 이름·순서·필수/선택처럼, 그것 없이는 산출물 꼴이 안 나오는
  최소치. 규칙 산문·예시까지 옮기면 그건 골격이 아니라 사본이다
- **델타는 세 갈래로 가른다.** 표준의 규칙 서술 자체는 안 옮긴다 — 원문이 든다.

| 갈래 | 무엇 |
|---|---|
| **선택** | 표준이 선택으로 둔 것 중 무엇을 켜고 끄나 |
| **덮어쓰기** | 표준과 **어긋나는** 것. 왜 어기는지까지 |
| **더하기** | 표준에 **없는** 것. 표준의 가장 가까운 조항과 **왜 그걸론 안 되는지**를 짝지어 쓴다 |

셋이 다 얇으면 그건 스킬이 아니라 **좌표 한 줄**이면 된다.

## 5. 덮어쓰는 자리는 원문에 표식을 박는다

`SKILL.md` 를 먼저 읽는다는 보장이 없다. **원문을 바로 여는 쪽이 더 흔하고**, 그때 빈 절은
*채우라는 뜻*으로 읽힌다.

- 한 줄 주석으로 박는다 — **주석 문법은 그 파일 것을 따른다**(`<!-- OVERRIDE … -->` · `// OVERRIDE …`)
- 담을 것 셋 — **우리는 안 쓴다/다르게 쓴다 · 진본이 어디 · `SKILL.md` 어느 절**
- **문서 전체에 걸리는 규칙은 박을 자리가 없다.** 그건 `SKILL.md` 에만 두고 *표식을 못 박는다*고 밝힌다

## 6. 낡음을 잴 방법을 남긴다

표식을 박으면 원문과 바이트가 어긋난다. **대조하는 자(`scripts/check-upstream.sh`)가 표식 줄만 걸러 다시 맞추고,
망이 안 닿으면 「다르다」가 아니라 「못 쟀다」로 나간다** — 참조 절에는 그 한 줄만 적어 둔다(저장소 뿌리에서 돈다):

```bash
sh scripts/check-upstream.sh <원본 URL> .claude/skills/<스킬>/references/<파일>
```

상류 URL 이 없으면 대조가 불가능하다. **그 사실도 적는다** — 못 재는 것을 잰다고 두지 않는다.

## 7. 역방향으로 점검한다

표준을 **기준선으로 놓고** 우리 것을 턴다. *"우리 규칙 중 표준에 이미 있는 것은 무엇인가."*

있으면 **지운다.** 우리 말로 다시 쓴 것이 제일 많이 나온다.

⚠ **우리 스킬끼리도 본다.** 한 조항이 다른 스킬 소관이면 거기 두고 **좌표만** 든다.
표준과의 중복만 보면 우리끼리 생긴 사본을 못 잡는다.

## 8. 참조가 없을 수도 있다

표준이 전부 딴 데를 겨냥해 안 맞는 축이 있다. 그때는 **억지로 묶지 않는다.**
대신 **왜 없는지**를 스킬 맨 아래에 적는다 — 후보와 탈락 사유를 함께.

안 적으면 다음 사람이 같은 검색을 처음부터 다시 한다.

## 갈리는 자리

| 갈리는 자리 | 어느 쪽 |
|---|---|
| 별이 한둘인 개인 저장소를 표준으로 삼을까 | **아니다.** 검증 없는 한 사람의 의견이다. 널리 쓰이는 것과 그럴듯한 것은 다르다 |
| 원문이 짧은데 표준이라 부를까 | **원문이 우리보다 아는 게 없으면 참조가 아니다.** 한 줄 출처 표기로 내린다 |
| 자립형으로 접었으면 `references/` 를 지울까 | **지우지 않는다 — 참조는 끊되 자료는 남긴다.** 낡음 재기(위 6)의 기준이고, 예시가 실값인 원문은 열 가치가 남는다 |
| 본문 곳곳에서 `references/` 를 가리킬까 | **참조 절 한 자리만 가리킨다.** 폴더가 있다는 사실은 폴더가 말한다 — 흩어진 언급은 장식이고 먼저 낡는다 |
| 원문이 길어서 요약할까 | 안 된다. 통째로 두고 `SKILL.md` 는 **골격**(위 4)과 **무엇을 물을 때 어느 파일을 여나**를 든다 |
| 원문 파일이 서로 겹친다 | 상류의 중복은 상류 사정이다. **발췌하면 그게 압축이다** — 통째로 두고 여는 기준만 적는다 |
| 스크립트가 딸려 있다 | 전제(저장 위치·도구·규모)가 다르면 **안 가져온다.** 안 쓸 것을 만드는 스크립트가 제일 흔하다 |
| 표준을 안 쓰는 자리를 주석으로 숨길까 | 숨기지 않는다. **살아 있는 규칙**이라 보여야 한다 — 위 5 |
| 스킬이 아니라 훅·룰 감인가 | 규범 **[Layer Triage]** 가 가른다 — 기계가 재면 훅, 파일 영역에서만 걸리면 `paths` 룰 |

## 참조 — 표준 원문

`references/` 는 공식 스킬 작성 문서 **영어 원문 그대로**다.

| 파일 | 무엇을 물을 때 |
|---|---|
| `skill-development.md` | 스킬의 뼈대 — 폴더 구조 · 머리말 · 필요할 때 읽는 구조 · 검증 |
| `skill-creator.md` | 만드는 절차 — 설명문 쓰기 · 트리거 설계 · 평가셋 |

원본 `anthropics/claude-plugins-official` 저장소 · **Apache-2.0** · 받은 시점 2026-08
경로 — `plugins/plugin-dev/skills/skill-development/SKILL.md` · `plugins/skill-creator/skills/skill-creator/SKILL.md`

**손댄 것은 파일 이름뿐이다.** 둘 다 상류에서는 `SKILL.md` 라 로더와 부딪혀 바꿨고, **내용은 바이트 그대로**다.
표식은 없다 — 덮어쓰는 자리가 없기 때문이다. 그래서 거르지 않고 그대로 대조된다.

```bash
B=https://raw.githubusercontent.com/anthropics/claude-plugins-official/main/plugins
sh scripts/check-upstream.sh $B/plugin-dev/skills/skill-development/SKILL.md .claude/skills/skill-from-standard/references/skill-development.md
sh scripts/check-upstream.sh $B/skill-creator/skills/skill-creator/SKILL.md  .claude/skills/skill-from-standard/references/skill-creator.md
```
