# 감긴 파일은 파서가 아니라 앱이 연다

Fasoo DRM 은 파일을 **통째로 자기 컨테이너로 감싼다.** 확장자는 그대로인데 머리 바이트가
바뀌므로, 형식을 시그니처로 판별하는 모든 파서가 인식 단계에서 죽는다.
**정식 오피스 앱은 그 보호를 복호해 준다** — 그래서 파서를 바꿔 끼우는 대신 앱을 태운다.

원형 문서 블록을 버리는 게이트웨이에 문서를 넣어야 할 때 이 자리가 온다 — 글자로 바꿔야
하는데 그 글자를 뽑을 파서가 죽는다.

## 1. 감긴 것인지 먼저 판별한다

머리 4바이트를 본다. 감기지 않았으면 이 스킬은 필요 없다.

```bash
python -X utf8 -c "print(open(r'<경로>','rb').read()[:12])"
```

| 머리 바이트 | 무엇 |
|---|---|
| `%PDF` | 평문 PDF — 보통 파서로 읽는다 |
| `PK` | 평문 OOXML(docx·xlsx·pptx) — 같음 |
| `\xD0\xCF` | 옛 오피스 OLE — 같음 |
| 그 밖(`\x9b DRMONE` 등) | **감겼다.** 아래 2로 간다 |

⚠ **git 저장소 안이면 커밋된 판을 먼저 본다.** DRM 은 **작업트리 파일만** 덮어쓰므로 커밋된
판은 평문인 채 남아 있다 — `git show HEAD:<경로>` 로 꺼내 머리를 다시 본다. 평문이면 앱을
태울 일이 아니다. **이 성질은 반대로도 걸린다** — 감긴 파일은 매번 `git status` 에 수정으로 뜬다.

## 2. 앱을 태워 글자를 뽑는다

`scripts/read-drm.ps1` 이 든다. 파일이든 폴더든 받고, 확장자로 앱을 골라 묶어 돈다 —
앱 생성이 건당 수 초라 확장자별로 한 번만 띄운다.

```bash
# 폴더 통째 — 지원 확장자를 훑어 글자를 파일로 뽑는다
powershell -NoProfile -ExecutionPolicy Bypass \
  -File "<이 스킬>/scripts/read-drm.ps1" "<폴더>" -OutDir "<나갈 폴더>"
```

⚠ **파일 여럿을 줄 때는 `-Command` 로 콤마 배열을 넘긴다** — `-File` 뒤에 공백으로 나열하면
둘째부터 위치 파라미터로 안 붙어 실패한다(실측).

```bash
powershell -NoProfile -ExecutionPolicy Bypass -Command \
  "& '<이 스킬>/scripts/read-drm.ps1' -Path '<파일1>','<파일2>' -Preview 120"
```

`-OutDir` 를 빼면 화면에 앞부분만 낸다(`-Preview` 로 길이 · `0` 이면 셈만).

**어느 앱이 무엇을 드나**

| 확장자 | 앱 |
|---|---|
| `.doc` `.docx` `.rtf` **`.pdf`** | Word |
| `.xls` `.xlsx` `.xlsm` `.csv` | Excel |
| `.ppt` `.pptx` | PowerPoint |

⚠ **`.pdf` 도 워드가 든다** — Acrobat COM(`AcroExch.PDDoc`)은 아크로뱃이 깔려 있어도 클래스
미등록(`0x80040154`)으로 안 뜬다(실측). 워드는 PDF 를 변환해 열므로 글자는 다 온다.

앱이 안 뜨면 오피스가 깔렸나·그 계정으로 활성화됐나를 본다. **사람이 로그온한 대화형
세션에서만 된다** — 서비스·무인 스케줄러에서는 대화창이 떠 멈출 수 있다.

## 3. 뽑은 글자는 원문이 아니라 추출본이다

앱이 뽑은 글자에는 잡음이 섞인다. **대조 없이 인용하지 않는다** — 실측된 것 둘:

- **줄바꿈 자리에 `/` 가 낀다**(`analysts' /assumptions`). 붙은 낱말을 원문으로 믿으면 틀린다
- **표의 마지막 칸을 흘린다.** 워드로 뽑은 7칸 표에서 끝 칸이 비어 나온 실측이 있다 —
  **표는 다른 엔진이나 앱 화면으로 한 번 더 본다**

⚠ **수치·표·고유명사는 그 자리를 눈으로 확인한다.** 산문은 잡음이 눈에 걸리지만 숫자는
안 걸린다 — 틀린 채 조용히 지나간다.

## 갈리는 자리

| 갈리는 자리 | 어느 쪽 |
|---|---|
| 파서가 죽었다 | **먼저 머리 바이트를 본다.** 파서를 바꿔 끼우기 전에 감긴 것인지부터 가른다 |
| DRM 을 풀어 평문으로 저장할까 | **이 스킬이 안 든다.** 읽기만 한다 — 보호 해제는 사내 정책과 권한의 일이다 |
| 파워포인트 창이 떠서 방해된다 | 워드·엑셀은 숨겨지지만 **파워포인트는 숨기기를 거부한다.** 그 앱만 창이 뜬다 |
| 파워포인트 읽은 뒤 권한 경고창이 반복된다 | 파워포인트는 COM Quit 후에도 Fasoo DRM 훅 때문에 프로세스가 백그라운드에 남아 "열람 권한이 없습니다(0x703000...)" 팝업을 무한 반복한다. **스크립트가 생성한 파워포인트 프로세스(PID)는 읽기 완료 즉시 강제 종료(Stop-Process)하고, 오피스 문서 복구(Resiliency\DocumentRecovery) 레지스트리와 임시 락 파일(~$...)을 자동 정리해야 한다.** |
| 파일 한 건인데 스크립트를 쓸까 | 한 건이면 인라인 COM 호출로 족하다. **스크립트는 규모가 정당화한다** |
| 여러 번 참조할 문서다 | 파일을 저장소에 두는 값이 없다 — DRM 이 다시 감싸고 다음 사람도 같은 벽을 만난다. **필요한 것을 추려 읽는 자리에 박는다** |
