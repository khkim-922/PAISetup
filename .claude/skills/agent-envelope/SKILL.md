# 에이전트에게 일을 시킨다

**이 스킬의 독자는 호출 주체(부모)다.** 레인은 이 스킬을 안 읽는다 — 레인이 받는 것은
봉투뿐이고, 봉투에 무엇이 실리나까지가 부모 몫이다.

**하네스 몫은 안 옮긴다** — 발사·병렬 다발 발사·백그라운드·완료 통지·이어가기·모델
지정·worktree 격리는 도구 계약이 세션에 싣고, 대규모 오케스트레이션 스크립트는 그쪽
스킬(workflow-authoring)이 든다. 여기는 그 위에서 사고로 산 규율만 든다.

- **근거 원칙** — 규범 **[Single Source · Point or Derive]** · **[Goal-Driven Execution]** · **[Root Cause Fix]**

## 1. 가르기 전 — 병렬을 열 수 있나

- **찾기·재기는 언제든 병렬이다. 고치기는 한 손이거나 worktree 격리다** — 같은 트리에
  쓰는 손이 둘이면 늦게 쓴 쪽이 이기고, 검사는 서로의 반쯤 고친 코드 위를 돈다
- 구현 병렬은 셋이 함께 설 때만 연다 — **worktree 격리 · 봉투에 소유 선긋기 · 부모 한 손 머지**
- **소유는 파일이 아니라 「무엇을 붙잡고 도나」로 가른다.** 단일 인스턴스 자동화
  서버(오피스 COM 류) · 포트 · 골든 · 공유 게이트는 파일 표에 안 잡힌다 — worktree 격리도
  파일만 가른다
- 같은 트리에서 여럿이 재면 **재는 자가 제 소스 지문(해시)을 산출에 같이 찍게 한다** —
  재는 도중 트리가 움직이면, 지문 없는 측정은 어느 판 위에서 났는지 증명이 안 된다

## 2. 봉투를 짓는다

**과업 진본이 곧 봉투다** — 문제·실측·갈래·재는 법·경계는 진본(이슈)이 들고, 봉투에는
좌표와 이 판의 규율만 얹는다(이슈 골격은 issue-write 스킬). **이력을 붙여넣지 않는다** —
봉투가 진본을 옮겨 적기 시작하면 그 순간 두 벌이 되고, 봉투는 대화 내내 컨텍스트에 산다.

**진본은 레인이 직접 연다** — 부모가 본문을 사본 파일로 옮겨 적지 않는다: 옮기는 순간
두 벌이고(낡는 쪽은 늘 사본), 옮겨 적기 자체가 봉투마다 이중 일이다. 봉투에는 진본의
주소(이슈 번호)만 싣고, 릴레이가 본문을 손대는 판(따옴표를 엔티티로 굳히는 류)은 **푸는
법 한 줄**을 곁에 적는다. 재는-법 코드가 이송에서 잘렸으면 레인이 서술로 재구성한다.

봉투에 미리 가르는 것 — 뒤늦게 가르면 머지에서야 드러난다:

| 칸 | 무엇 |
|---|---|
| 소유 | 파일/구역 + 붙잡는 자원 + **그 실물을 역산한 Reference 문서**(코드를 고친 손이 같은 봉투에서 문서도 고친다 — 문서만 따로 레인을 세우지 않는다) · **안 볼 것**까지 — 겹침은 소유가 아니라 「안 봄」이 막는다 |
| 이름 | 표찰(라벨·앵커) · 산출/보고 파일 경로 — **레인마다 다르게.** 같은 이름은 서로 덮는다 |
| 모델 | 명시한다 — 안 적으면 부모 모델을 상속한다 |
| 산출 계약 | 발견마다 `파일:줄` + 실패 시나리오 — 없으면 인상이라 안 받는다 · **안 잰 것·안 본 것을 이름으로** · 화면이면 그림 경로와 「무엇이 보이나」를 사람 말로 · **탐침은 트리를 인자로 받게 짓는다** — 경로를 박으면 부모의 전/후 재기가 헛돈다 |

⚠ **봉투가 가리키는 좌표가 실재하는지 부모가 먼저 확인한다** — 진본 본문이 낡았을 수 있다.
레인에도 같은 확인을 시키고, 없으면 **고치지 말고 보고하라**고 적는다.

**레인이 다른 저장소의 규격을 옮겨 오는 판이면 봉투에 borrow-spec-as-pair 를 싣는다** — 레인은
스킬을 안 읽으므로 짝을 세는 규율은 봉투가 이름으로 든다.

**봉투와 레인의 말은 영어, 보고서만 한국어다** — 모델 안의 매체는 영어라 봉투를 한국어로 쓰면
레인이 매 문장을 옮기며 읽고, 중간 산출도 한 번 더 옮긴다. 그래서 봉투 본문·레인의 중간 작업·
곁말은 영어로 두고, **사람이 읽는 최종 보고서 한 장만 한국어로** 시킨다(옮김의 규율은 규범
[Cross-Cultural Recoupling]). 좌표·이름·따옴표 안의 실물 문자열은 원문 그대로다 — 옮기면 못 찾는다.

**발사 전에 나무를 맞춘다** — 격리 나무는 도구가 세우지만 어디서 무엇 위에 서나는 도구 계약이
안 적는다: **세션이 열린 저장소(세션 기본 폴더)** 에, **원격 main(`origin/main`) 위에** 선다 — 셸에서
`cd` 한 저장소가 아니고, 로컬 main 도 지금 갈래도 아니다. 형제 저장소에 레인을 세우려면 나무를 손수
세우고(`git worktree add .claude/worktrees/<이름> -b worktree-<이름> origin/main`) 격리 없이 띄우며
봉투에 그 절대 경로를 박는다. 안 민 커밋은 레인에 없고, 봉투가 그 커밋의 좌표를 적으면 레인은 없는
자리를 찾는다. 차례는 셋이다 — **먼저 민다 → 발사(또는 손수 세운 나무의 경로를 봉투에) → 발사 직후
`git -C <나무> rev-parse HEAD` 로 밑판을 잰다.** 밑판이 봉투 좌표와 다르면 **레인 안에서 맞추게 하지
않는다** — 레인은 git 으로 상태를 못 바꾼다(⑥ 과 같은 층에서 승인이 막는다). 밀고 다시 띄우거나,
봉투 좌표를 그 밑판 기준으로 다시 주고 부모가 병합을 맡는다.

## 3. 레인 절대 규칙 — 이 블록을 봉투에 그대로 싣는다

레인이 읽는 말이라 영어다(2절). 부모는 뜻을 알고 싣는다 — 옮겨 적지 않는다.

    ① Own exactly one envelope. Read neighbouring files, never edit them — another lane is there.
    ② Never touch anything outside your ownership. Report defects you find there; do not fix them.
    ③ Never run golden/snapshot blessing (bless-style commands) — a human reads the full text and approves.
    ④ Never say "done" while anything is red — a "could not measure" mark is not green either.
    ⑤ If tightening a check turns green into red, fix the check and the specimen in the same pass.
    ⑥ Never change state through git. The parent commits — leave changes uncommitted in the worktree.
    ⑦ Never derive expected values from what you measured. Write why the value must be what it is; if the measurement differs, report it.
    ⑧ Before reporting "absent", run a positive control — first ask whether the specimen really has that shape.

레인 갈래에 맞게 **덜어내되 더하지 않는다** — 읽기 전용 재기 레인이면 ③⑤ 는 안 걸릴 수 있다.

## 4. 수확 — 부모가 지는 것, 레인에 못 넘긴다

- **부모 확인은 재검이 아니라 시야다** — 봉투가 좁힌 시야 밖을 부모가 본다. 제 손으로
  재는 것은 넷: 소유 밖 형제(레인이 고친 무늬를 grep) · 레인 목록 밖 곁 검사 전수 ·
  레인이 옮겨 적거나 다시 쓴 헝크의 원본 대조 · 레인이 올린 「부모가 가를 것」. 그림은
  눈으로 연다
- **레인이 돌린 검사·물림은 재돌리지 않는다** — 새 판정을 물리는 손은 레인이고 봉투가
  시킨다. 보고에 건수·물림 결과·트리 지문이 있으면 받는다. diff 는 읽는다 — 미커밋
  worktree 에 `git checkout` 되돌리기는 곧 삭제라, 되돌림은 사본에서
- 레인 여럿의 산출은 **교차 중복부터 걷는다** — 같은 자리를 두 축이 문다
- **소유 밖 발견은 부모가 가른다**(갈래 셋은 issue-write) — 지금 고칠 것이면 그 자리를
  쥔 레인에게, 없으면 발견한 레인에 소유를 넓혀서(맥락을 이미 쥐어 새 봉투보다 싸다).
  넓힌 소유는 봉투에 적는다
- **넘김은 받는 이슈에 줄을 남긴다** — 마감 코멘트에만 적으면 증발한다
- **나무를 걷는다** — 격리 나무는 저장소 **안** `.claude/worktrees/<이름>/` 에 서고, 도구는 변경이
  없을 때만 스스로 걷는다. 남은 나무는 옛 판의 사본이라 트리를 통째로 훑는 검사가 그것을 문다.
  수확이 끝나면 `git worktree remove --force` 와 `git branch -D worktree-*` 로 걷는다

## 갈리는 자리

| 갈리는 자리 | 어느 쪽 |
|---|---|
| 파일 소유로 갈랐는데 겹쳤다 | 파일 밖 자원(단일 기계·포트·골든)을 다시 센다 — 1절 |
| 고침이 작아 물림을 건너뛸까 | 안 된다. 물리지 않은 판정은 통과하도록 쓴 것과 같은 값이다 |
| 레인 보고가 길고 자세하다 | 길이는 판정이 아니다. 좌표·시나리오·안 잰 것 셋이 있나만 본다 |
| 봉투를 더 채워 줄까 | 짧은 것이 옳다. 진본 좌표 + 이 판의 규율이면 끝 — 붙여넣은 이력은 값이 아니라 비용이다 |
| 레인이 곁 결함을 고쳐 왔다 | 시키지 않은 소유 밖 고침은 받지 않는다 — 보고로 되돌리고, 가름은 수확 절 「소유 밖 발견」이 든다 |
| 레인이 「밑판이 봉투와 다르다」고 한다 | 레인 탓이 아니라 안 민 부모 탓이다 — 2절 「발사 전에 나무를 맞춘다」. 레인에게 맞추라고 시키지 않는다 |
| 봉투를 한국어로 쓸까 | 안 쓴다 — 2절. 사람이 읽는 최종 보고서 한 장만 한국어다 |

## 왜 참조가 없나

기준선이 **하네스 자체**다 — 도구 계약이 세션에 이미 실려 있어 옮겨 적으면 사본이 된다.
