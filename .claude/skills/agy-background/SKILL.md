# agy 에게는 백그라운드로 맡긴다

맡겨 두고 딴 일을 하는 길이다 — 띄운 뒤 대화를 잇고, 끝나면 알림으로 거둔다. agy 는 이 스킬의 래퍼 하나로 부르고,
이 세션의 Bash 가 직접 띄운다(서브에이전트로 감싸지 않는다).

## 맡기는 법

1. **프롬프트를 파일로 쓴다**(스크래치패드). 큰 자료는 경로를 주고 agy 가 읽게 한다 — 래퍼는 명령줄 한도
   (`MAX_PROMPT_CHARS`)를 넘는 프롬프트를 안 받는다.
2. **Bash 를 `run_in_background: true` 로 부르고, `pythonw` 로 띄운다** — 다른 것으로 감싸면 창이 뜬다. 윈도
   밖에서는 `python3` 로 부른다(재지 않았다).

   ```sh
   pythonw "<이 스킬 폴더>/scripts/agy_bg.py" --prompt-file <프롬프트> --out <답 파일> --cwd <작업 자리> \
     [--model "<이름>"] [--timeout <초>] [--conversation <id>]
   ```

3. **끝나면 `--out` 파일을 읽는다.** 끝 줄 `[agy-bg] <갈래> …` 이 갈래 · 모델 · 넘어간 자취 · `conversation` id 를
   든다. 종료 코드 0 일 때만 답이 온 것이고, 아니면 그 위의 agy 출력 · stderr · 로그 경로가 까닭을 든다. 인자가
   틀리면 답 파일 없이 종료 코드만 남는다.
4. **이어 물을 때**는 `--conversation <id>` 를 준다. 끝 줄 `model=` 이 `api:` 로 시작하면 그 이름도 `--model` 로 준다.

## 모델

- 래퍼가 고르고, 한도나 과부하면 다음 모델로 넘어간다. **`--model` 을 주면 그 하나만 쓰고 안 넘어간다** — 이름은
  `agy models` 의 표시 이름 그대로다.
- `AGY_MODEL_DELEGATE` 가 있는 PC(사내)에서는 가벼운 일(훑기 · 찾기 · 요약)에 `--model "$AGY_DEFAULT_MODEL"` 을
  준다. 없는 PC 에서는 래퍼가 고르게 둔다.

## 작업 자리

agy 는 권한을 묻지 않고 돈다 — 프롬프트의 금지로는 못 막으니 **작업 자리로 막는다.**

- 조사만 시킬 때 `--cwd` 는 스크래치패드다.
- 저장소를 줬으면 끝난 뒤 `git status --porcelain` 으로 남긴 것을 본다.

## Claude 에게 맡길 때 — agy 의 결과를 검증하거나 판단을 따로 맡기는 일

- **서브에이전트(Agent 도구)가 먼저다** — `model` 을 주고 백그라운드로 띄운다. 세션의 승인 방식과 도구를
  물려받는다 — 지연 목록의 도구(웹 등)는 ToolSearch 로 불러 쓰고, 다른 저장소의 파일은 절대 경로로 읽는다.
- **셸(`claude -p`)로 띄우면** 쓸 도구를 `--allowedTools` 로 적고, 승인 방식은 세션 그대로 둔다.
  `--output-format json` 으로 받아 `permission_denials` 가 비었나 보고, 비어 있지 않으면 실패로 친다.
