내 저장소 받기 · 설정 저장소 만들기

설치 창의 「내 저장소 받기」 칸 옆 링크가 여는 안내입니다.

1. 이 칸은 무엇을 하나

git 저장소 주소를 넣으면, 설치가 다 끝난 뒤 그 저장소를 내 PC 의 C:\Users\<내 이름>\repos\<저장소 이름> 에 받아 둡니다(git clone). 그게 전부입니다. 코드 저장소든 문서 저장소든 아무거나 됩니다.

  • 여러 개를 받으려면 주소 사이를 빈칸으로 띄웁니다.
  • 비워 두어도 됩니다. 프로그램·확장·CLI·회사 키는 이 칸과 상관없이 다 깔립니다.
  • 비공개 저장소면 받을 때 GitHub 로그인 창이 한 번 뜹니다.

대부분은 여기서 끝입니다. 아래 「설정 저장소」는 여러 PC 를 오가며 Claude Code 설정을 들고 다니려는 사람만 필요합니다. PC 하나만 쓰면 안 봐도 됩니다.

2. 「설정 저장소」란

Claude Code 는 내 설정을 홈 폴더(C:\Users\<내 이름>\.claude\)에 둡니다. 작업 규칙 문서, 스킬, 프로젝트별 메모리, 그리고 개인 API 키나 git 이름·메일 같은 것들입니다. PC 가 둘 이상이면 이것들이 PC 마다 따로 놀고, 매번 로그인할 때 초기화되는 VDI 에서는 아예 날아갑니다.

설정 저장소는 그 설정들을 git 저장소 하나에 넣어 두고, 새 PC 에서 설치 한 번으로 되살아나게 하는 방법입니다. 설치기는 받아온 저장소의 뿌리에 .claude\hooks\session-start.sh 파일이 있으면 「이건 설정 저장소구나」 하고 그 파일을 실행합니다. 그 파일이 나머지를 알아서 합니다.

3. 설정 저장소를 넣으면 무엇이 더 일어나나

무엇어떻게
git 이름·메일저장소에 적어 둔 값으로 git config --global 을 맞춥니다
같이 쓰는 저장소들저장소에 적어 둔 목록을 repos\ 아래에 받아 둡니다(이미 있으면 건너뜁니다)
개인 API 키저장소의 secrets.env 에 적어 둔 키를 사용자 환경변수로 심습니다(Tavily · GitHub 토큰 등)
Claude Code 홈 설정저장소의 vdi-home-settings.json 을 홈 설정으로 깝니다
규칙 문서·스킬·메모리저장소의 deploy.ps1 이 홈과 각 저장소로 뿌립니다

이 일들은 그 뒤로도 설정 저장소를 연 Claude Code 세션과 로그인 때 도는 자동 실행이 다시 확인합니다. 저장소에서 키를 바꾸거나 규칙 문서를 고치면 그다음 번에 새 값이 심깁니다. 다른 프로젝트만 연 세션은 맞춰야 할 것이 있으면 알리기만 합니다.

4. 설정 저장소 만드는 법

맨바닥에서 만들지 않습니다. 설치가 견본 폴더를 깔아 둡니다: C:\Users\<내 이름>\.claude\seeds\config-repo\. 그 안에 필요한 파일이 다 들어 있고, 고칠 것은 내 값을 적는 파일 둘뿐입니다.

  1. GitHub 에 비공개 저장소를 하나 만듭니다. 이름은 아무거나 됩니다. 개인 키가 들어가므로 반드시 비공개(Private)로 둡니다.
  2. 견본 폴더의 내용을 그 저장소 폴더에 통째로 복사합니다. 숨김 폴더 .claude 와 .githooks 도 같이 복사해야 합니다. 탐색기에서 끌어다 놓으면 숨김 폴더가 빠지기 쉬우니, 터미널에서 이렇게 하는 편이 안전합니다. 
    cp -r ~/.claude/seeds/config-repo/. ~/repos/<새 저장소>/
  3. personal.conf 를 열어 내 값을 적습니다. 적을 것은 셋: git 이름과 메일, 같이 받아 둘 저장소 이름들, 저장소 주소 형식. 각 줄 위에 설명이 있습니다.
  4. deploy.targets.d\example-pc.conf 를 내 PC 에 맞게 고치고 이름을 바꿉니다. 「어느 PC 의 어느 폴더로 뿌리나」를 적는 파일입니다. 이름은 home.conf 처럼 PC 를 알아볼 수 있게 두고, example-pc.conf 는 지웁니다.
  5. 개인 키가 있으면 secrets.env 를 만듭니다. 한 줄에 이름=값 하나씩. 없으면 안 만들어도 됩니다.
  6. 커밋하고 올립니다.
  7. 설치 창의 「내 저장소 받기」 칸에 그 주소를 넣고 설치를 누릅니다. 다음부터는 새 PC 에서 이 한 번으로 설정이 다 되살아납니다.

고치지 말아야 할 것. 견본에서 온 스크립트들(deploy.ps1 · .claude\hooks\ · .githooks\)은 손대지 않습니다. 내 값은 전부 위 3·4·5 번 파일에 들어가고, 스크립트는 그 파일들을 읽습니다. 스크립트를 고치면 다음에 새 판을 받을 때 그 자리에서 충돌합니다.

5. 더 알고 싶으면

견본 폴더의 README.md 가 파일 하나하나가 무엇인지, 커밋할 때 도는 검사는 무엇인지, 잘 안 될 때 어디를 보는지를 적고 있습니다. 같은 폴더의 그림 둘 (session-start-flow.svg · deploy-flow.svg)은 세션을 열 때와 뿌릴 때 무슨 일이 어떤 순서로 일어나는지를 보여 줍니다. 더블클릭하면 브라우저가 엽니다.

이 문서는 설치 폴더에 같이 온 한 장입니다. 밖으로 나가는 주소가 없어 사내망에서도 뜹니다.
