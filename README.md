# Claude Code 사내 설치본

윈도우 PC 한 대에 Claude Code 개발 환경을 한 번에 세운다 — 사내 게이트웨이에 붙은 채로.

**포스코 사람용이다.** 사내는 회사 키로 게이트웨이에 붙고, 사외는 구독·개인 로그인으로 선다 —
회사 키·프록시·회사 설정은 사내에서만 뜻이 있고, 프로그램(VS Code · 확장 셋 · CLI 셋)은 어디서나
깔린다. 사내 PC · 사외 VDI · 사내 VDI · 집 — **네 자리에서 같은 파일을 누르면 된다.**
어느 자리인지는 설치가 스스로 잰다(그 주소에 닿나 안 닿나). 고를 것이 없다.

## 왜 있나

맨바닥 PC 에서 Claude Code 를 쓰려면 프로그램 넷을 깔고, VS Code 확장을 붙이고, 게이트웨이
주소와 키를 사용자 환경변수에 심어야 한다. 순서를 하나 어기면 조용히 어긋난다 — 확장은
깔렸는데 실행할 CLI 가 없거나, 키는 심었는데 창을 안 닫아 안 걸리거나, 파이썬은 깔렸는데
윈도우가 미리 깔아 둔 껍데기가 대신 잡히거나. 다 겪고 나서 순서와 판정을 한 파일에 넣었다.

## 무엇이 깔리나

| | |
|---|---|
| VS Code · **Claude Code 확장** | 확장은 CLI 를 자식으로 부른다 — 둘 중 하나만 있으면 안 돈다 |
| Claude Code CLI · Node.js | 위를 돌리는 것 |
| **Codex CLI · Codex 확장** · **Gemini CLI · Gemini CLI Companion 확장** | 어디서나 깔린다. **사내**는 같은 회사 키로 게이트웨이에 붙는다 — Codex 는 직결, Gemini 는 아래 프록시를 지난다. **사외**는 각자 로그인으로 쓴다 — Codex 는 `codex login`(ChatGPT), Gemini 는 첫 실행의 Google 로그인 |
| **로컬 프록시** | **사내에서만.** `127.0.0.1:18901` 에 서서 Claude Code(Opus 5)와 Gemini CLI 를 게이트웨이로 넘긴다. 로그인마다 저절로 뜬다. 왜 있나는 `posco/pgpt-proxy/README.md` |
| Git · Python · GitHub CLI | 코드를 짤 사람만. `-NoDevTools` 로 뺀다 — **다만 사내에서는 Python 만은 깐다** (프록시가 그것으로 돈다). 「내 저장소 받기」에 주소를 넣었고 GitHub CLI 로그인이 비었으면 **저장소를 받기 직전에** 설치가 브라우저 로그인을 띄운다 — 일회용 코드와 남은 시간(180초)이 팝업에 뜬다 |
| Claude 데스크탑 앱 | **사외에서만.** 사내에서는 게이트웨이를 못 물어 쓸모가 없다 |
| 게이트웨이 주소 · 모델 · **키** | 사용자 환경변수로 심는다. 키는 한 번만 넣는다 — 세 CLI 가 읽는 세 이름에 같이 심긴다. **사외면 안 묻고, 사내에서 쓰던 기계를 사외에서 누르면 남아 있던 사내 값을 걷는다** (아래) |
| Codex · Gemini 설정 | 사내에서만. `~/.codex/config.toml` · `~/.gemini/settings.json` 을 회사 설정 틀(`posco/`)에서 채운다 — 키는 그 파일에 안 들어간다, 환경변수가 든다 |
| **사내 환경 문서** · **씨앗 셋** | `~/.claude/posco/` · `~/.claude/seeds/gateway/` · `~/.claude/seeds/check/` · `~/.claude/seeds/config-repo/` 로 깔린다. 고를 것이 아니라 환경이라 스위치가 없다. **거울이라 짐에서 빠진 파일은 홈에서도 빠진다** — 옛 판의 찌꺼기가 남아 진본인 척하지 않는다 |

## 폴더에 무엇이 들어 있나

**받는 것은 `Setup.exe` 하나다.** 두 번 누르면 끝이고, 아래 것들은 그 안에 들어 있다 —
설치가 제 자리(`%LOCALAPPDATA%\Claude Code Setup\<판>`)에 풀어 쓴다. **손으로 열 일은 없지만,
무엇이 오는지는 알고 받는 편이 낫다.**

```text
├─ install.cmd               설치 창을 띄우는 것. Setup.exe 가 이것과 같은 화면을 연다
├─ install.ui.ps1            설치 창 — 값을 받고 진행을 보여준다
├─ install.ps1               설치 몸통 — 무엇을 어떻게 깔지는 이 한 자리가 든다
├─ install.env               회사 공통값(주소·모델)이 채워져 온다. 키 칸은 비어 있다
├─ install-flow.svg       ← 위 흐름 그림. 릴리스 쪽에도 같은 것이 한 장 선다
├─ setup-icon.ico            설치가 바탕화면 바로가기에 박는 아이콘. 홈으로 같이 깔린다
├─ config-repo-howto.html    「설정 저장소란? 만드는 법」 한 장 — 설치 창의 링크가 연다
│
├─ posco/                    사내 게이트웨이 환경 문서 한 층 — 되고 안 되는 것의 진본
│                            (회사 루트 CA `corp-ca.pem` 도 여기 있다 — 설치가 쓴다)
├─ seeds/
│  ├─ gateway/               게이트웨이 배관 씨앗 — 새 프로젝트가 복사해서 출발한다
│  ├─ check/                 검사 씨앗 — 새 저장소의 `_check/` 가 복사해서 출발한다
│  └─ config-repo/           설정 저장소 씨앗 — 「내 저장소 받기」 칸을 쓸 사람만 본다.
│                            세션 훅·배포·커밋 게이트가 **한 벌로 돌게** 들어 있다
│
├─ .claude/                  **두 가지가 한 폴더에 산다** — 홈으로 가는 셋과, 이 설치본이
│                            제 살림으로 들고 있는 나머지. 바로 아래가 그것을 가른다
├─ agents/                ← 비어 있다. 제 서브에이전트를 여기 넣으면 같이 깔린다
│
├─ README.md                 이 글
├─ VERSION                   이 설치본이 몇 판인지. 릴리스 이름과 같은 값이다
├─ LICENSE                   MIT
├─ .gitattributes            줄끝을 못박는다 — 저장소 사정이라 안 봐도 된다
├─ .gitignore                무엇을 저장소에 안 담나 — 저장소 사정이라 안 봐도 된다
├─ .markdownlint-cli2.jsonc  만든 사람의 글 검사 설정 — 안 봐도 된다
├─ lychee.toml               만든 사람의 링크 검사 설정 — 안 봐도 된다
└─ .githooks/                만든 사람이 커밋할 때 재는 문지기 한 벌 — 안 봐도 된다
```

`posco/` 와 `seeds/` 는 **고를 것이 아니라 환경**이라 스위치가 없다 — 누가 받아도 홈에 깔린다.

`.claude/` 는 **한 이름 아래 두 가지가 산다.**

| `.claude/` 안의 | 무엇이고 어디로 가나 |
|---|---|
| `CLAUDE.global.md` · `rules.global/` · `skills/` (그리고 뿌리의 `agents/`) | **홈으로 가는 셋.** 가운데 옵션을 켠 사람에게만 `~/.claude/` 로 간다 — **꺼진 것이 기본**이다 |
| 그 밖의 것 — 커밋 게이트가 쓰는 훅 · 도구 선언 · 전역 설정 · 린터 설정 | **여기 사는 살림이지 홈으로 가는 것이 아니다.** 만든 사람이 이 설치본을 짓는 데 쓰는 것들이라 **옵션을 켜도 안 깔린다.** 안 봐도 된다 |

⚠ **이 폴더를 사람이 만들 일은 없다.** `Setup.exe` 가 제 안에서 꺼내 제 자리에 편다 — 같은
판을 두 번 눌러도 이미 펴져 있으면 건너뛴다.

## Security

**키는 짐에 안 담겨 온다.** 설치가 물어보고, 화면에 안 찍히게 받아 사용자 환경변수로
심는다. **키는 사람마다 제 것이다** — 남의 것을 받아 쓰지 않는다. 받은 그대로의 짐에는
키 칸이 비어 있다.

여러 대를 세우느라 매번 묻는 것이 번거로우면 펴진 짐의 `install.env`
(`%LOCALAPPDATA%\Claude Code Setup\<판>\`)에 제 키를 적어 둘 수 있다. **그렇게 적었으면 그
파일을 남에게 넘기지 않는다.** ⚠ **그 파일의 `#이름 = 값` 줄은 주석이 아니다** — 그 자리의
머리말이 그것을 든다. 읽고 나서 연다.

## Install

먼저 한 장으로. **띠 넷이 「누가 하나」다** — 손을 대는 것은 `사람` 띠 넷뿐이고 나머지는
저절로 돈다. `내 저장소` 띠는 **아래 「내 저장소 받기」 칸을 채운 사람만** 도는 갈래다.
빨간 곁줄이 실제로 사람들이 걸린 자리다.

![설치 흐름 — 담당 띠 넷으로 가른 설치 순서, 갈래 셋](install-flow.svg)

글자가 잘려 보이면 그 자리에 마우스를 올린다 — 전문이 뜬다. 이 글을 브라우저로 보고 있지
않다면 릴리스 쪽 같은 그림을 연다.

1. 릴리스에서 **`Setup.exe`** 를 받는다 — 받을 것은 그 파일 하나다
2. **두 번 누른다** — 설치 창이 뜬다. 검은 창은 안 뜬다
3. **API 키**를 넣는다. 주소는 채워져 있다
4. **[설치 시작]** 을 누른다 — 막대가 차는 동안 기다린다
5. **사외이고 Claude 로그인이 안 서 있으면 브라우저가 뜨고, 최대 180초 기다린다**
6. **저장소 주소를 넣었으면 마지막 칸 직전에 GitHub CLI 로그인 코드 팝업이 뜬다** — [브라우저 열기]를 누르고 그 코드를 넣는다. 남은 시간이 창에 보이고, 서면 스스로 닫힌다. 안 눌러도 설치는 이어서 간다
7. **검증이 끝나고 3초 뒤에 설치가 창을 띄운다** — 사내면 VS Code, 사외면 Claude 데스크탑

⚠ **그 칸은 저장소를 받기 직전에 선다.** 앞쪽에 두면 프로그램을 깔기도 전에 사람을 붙들어
두는데, 그 자격이 실제로 필요한 자리(비공개 저장소 clone)까지는 한참 남는다.

설치가 끝나면 **바탕화면과 시작 메뉴에 「PAI Setup Wizard」 꽃 아이콘**이 생긴다.
**다음부터는 그것을 누르면 된다** — 누르면 설치 창이 뜨면서 **새 판이 나왔는지 같이 봐 준다.**
새 판이 있으면 그 자리에서 받는다 — 받은 파일을 릴리스에 같이 오른 SHA-256 과 대조하고, 못 재거나
다르면 띄우지 않고 까닭을 댄다. (우리가 받는 것이라 위의 파란 경고는 안 뜬다.)

무엇을 띄울지는 고르는 것이 아니라 **설치가 잰 자리**가 정한다. 사내는 게이트웨이라 그 주소로
말이 통하는 것이 확장·CLI 뿐이고, 사외는 구독 로그인이라 데스크탑 앱이 앞문이다.
사외 로그인은 저장소 옵션과 무관하다. `claude auth status`로 먼저 재고, 비었을 때만
`claude auth login`을 띄운다. 저장소 칸을 비워도 동일하게 돈다.
**3초는 위의 `[O]/[X]` 를 읽을 틈이다** — 새 창이 설치 창을 덮으므로 바로 띄우면 그 판정을
아무도 못 보고 지나간다.

⚠ **이미 돌고 있으면 먼저 묻는다.** 「껐다 새로 열까요?」 창이 뜬다 — **[예]** 면 끄고 새로
띄우고, **[아니오]** 면 안 띄우고 손으로 하라고 댄다. VS Code 든 데스크탑이든 같다.

왜 굳이 새로 여나 — **돌던 것은 뒤에 온 것을 모르기 때문이다.** 두 갈래로 그렇다. 창은 뜰 때
환경을 한 번 복사하고 그 뒤에 바뀐 것은 안 따라온다. 그리고 **이 설치가 끝이 아니다** —
뒤이어 부트스트랩이 배포를 부르고 거기서 MCP 서버가 등록되고 세션 훅이 심긴다. 돌던 앱은
그 선언을 뜰 때 한 번 읽고 말았다.

⚠ **[예] 를 누르기 전에 저장한다.** 창을 닫으라고 먼저 보내지만, 그래도 안 나가면 세게
끝낸다. **Claude 데스크탑은 창만 닫으면 안 꺼지고 트레이(시계 옆)로 내려간다** — 세게
끝내는 자리가 있는 까닭이 그것이다.

### 윈도우가 한 번 막는다 — 거기서 멈추지 않는다

인터넷에서 받은 파일이라 **처음 누를 때 파란 경고창이 뜬다.**

> **Windows의 PC 보호** — 「추가 정보」를 누르면 아래에 **「실행」** 단추가 나온다.

서명을 안 산 파일이라 그렇고, 짐 안의 어느 파일도 인터넷에 다시 나가지 않는다.
경고창을 닫아 버리면 아무 일도 안 일어난 것처럼 보이므로 — **눌러야 시작된다.**

### 옵션 셋 — 그대로 두면 된다

| 칸 | 기본 | 무엇 |
|---|---|---|
| 개발 도구도 깝니다 | **켜짐** | Git · Python · GitHub CLI. 코드를 안 짜면 꺼도 된다 |
| 같이 온 규범 · 룰 · 스킬도 깝니다 | **꺼짐** | 만든 사람의 작업 규율이 같이 들어 있다. 쓸 사람만 켠다 — 안 켜도 설치는 완전하다 |
| 이미 깔린 것도 최신으로 올립니다 | **켜짐** | 옛 판이 깔려 있으면 올린다 |

### 규범 · 룰 · 스킬 — 가운데 칸이 옮기는 것

가운데 칸을 켜면 짐 안의 네 자리가 홈의 네 자리로 간다. **설치는 이름을 하나도 안 본다** —
그 자리에 무엇이 들었든 그대로 나른다.

| 짐의 이 자리 | 홈의 이 자리로 |
|---|---|
| `.claude/CLAUDE.global.md` | `~/.claude/CLAUDE.md` |
| `.claude/rules.global/` | `~/.claude/rules/` |
| `.claude/skills/` | `~/.claude/skills/` |
| `agents/` | `~/.claude/agents/` — **비어 있다.** 만든 사람의 에이전트는 안 싣는다 |

자리가 비어 있으면 **건너뛰고 실패로 세지 않는다.**

⚠ **덮어쓰는 것이 아니라 합친다.** 같은 이름은 갈리지만 홈에 이미 있던 **다른 이름은 남는다.**
깨끗하게 갈려면 `~/.claude/` 의 `skills` · `rules` · `agents` 를 먼저 지우고 깐다.
(`CLAUDE.md` 는 파일 하나라 통째로 갈린다.)

**제 규율을 쓰려면 — 이 칸이 아니라 「내 저장소 받기」다.** 짐은 손으로 열 자리가 아니라서
(`Setup.exe` 가 제 안에서 꺼내 판마다 새 폴더에 편다) 거기 든 것을 갈아 끼워 봐야 다음 판에서
말없이 되돌아간다. 제 규범·룰·스킬은 **제 설정 저장소가 든다** — 그 주소를 아래 칸에 넣으면
설치가 저장소를 받고 그 뿌리의 훅이 홈에 뿌린다. 그 저장소를 만드는 법은 아래 「내 저장소
받기」 칸이 든다.

## Usage

설치 창의 기록 칸 마지막이 이렇게 찍힌다. **하나라도 `[X]` 면 안 선 것이다** — 창 아래
줄도 빨갛게 바뀐다.

```text
=== 검증 ===
  [O] VS Code
  [O] 클로드 확장
  [O] Claude Code CLI
  [O] ANTHROPIC_BASE_URL
  [O] ANTHROPIC_AUTH_TOKEN

  3초 뒤에 엽니다 — 위 검증 칸을 먼저 읽는다
  VS Code — 띄웠다

=== 끝 === VS Code 를 열었습니다 — Ctrl+Shift+P → Claude 로 확장을 엽니다
```

**마지막 `=== 끝 ===` 줄이 다음에 할 일을 댄다** — 창 아래 줄에 뜨는 것도 그 줄이고, 갈래마다
다른 말을 한다(띄웠다 · 이미 떠 있다 · 못 찾았다). 띄운 것이 VS Code 면 거기서
`Ctrl+Shift+P` → `Claude` 로 확장을 연다.

### 같이 깔린 환경 자료 — 어디에 있나

| 자리 | 무엇 |
|---|---|
| `~/.claude/posco/` | **사내 게이트웨이 환경 문서 한 층.** 무엇이 되고 안 되는지는 **이 폴더 전체**가 답한다 — 한 장만 보고 판정하지 않는다 |
| `~/.claude/seeds/gateway/` | **게이트웨이 배관 씨앗.** 새 프로젝트를 시작할 때 이 폴더를 복사해 출발한다. 임포트하는 묶음이 아니다 |
| `~/.claude/seeds/check/` | **검사 씨앗.** 새 프로젝트의 `_check/` 가 복사해 출발한다 — 판정 한 벌 · 종료코드 계약을 무는 자 · 어느 저장소에서나 도는 게이트. 받아 간 사본은 곁말이 진본을 가리키고 `borrowed_check.py --receive` 로 다시 받는다 |
| `~/.claude/seeds/config-repo/` | **설정 저장소 씨앗.** 아래 「내 저장소 받기」 칸을 쓰려는 사람만 본다 — 그 칸이 기대하는 저장소를 만드는 골든이고, **돌아가는 한 벌**이 다 들어 있다 |

### 「내 저장소 받기」 칸 — 안 넣어도 된다

빈 칸이 **기본이고 맞는 답이다** — 위의 것은 이미 다 깔리고, 채워도 그대로 산다. 넣는 칸은
*제 저장소*를 **받아 두는** 자리이고, 설치는 **`~/repos/<저장소 이름>`** 으로 받는다.
**여러 개는 빈칸으로 가른다** — 주소에는 빈칸이 없으므로 그것이 가르는 자다:

```text
https://github.com/나/설정.git  https://github.com/나/메모.git
```

받아온 저장소 뿌리에 **`.claude/hooks/session-start.sh`**(Claude Code 의 SessionStart 훅)가
있고 없음이 그 뒤를 가른다 — 여럿이 그 파일을 들면 **첫 것만 부르고** 나머지는 이름만 찍는다(둘을 잇달아
부르면 뒤엣것이 앞엣것의 키·설정을 덮는다). 무엇이 있으면 무엇이 도나는 **`~/.claude/seeds/config-repo/README.md`**
(설정 저장소 씨앗)가 든다. 씨앗이 왜 있고 맨바닥에서 짜면 무엇을 다시 겪나 · 만드는 일곱
걸음은 칸 옆 「설정 저장소란? 만드는 법」 링크가 여는 안내 한 장이 든다 — 설치가 끝난 뒤에도
`~/.claude/seeds/config-repo/config-repo-howto.html` 을 더블클릭하면 같은 장이 열린다.

**옵션 셋은 창에서 고른다.** 여러 대를 같은 값으로 세워야 하면 `Setup.exe` 에 깃발을 붙여
칸을 미리 채워 둘 수 있다 — 창은 그대로 뜬다:

```powershell
.\Setup.exe -NoDevTools          # 개발 도구 칸을 끈 채로 연다
.\Setup.exe -WithPersonalConfig  # 규범·룰·스킬 칸을 켠 채로 연다
.\Setup.exe -NoUpgrade           # 갱신 칸을 끈 채로 연다
```

**창까지 안 띄우려면 설치 몸통을 직접 부른다.** 한 번 눌러 본 PC 면 짐이
`%LOCALAPPDATA%\Claude Code Setup\<판>\` 에 펴져 있다 — 그 자리의 `install.ps1` 이 몸통이고,
위 셋에 더해 `-NoLaunch`(끝에 창을 안 띄운다 — 물음창도 안 뜬다)와 `-Yes`(묻지 않는다)를 든다.

**여러 번 눌러도 안전하고, 누를 때마다 최신으로 올린다.** 이미 있는 것은 판을 견줘 바뀐
것만 찍는다 — `올렸다 1.2.3 -> 1.2.9` 처럼. 그래서 이 설치본은 처음 세울 때만이 아니라
**갱신할 때도 같은 것을 누르면 된다.**

## 안 될 때

### 설치 창이 뜨기도 전에 — `Setup.exe` 가 낸 창

설치 창이 못 뜨고 작은 창 하나만 뜬 자리다. **그 문구가 무엇을 해야 하는지를 가른다.**

| 창에 뜬 말 | 왜 · 어떻게 |
|---|---|
| `이 설치본에 판 번호가 없습니다` | 받은 파일이 성하지 않다 — **다시 받는다.** 두 번째도 같으면 그 문구를 보낸 사람에게 보낸다 |
| `윈도우가 이 계정의 자리를 안 알려 줍니다` | 이 계정에 `%LOCALAPPDATA%` 가 안 선 자리다. 로그아웃했다 다시 들어와 보고, 같으면 IT 에 프로필을 묻는다 |
| `설치 짐을 꺼내지 못했습니다` · `설치 짐이 반쪽만 풀렸습니다` | 짐이 펴지다 말았다. **`%LOCALAPPDATA%\Claude Code Setup\<판>` 폴더를 통째로 지우고 다시 누른다** — 반쯤 펴진 자리가 남아 있으면 다음 누름이 그것을 성한 것으로 보고 건너뛴다. 디스크가 찼는지도 같이 본다 |
| `설치 짐을 푸는 데 실패했습니다 — 이 윈도우가 너무 옛 판일 수 있습니다` | 짐을 푸는 자는 윈도우가 들고 오는 `tar.exe` 인데 **Windows 10 1803 아래에는 그것이 없다.** 그보다 옛 판이면 IT 에 윈도우 올리기를 요청한다. 그 위인데도 나면 위와 같이 판 폴더를 지우고 다시 누른다 |
| `설치 화면을 띄우지 못했습니다` | PowerShell 이 정책에 막힌 자리다. 그 줄을 그대로 보낸 사람에게 보낸다 |

**아무 창도 없이 파일이 사라졌다면 — 백신이다.** 서명을 안 산 설치 파일이라 백신이
휴리스틱으로 무는 자리가 있다. 브라우저가 「위험한 파일」이라 하거나, 받아 둔 파일이
말없이 없어지거나, 백신이 격리했다는 알림이 뜬다. **문 이름은 판마다 달라 우리가 미리 못
댄다** — 백신이 낸 문구를 **그대로 복사해 보낸 사람에게 보낸다.** 그 문구가 있어야 IT 에
예외를 낼 수 있고, 다음 판에서 그 계열을 피해 구울 수 있다.

### 설치가 도는 중

| 화면 | 왜 · 어떻게 |
|---|---|
| `winget 이 없다` | 설치가 먼저 되살려 본다 — 프로필 재등록, 안 되면 GitHub 에서 받기. 그래도 안 되면 진행하되 모자란 것 이름을 끝에 댄다 |
| winget 이 정책에 막힌다 | 사내 PC 정책이다. IT 에 문의한다 |
| **`지정한 경로가 존재하지 않습니다`** 창이 뜬다 | winget 이 받아 둔 설치기가 **실행 직전에 사라졌다.** 사내에서만 겪은 자리다 — 보안이 갓 받은 파일을 먹는 것으로 의심된다. **「확인」을 누르면 설치는 이어서 돈다** (안 누르면 그 자리에서 멈춰 있다). 그 앱만 나중에 손으로 깔고, 되풀이되면 IT 에 `%TEMP%\WinGet` 예외를 요청한다 |
| `! Claude 데스크탑을 못 찾았다` | 사외인데 윈도우가 그 앱을 안 잡는다. 시작 메뉴에서 직접 열면 되고, **그 줄을 그대로 만든 사람에게 보낸다** — 앱이 깔리는 꼴이 자리마다 달라서 나는 자리다 |
| 확장은 도는데 응답이 안 온다 | 낡은 창이다. VS Code 를 **전부 닫고** 새로 연다 |

### 검증 칸이 `[X]` 일 때

**칸마다 다음 걸음이 다르다.** 위에서부터 보고 **첫 번째 `[X]` 를 먼저 고친다** — 아래 것은
대개 그것에 딸린 것이다.

| `[X]` 가 뜬 칸 | 다음에 무엇을 하나 |
|---|---|
| `VS Code` | winget 이 못 깔았다. 위쪽 빨간 줄이 까닭을 든다 — 정책이면 IT, 아니면 다시 누른다 |
| `클로드 확장` · `Codex 확장` · `Gemini CLI Companion 확장` | VS Code 가 먼저 안 선 것이다. 위 칸을 먼저 고치고 다시 누른다. VS Code 는 `[O]` 인데 확장만 `[X]` 면 사내망이 확장 장터를 막은 자리라 IT 에 문의한다 |
| `Claude Code CLI` · `Codex CLI` · `Gemini CLI` | npm 이 못 깔았다. Node.js 줄이 위에서 졌는지 먼저 보고, 성했으면 **새 터미널을 열어** 다시 누른다 — 갓 깔린 Node 의 경로를 옛 창은 모른다 |
| `사내 환경 문서 (n/m)` · `게이트웨이 씨앗 (n/m)` · `검사 씨앗 (n/m)` · `설정 저장소 씨앗 (n/m)` | 홈에 깔린 파일 수가 짐보다 적다. 괄호의 두 숫자가 그것을 댄다. `~/.claude/` 가 읽기 전용이거나 백신이 복사를 막은 자리라 — 다시 누르고, 같으면 그 줄을 그대로 보낸다 |
| `ANTHROPIC_BASE_URL` · `ANTHROPIC_AUTH_TOKEN` · `ANTHROPIC_MODEL` | 키를 안 넣었거나 빈 값이다. 다시 눌러 넣는다 |
| `OPENAI_API_KEY` · `GEMINI_API_KEY` | 같은 회사 키를 Codex·Gemini 가 읽는 이름으로도 심는 자리다. 위의 `ANTHROPIC_AUTH_TOKEN` 이 같이 `[X]` 면 그것만 고치면 된다 |
| `Codex config.toml` · `Gemini settings.json` | 회사 설정 틀을 그 자리에 못 썼다. `~/.codex/` · `~/.gemini/` 가 읽기 전용인지 보고 다시 누른다 |
| `로컬 프록시 (/health)` | **프록시가 안 떴다** — 사내에서 Claude Code 와 Gemini 가 게이트웨이에 못 붙는다. 파이썬이 성한지 보고 다시 누른다. 왜 이 프록시가 있고 손으로 어떻게 세우나는 `~/.claude/posco/pgpt-proxy/README.md` 가 든다 |
| `Opus 5 문 — prefill …` | **떴는데 문을 못 연다** — 둘은 다른 명제라 따로 잰다. 괄호 안 숫자가 게이트웨이가 낸 답이다: **500 이상이면 상류가 끊은 것이라 우리 자리가 아니고**(잠시 뒤 다시 누른다), 그보다 작으면 프록시가 제 일을 못 한 것이다. 같은 `~/.claude/posco/pgpt-proxy/README.md` 가 재는 법을 든다 |

## 무를 때

**되돌리는 스위치는 아직 없다** — 아래를 손으로 지운다. PC 를 반납하거나, 부서를 옮기거나,
회사 게이트웨이를 떠나 개인 구독으로 돌아갈 때다.

⚠ **가장 급한 것은 환경변수다.** `ANTHROPIC_BASE_URL` 이 사내 프록시(`127.0.0.1:18901`)를
가리킨 채로 남으면, **사외로 나간 노트북의 Claude 가 뜨지도 않은 루프백을 문다** — 프로그램을
다 지워도 이 줄 하나가 남으면 그렇다.

| 지울 것 | 어디서 |
|---|---|
| **사용자 환경변수** — `ANTHROPIC_BASE_URL` · `ANTHROPIC_AUTH_TOKEN` · `ANTHROPIC_MODEL` · `OPENAI_API_KEY` · `GEMINI_API_KEY` | 시작 메뉴에 「환경 변수」로 검색 → 「계정의 환경 변수 편집」. 지우고 창을 새로 연다 |
| **로그인마다 뜨는 프록시** — 등록 이름은 `PGPTProxy` | 작업 관리자 → 시작 프로그램에서 사용 안 함. 완전히 걷으려면 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 의 그 이름을 지운다 |
| **홈에 깔린 환경 자료** | `~/.claude/posco/` · `~/.claude/seeds/` 폴더를 지운다 |
| **옵션을 켜서 깔린 규범·룰·스킬** | `~/.claude/` 의 `CLAUDE.md` · `rules/` · `skills/` · `agents/` |
| **Codex · Gemini 회사 설정** | `~/.codex/config.toml` · `~/.gemini/settings.json` |
| **바탕화면·시작 메뉴의 「PAI Setup Wizard」** | 바로가기를 지운다 |
| **펴 둔 짐** — 판마다 폴더가 하나씩 쌓인다 | `%LOCALAPPDATA%\Claude Code Setup\` 를 통째로 지운다 |

프로그램(VS Code · Node · Git · Python · CLI 셋)은 **남겨도 된다** — 회사와 무관한 것들이고,
지우려면 윈도우의 「앱」 화면이나 `winget uninstall` 이 든다.

⚠ **사내에서 쓰던 기계를 사외에서 다시 누르면 위의 첫 셋은 설치가 걷는다.** 자리를 스스로
재서 사외로 판정하면 게이트웨이 주소·키와 자동시작 프록시를 제 손으로 물린다 — 옛 값이 남아
새 값을 가리는 것이 부재보다 나쁜 자리라서다. 그 판정이 안 서는 자리(회사를 아주 떠날 때)를
위해 위 표를 둔다.

## 새 판이 나오면

모델 이름이 바뀌거나 게이트웨이가 옮겨지면 **깔린 것이 낡는다** — 저절로
따라가지는 않는다. 그때는 새 `Setup.exe` 를 받아 다시 누른다.
**여러 번 눌러도 안전하다** — 이미 맞는 것은 안 건드리고 달라진 것만 고친다.

받은 판이 언제 것인지는 릴리스 쪽에 적혀 있다.

## 문의

이 설치본을 낸 사람에게. 설치 화면을 **통째로 복사해서** 보내면 빠르다 — 어느 칸에서
멈췄는지가 거기 다 찍힌다.

## 쓰임 제한

**포스코 사람용이다.** 회사 키·프록시·회사 설정은 게이트웨이가 닿는 사내에서만 뜻이 있고,
사외에서는 그것들을 안 세우고 구독·개인 로그인으로 선다. 키는 사람마다 제 것이고, 받는 짐에는
안 들어 있다.
